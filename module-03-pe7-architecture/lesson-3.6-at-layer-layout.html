Lesson 3.6

@layer layout

Arrangement in space. Nothing else. The layout layer holds structural primitives — stack, cluster, grid, center, frame — and it is forbidden from ever setting a colour or a font.

The single responsibility

The layout layer arranges things in two dimensions. It decides what is a row, what is a column, what is a grid, how many tracks, what the gap is, what the inline size is. It does not decide what those things look like.

If you can delete every rule in the layout layer and the page still has the right colours, fonts, and decorations — just wrong arrangement — the layer is doing its job.

Primitive vocabulary

PE7 ships a small, deliberate vocabulary of layout primitives. Every project uses roughly the same ones. Module 5 covers each in detail. Here is the preview:

  • stack — vertical flow with a consistent gap between children.
  • cluster — horizontal flow that wraps, for rows of tags, buttons, breadcrumbs.
  • grid — auto-fit responsive grid for card layouts.
  • center — horizontally centered content with a max inline size.
  • frame — aspect-ratio container for media.
  • switcher — a row that collapses to a column below a container breakpoint.
  • sidebar — main-content-plus-sidebar that collapses sensibly.

Every layout need in a normal product application composes from these. If you find yourself reaching for a one-off layout in a component, stop — the right move is usually to add a new primitive to the layout layer.

Canonical primitives

@layer layout {
  .stack {
    display: grid;
    gap: var(--space-4);
  }

  .cluster {
    display: flex;
    flex-wrap: wrap;
    gap: var(--space-3);
    align-items: center;
  }

  .grid {
    display: grid;
    gap: var(--space-4);
    grid-template-columns: repeat(auto-fit, minmax(min(100%, 18rem), 1fr));
  }

  .center {
    box-sizing: content-box;
    max-inline-size: var(--measure-wide);
    margin-inline: auto;
    padding-inline: var(--space-4);
  }

  .frame {
    aspect-ratio: 16 / 9;
    overflow: hidden;
  }
}

Notice: every value comes from a token. The structure is the layout layer's decision. The spacing is still a tokens responsibility that layout consumes.

What layout must not contain

  • No colours. Not even background for "visual separation." That is components.
  • No typography. A layout primitive does not set font-family or font-size.
  • No borders or shadows. Those are decoration — components own decoration.
  • No element selectors. Layout is classes only.
  • No component names. A .card-grid rule is a component, not a layout primitive. The layer is .grid; the component reuses it.
