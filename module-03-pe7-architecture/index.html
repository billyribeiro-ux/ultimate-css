Module 3 · Architecture

The PE7 Layer Architecture

Module 2 taught you the syntax. This module teaches you what to do with it. Six layers, each with exactly one job, and seven non-negotiable boundary rules that keep those jobs from bleeding into each other.

Module goal

Learn to reach for the right layer without thinking. By the end of this module, when you see a CSS problem you will immediately know which of the six layers it belongs in — and you will know which it does not belong in, which is often the more important skill.

The stack, at a glance

@layer reset, tokens, base, layout, components, animations;

That line is the spine of every PE7 project. Every rule in your codebase lives in exactly one of those six layers. No exceptions, no overflow, no unlayered leaks.
