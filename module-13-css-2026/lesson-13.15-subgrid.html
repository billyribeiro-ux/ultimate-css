Lesson 13.15

Subgrid: Nested Grids That Align

subgrid lets a child grid inherit its parent's track definitions — so headings, prices, and buttons across a row of cards line up perfectly, even when content lengths vary.

The problem

A row of three pricing cards. Each has a heading, a price, a feature list, and a CTA button. The feature lists have different lengths. Without subgrid, the buttons float at different heights. To fix it, developers add min-height hacks or JavaScript to equalize heights. Both are fragile.

The fix

.pricing-grid {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: var(--space-lg);
}
.pricing-card {
  display: grid;
  grid-template-rows: subgrid;
  grid-row: span 4; /* heading, price, features, CTA */
  gap: var(--space-md);
}

grid-template-rows: subgrid makes the card's row tracks inherit from the parent grid. The parent distributes rows evenly across all cards. Headings align. Prices align. Buttons align. Regardless of content length.

Real-world: form layout

.form-grid {
  display: grid;
  grid-template-columns: auto 1fr;
  gap: var(--space-sm) var(--space-md);
}
.form-row {
  display: grid;
  grid-column: 1 / -1;
  grid-template-columns: subgrid;
}

Labels in the first column, inputs in the second. Every row participates in the same column track — labels align, inputs align, no matter how wide the longest label is.
