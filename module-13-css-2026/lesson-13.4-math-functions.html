Lesson 13.4

CSS Math Functions: round(), mod(), rem(), sign(), abs()

Chrome 125+, Firefox 118+, Safari 15.4+ (varies per function). Pure math in CSS — snap values to grids, cycle through patterns, detect direction, and compute absolute differences without JavaScript.

round() — snap to a grid

round(nearest, 1.7rem, 0.25rem) snaps 1.7rem to the nearest multiple of 0.25rem (returns 1.75rem). Use this to enforce a spacing grid — any computed value gets rounded to your base unit.

Rounding strategies: nearest (default), up, down, to-zero.

mod() and rem() — cyclic patterns

mod(7, 3) returns 1 — the modulo (always non-negative for positive divisors). rem(7, 3) returns 1 too in this case, but they differ for negative values. For layout patterns, mod() is what you want.

Combined with custom properties or sibling-index(), mod() enables cyclic patterns: alternating row colors, rotating animation delays, column assignments in a masonry-like layout.

sign() — directional logic

sign(--value) returns -1, 0, or 1 depending on the sign of the value. Use it for scroll direction indicators, caret rotation, or conditional transforms that flip based on a computed property.

abs() — magnitude without direction

abs(--delta) returns the absolute value. Useful for computing distances, ensuring a minimum gap regardless of direction, or normalizing animation ranges.

Real-world: spacing grid + cyclic tints

round() keeps your spacing on a 4px grid even when using fluid values. mod() with a counter or index cycles through 3 accent colors without writing separate :nth-child rules.
