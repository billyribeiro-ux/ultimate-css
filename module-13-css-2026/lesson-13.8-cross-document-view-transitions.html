Lesson 13.8

Cross-Document View Transitions

Chrome 126+, Firefox 135+, Safari 18+. Animate between full page navigations with a single CSS at-rule. No JavaScript router, no SPA framework, no client-side rendering required.

The opt-in: @view-transition

@view-transition { navigation: auto; } in your CSS enables cross-document view transitions for same-origin navigations. When the user clicks a link to another page on the same site, the browser captures a snapshot of the old page, loads the new page, and cross-fades between them.

view-transition-name: morph specific elements

By default, the entire page cross-fades. To morph a specific element (e.g., a card expanding into a detail page), give it a view-transition-name on both pages. The browser will animate that element's position, size, and appearance between its old and new states.

Each view-transition-name must be unique on a page. Two elements with the same name will break the transition.

view-transition-class: group animations

When multiple elements share the same animation style (e.g., all nav links slide in together), use view-transition-class to group them. You can then style all elements in that class with a single ::view-transition-group(.classname) rule.

Pseudo-elements for custom animations

The view transition API creates pseudo-elements you can style:

  • ::view-transition-group(name) — the container for old and new snapshots
  • ::view-transition-old(name) — the outgoing snapshot (fades out)
  • ::view-transition-new(name) — the incoming snapshot (fades in)

Override their default animations with custom keyframes for slides, zooms, or any effect you want.

Real-world: multi-page documentation site

A documentation site with a persistent sidebar: the sidebar has view-transition-name: sidebar on every page. During navigation, the sidebar stays put while the main content area cross-fades. The user perceives app-like continuity without any JavaScript framework.

Demo — view transition CSS (static reference)

/* Enable cross-document transitions site-wide */
@view-transition {
  navigation: auto;
}

/* Persistent sidebar morphs between pages */
.sidebar {
  view-transition-name: sidebar;
}

/* Main content area */
.main-content {
  view-transition-name: main;
}

/* Custom animation: slide in from right */
::view-transition-new(main) {
  animation: slide-in 0.3s ease-out;
}
::view-transition-old(main) {
  animation: slide-out 0.3s ease-in;
}

@keyframes slide-in {
  from { transform: translateX(2rem); opacity: 0; }
}
@keyframes slide-out {
  to { transform: translateX(-2rem); opacity: 0; }
}

Try it yourself

Mini-exercise

To test cross-document view transitions live: create two HTML files (page-a.html and page-b.html) in the same directory, both linking the same CSS with @view-transition { navigation: auto; }. Give the shared header view-transition-name: header on both pages. Serve them on localhost and click between pages — the header will stay fixed while content cross-fades.
