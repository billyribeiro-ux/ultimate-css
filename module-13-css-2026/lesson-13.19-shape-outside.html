Lesson 13.19

shape-outside: Text Wrapping Around Shapes

shape-outside: circle(50%) wraps text around a circular element instead of a rectangle. Magazine-style editorial layouts — text flowing around portraits, product images, decorative elements — with pure CSS.

The concept

By default, when you float an element, surrounding text wraps around its rectangular bounding box. shape-outside redefines the wrapping boundary to a circle, ellipse, polygon, or even the alpha channel of an image. The text flows along the shape's contour instead of the box edge.

The key constraint

shape-outside only works on floated elements. This is not an arbitrary limitation — it defines the exclusion area that inline content flows around, and CSS flow exclusions are tied to the float model. The element must have float: left or float: right.

Circle

.avatar {
  float: left;
  width: 8rem;
  height: 8rem;
  border-radius: 50%;
  shape-outside: circle(50%);
  shape-margin: 1rem;
  margin-right: 1rem;
}

circle(50%) creates a circular exclusion area using 50% of the element's width as the radius. The text wraps along the curve of the circle instead of the square bounding box.

shape-margin

shape-margin: 1rem;

shape-margin adds breathing room between the shape boundary and the wrapping text. Without it, text would press right up against the circle. Think of it as padding for the shape — it expands the exclusion area outward.

Polygon

.diamond {
  float: left;
  width: 10rem;
  height: 10rem;
  shape-outside: polygon(50% 0%, 100% 50%, 50% 100%, 0% 50%);
  clip-path: polygon(50% 0%, 100% 50%, 50% 100%, 0% 50%);
  shape-margin: 0.75rem;
}

The polygon() function accepts a list of x/y coordinate pairs. The text wraps along the polygon edges. Pair it with the same clip-path polygon to make the element itself match the wrapping shape visually.

Image-derived shapes

.cutout {
  float: right;
  width: 12rem;
  shape-outside: url(product-cutout.png);
  shape-image-threshold: 0.5;
  shape-margin: 1rem;
}

When you pass an image URL, the browser uses the alpha channel to determine the shape boundary. shape-image-threshold sets the minimum alpha value (0 to 1) that defines the shape edge. This is how you wrap text around a product image cutout or an irregular illustration.

Real-world patterns

  • Editorial profiles: text flowing around a circular headshot in an about page or author bio
  • Product pages: text wrapping around a product image cutout — the product "sits inside" the text
  • Magazine layouts: pull quotes or decorative elements with text flowing around non-rectangular shapes
  • Landing pages: a hero section where body text wraps around a diagonal or curved decorative block

Browser support

Chrome 37+, Firefox 62+, Safari 10.1+. Fully production-ready across all modern browsers. No polyfill needed.

Mini-exercise

Change shape-outside: circle(50%) to polygon(0% 0%, 100% 0%, 100% 100%) — a triangle. Add a matching clip-path with the same polygon coordinates. Watch the text rewrap along the diagonal edge. Then increase shape-margin to 1.5rem and observe how the text pulls away from the shape boundary.
