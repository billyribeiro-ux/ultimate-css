Lesson 13.2

Relative Color Syntax: oklch(from ...)

Chrome 125+, Firefox 128+, Safari 18+. Derive any color from any other color — lighten, darken, desaturate, shift hue — all in pure CSS. One brand token generates an entire palette.

The syntax: oklch(from origin l c h)

Relative color syntax takes an origin color and exposes its channels as variables you can manipulate with calc(). In OKLCH, those channels are l (lightness 0-1), c (chroma 0-0.4), and h (hue 0-360).

oklch(from var(--brand) l c h) returns the brand color unchanged. The power comes from modifying the channels.

Lighten and darken

oklch(from var(--brand) calc(l + 0.2) c h) adds 20% lightness — a lighter tint. calc(l - 0.15) darkens. Because OKLCH lightness is perceptually uniform, +0.2 looks like the same amount of change regardless of the base color.

Desaturate and saturate

oklch(from var(--brand) l calc(c * 0.5) h) halves the chroma — a muted version. calc(c * 1.5) intensifies. Clamping happens automatically; you cannot exceed the gamut.

Hue rotation

oklch(from var(--brand) l c calc(h + 180)) produces the complementary color. calc(h + 30) gives an analogous neighbor. Hue wraps at 360 automatically.

Real-world: one token, full palette

Instead of hand-picking 8 color variants for hover, active, subtle, on-brand-text, and complementary states, you derive them all from a single --brand token. Change the brand token and every variant updates instantly — zero manual recalculation.
