Lesson 13.7

::details-content: Animatable Disclosure

Chrome 131+. Firefox and Safari not yet. The ::details-content pseudo-element targets the content area of <details>, enabling fully animated accordion panels when combined with interpolate-size.

What ::details-content targets

The ::details-content pseudo-element represents everything inside a <details> element except the <summary>. Previously there was no way to target this anonymous box — you had to wrap content in a <div> and style that instead. The pseudo-element makes the wrapper unnecessary.

The animated accordion pattern

Combine ::details-content with interpolate-size: allow-keywords from Lesson 13.5. Set the closed state to block-size: 0; overflow: hidden; and the open state to block-size: auto;. Add a transition on block-size. The browser handles the rest.

The complete pattern

The key declarations: on ::details-content, set block-size: 0; overflow: hidden; transition: block-size 0.3s ease, content-visibility 0.3s allow-discrete;. On details[open]::details-content, set block-size: auto;. The content-visibility transition with allow-discrete handles the display toggling smoothly.

Why this matters

Native <details> is accessible by default — keyboard operable, announced correctly by screen readers, no ARIA needed. But the jarring snap open/close made teams reach for custom JavaScript accordions. This pseudo-element brings smooth animation to native HTML, keeping all the accessibility benefits of the built-in element.

Fallback

Without support, <details> works exactly as it always has — instant open/close. The semantic structure and accessibility remain intact. This is the ideal progressive enhancement: enhanced experience in supporting browsers, full functionality everywhere else.

Demo — animated FAQ with ::details-content

What is the ::details-content pseudo-element?
It targets the content area of a details element — everything except the summary. It enables direct styling and animation of the disclosure content without wrapper elements.
Does it replace wrapper divs in accordions?
Yes. Previously you needed a wrapper div around the content to set overflow, height, and transitions. The pseudo-element targets that anonymous box directly, making the wrapper optional.
How does it work with interpolate-size?
Set interpolate-size: allow-keywords on a parent, then transition block-size from 0 to auto on the pseudo-element. The browser smoothly interpolates between the values. Without interpolate-size, you cannot transition to auto — the pseudo-element alone is not enough.

Try it yourself

Mini-exercise

Add an opacity transition alongside the block-size transition: start at opacity: 0 on the closed state and transition to opacity: 1 when open. The content should fade in as it expands. Then add a subtle background color to the open summary using details[open] summary to give visual feedback about which panel is active.
