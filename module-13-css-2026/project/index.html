  8. Every progressive-enhancement feature wrapped in @supports

field-sizing: content

::details-content + interpolate-size

How does the animated accordion work?
It combines interpolate-size: allow-keywords with the ::details-content pseudo-element. The content area transitions from block-size: 0 to block-size: auto smoothly.
What happens in unsupported browsers?
The details element still opens and closes — it just snaps instead of animating. The @supports fallback removes the transition so there is no broken half-state.
Is this production-ready?
As a progressive enhancement, yes. The core functionality (disclosure) works everywhere. The animation is a bonus in Chrome 131+. Never make animation a requirement for usability.
