Lesson 16.5 · Real-World Layout

The Portfolio Gallery (Behance/Dribbble Style)

A masonry-like gallery with hover overlays, category filtering via :has() and radio buttons, a lightbox powered by the Popover API, and staggered reveal animations. The CSS columns property creates the masonry effect, with a @supports fallback for future grid-template-rows: masonry.

Masonry with CSS columns

True CSS masonry (via Grid) is still experimental. The most robust approach today is columns: 3 with break-inside: avoid on each card. This creates the staggered-height effect Behance and Dribbble use. A @supports (grid-template-rows: masonry) block provides a progressive enhancement path.

Category filtering with :has()

Radio buttons at the top represent categories (All, Branding, Web, Illustration). When a category is selected, :has(input[value="branding"]:checked) on the wrapper hides non-matching cards with display: none. The "All" radio resets visibility. No JavaScript filtering logic needed.

Lightbox via Popover API

Each gallery card wraps a button that triggers a [popover] element. The popover covers the viewport with a backdrop blur and centers the enlarged image. Pressing Escape or clicking outside dismisses it. The API handles focus trapping and accessibility automatically.

Staggered reveal animations

Cards use animation-delay calculated from a CSS custom property --i set inline. Combined with animation-timeline: view(), each card fades and scales in with a slight offset, creating the signature portfolio reveal.

Try it yourself — category filtering with :has()

Key takeaway

CSS filtering with :has() eliminates the need for JavaScript filtering libraries. Radio buttons serve as state, the wrapper's :has() selector reads which category is active, and non-matching cards get display: none. The masonry layout via columns automatically reflows when cards disappear. Zero JavaScript, zero layout shifts, zero complexity.
