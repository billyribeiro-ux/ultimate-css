Lesson 16.8 · Real-World Layout

The Email Client (Gmail/Outlook Style)

A three-column email client with a folder sidebar, email list, and reading pane. Read/unread states via :has(input:checked), star toggles via checkbox with clip-path, a compose modal using the Popover API, and responsive collapse via container queries. The full Gmail layout in pure CSS.

Anatomy of the layout

The email client uses a three-column grid: a narrow folder sidebar, a scrollable message list, and a wider reading pane. The message list items are selectable via hidden checkboxes. When a message checkbox is checked, :has(input:checked) on the reading pane shows the corresponding email content.

Read/unread states

Unread messages use font-weight: 700 and a left border accent. Once "read" (simulated by checking a checkbox), the style shifts to normal weight. The :has() selector on the list item detects whether its internal checkbox is in a read state.

Star toggle via clip-path

The star is a label element styled with a five-pointed clip-path: polygon(). Its associated checkbox toggles between filled (gold) and outline (gray) states. No SVG, no icon font, just geometry.

Compose modal via Popover

The compose button triggers a [popover] element styled as a floating compose window. It includes To, Subject, and Body fields, positioned at the bottom-right like Gmail. The popover API handles dismiss-on-escape and backdrop stacking.

Key takeaway

The email client demonstrates CSS as a full UI state layer. Star toggles are checkboxes with clip-path geometry. Read/unread states derive from :has(). The compose window is a native [popover]. Three-column layouts with scrollable panes are a simple grid declaration. The browser is the framework.
