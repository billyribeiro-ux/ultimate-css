The Video Platform (YouTube/Netflix Style)

A video platform with a featured hero, category tabs via :target, a responsive video grid with Netflix-style hover preview (scale + info overlay), a sidebar "up next" column, and skeleton loading states. The complete streaming interface in pure CSS.

Anatomy of the layout

The video platform opens with a large featured hero (the currently highlighted video). Below it, category tabs let users switch views using :target pseudo-class. The main area is a responsive grid of video thumbnails using auto-fit with minmax(). A sidebar column shows "up next" suggestions. On smaller viewports, the sidebar collapses below the grid.

Netflix-style hover preview

On hover, video cards scale up slightly (scale: 1.05) and reveal an info overlay that slides up from below. The card uses z-index elevation on hover to prevent clipping by siblings. The transition uses a slight delay on mouse-enter and immediate on mouse-leave for a polished feel.

Category tabs with :target

Each category section has an id. Navigation links point to these anchors. The :target pseudo-class shows the targeted section while hiding others. This provides JavaScript-free tab switching with deep-linkable URLs.

Responsive auto-fit grid

The video grid uses grid-template-columns: repeat(auto-fit, minmax(14rem, 1fr)) to automatically adapt from 4 columns on wide screens to 1 column on mobile. No media queries needed for the column count.

Key takeaway

The Netflix hover effect is deceptively simple: transform: scale(1.05) with a z-index bump on hover. The delayed transition (100ms delay on enter, 0ms on leave) prevents the jittery feel of instant scaling. Combined with auto-fit grids and skeleton shimmer animations, you get a production-grade video platform layout with zero JavaScript.
