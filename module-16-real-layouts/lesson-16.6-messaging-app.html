Lesson 16.6 · Real-World Layout

The Chat Interface (iMessage/WhatsApp Style)

A two-panel chat app with a contacts sidebar, a message thread, chat bubble tails via ::after, a typing indicator with bouncing dots, an auto-sizing text input using field-sizing: content, and sticky date headers. The classic messaging layout, rebuilt in pure CSS.

Anatomy of the layout

The chat interface splits into a contacts sidebar (scrollable list) and a main chat area. The chat area has a header bar, a messages container with flex column layout, and a pinned input bar at the bottom. Messages use margin-inline-start: auto for sent (right-aligned) and default alignment for received (left-aligned).

Chat bubble tails

The triangular "tail" on each bubble is a ::after pseudo-element with a CSS triangle (border trick) or clip-path. Sent bubbles get a tail pointing right in the accent color, received bubbles get one pointing left in the neutral color. The tail is positioned at the bottom corner of the bubble.

Typing indicator

Three dots bounce in sequence using animation-delay offsets. Each dot is a span with a shared @keyframes that translates Y. The staggered delays (0ms, 150ms, 300ms) create the classic wave effect.

Auto-sizing input

The field-sizing: content property (with a fallback to fixed height) allows the textarea to grow as the user types, up to a max-height. This matches the behavior of native messaging apps without JavaScript resize observers.

Key takeaway

Chat layouts are a masterclass in flex alignment. Sent messages use margin-inline-start: auto to push right, received messages sit naturally on the left. The bubble tails are a single ::after pseudo-element with clip-path: polygon(). The typing indicator is three spans with staggered animation-delay. Simple primitives, polished result.
