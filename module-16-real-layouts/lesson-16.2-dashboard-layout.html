Lesson 16.2 · Real-World Layout

The Dashboard (Linear/Notion Style)

Every SaaS product has a dashboard. The layout is deceptively simple — sidebar, header, main content — but the implementation requires careful grid work, collapsible navigation via :has(), and a dark-first color system. This lesson rebuilds the Linear/Notion dashboard pattern from scratch.

Layout architecture

The dashboard uses a CSS Grid with two columns: a fixed-width sidebar (16rem) and a flexible main area (1fr). The sidebar collapses when a hidden checkbox is checked, detected by :has(#sidebar-toggle:checked) on the wrapper. This changes the grid template to 0fr 1fr with a transition on grid-template-columns.

The dark-first approach

Dashboards are always dark. The colors use OKLCH with very low lightness (6-14%) for surfaces and high lightness (85-95%) for text. The light-dark() function provides a light alternative, but the primary experience is dark.

The CSS-only bar chart

The chart section uses flexbox with items aligned to the bottom (align-items: flex-end). Each bar's height is set via a --h custom property. The bars use OKLCH gradients from bottom to top, creating a polished data visualization without any charting library.

Navigation with :target

Sidebar links use the :target pseudo-class to indicate the active section. When a navigation link is clicked, the corresponding section's ID is targeted, and the matching nav item receives its active style via :target combined with sibling selectors.

Key takeaway

The collapsible sidebar pattern uses a single checkbox and :has() to modify the parent grid. The sidebar content overflows hidden when the column shrinks. No JavaScript state, no event listeners. The grid transition is smooth because grid-template-columns with fr units is interpolable.
