Lesson 16.9 · Real-World Layout

The Social Feed (Twitter/Instagram Style)

A vertical social feed with post cards containing avatar, name, timestamp, content, image, and action bar. A like toggle via checkbox and :has() with a heart scale animation, a stories bar with horizontal scroll-snap, and skeleton loading placeholders. The essential social media layout.

Anatomy of the layout

The social feed is a single-column centered layout. A stories bar scrolls horizontally at the top. Below it, post cards stack vertically. Each card has a header (avatar + name + timestamp), content area, optional image, and an action bar with like/comment/share. A sidebar shows suggested follows on wider viewports.

Like toggle with heart animation

The heart icon is a checkbox label using clip-path or the ::before/::after technique to draw the heart shape. When checked, :has(input:checked) triggers a scale keyframe animation (scale up to 1.3, bounce back to 1). The color transitions from neutral gray to red via OKLCH.

Stories bar with scroll-snap

The stories bar is a horizontally scrolling flex container with scroll-snap-type: x mandatory. Each story circle uses a gradient border ring (via border-image or a background gradient behind the avatar) to indicate unseen stories.

Skeleton loading states

Skeleton placeholders use a linear-gradient background animation that sweeps left-to-right, creating the shimmer effect. The skeleton cards match the exact dimensions of real cards so there is zero layout shift when content loads.

Key takeaway

Social feeds combine every CSS fundamental: flex for card layout, scroll-snap for stories, checkboxes for interactive state (likes, follows), gradient animations for skeleton loading, and :has() for propagating state changes visually. The heart animation is a single scale keyframe triggered by :checked. Simple, tactile, zero JavaScript.
