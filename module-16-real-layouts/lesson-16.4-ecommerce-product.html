Lesson 16.4 · Real-World Layout

The Product Page (Apple Store Style)

The premium product page is designed to sell one thing beautifully. A large hero image area, a scroll-snap gallery with indicator dots, color swatches that change a CSS custom property, a spec table, star ratings via clip-path, and a sticky add-to-cart bar that appears on scroll. All pure CSS.

Anatomy of the layout

Apple-style product pages follow a strict hierarchy: massive product imagery dominates the top half, while purchase details (price, color, storage, CTA) live in a sticky sidebar. As the user scrolls, a compact add-to-cart bar appears at the top. The image gallery uses scroll-snap-type: x mandatory for swipe navigation, with ::scroll-marker dots providing visual pagination in supporting browsers.

Color swatches via custom properties

Each color swatch is a radio button. When checked, the :has() selector on the product wrapper updates --product-color, which the hero gradient reads. This creates a live color preview without JavaScript. The technique scales to any number of variants.

Star ratings with clip-path

Each star is a single element with a polygon clip-path defining the five-pointed shape. Fill state is controlled by width percentage on a child element, allowing fractional ratings (e.g., 4.3 stars). The approach is accessible when paired with proper aria-label text.

The sticky add-to-cart bar

Using animation-timeline: scroll(), the bar transitions from translate: 0 -100% to translate: 0 0 once the user has scrolled past the hero. No intersection observer needed.

Key takeaway

A single --product-color custom property, toggled by :has(input[value]:checked), can repaint an entire product page. The gallery gradient, the sticky bar accent, and even the swatch highlight all read from the same variable. This is CSS-as-state-management: radio buttons hold the state, custom properties distribute it, and the browser does the rest.
