Lesson 10.6

Progressive enhancement

:target-current and CSS Counters

Two long-standing "needs JavaScript" patterns — table-of-contents scrollspy and auto-numbered sections — now belong to CSS. :target-current picks the currently-active section of a scroll-target group; CSS counters number anything.

:target-current scrollspy

.toc {
  scroll-target-group: auto;
}
.toc a:target-current {
  color: var(--color-primary);
  font-weight: 600;
}

Declare the navigation as a scroll target group. The browser tracks which section the page is scrolled to — based on the hash fragments the anchors point at — and matches :target-current on the corresponding anchor. No scroll listener, no Array.from(sections), no threshold tweaking.

CSS counters for auto-numbering

Counters are baseline in every browser going back a decade. If you have not used them, now is the time:

ol.steps { counter-reset: step; list-style: none; padding: 0; }
ol.steps li { counter-increment: step; }
ol.steps li::before { content: counter(step) ". "; color: var(--color-primary); font-weight: 700; }

You can reset, increment, and display counters across the document. Combine with nested counters for section.subsection numbering, or with counters() (plural) for full outline strings.

Why mix them?

Counters are your universal baseline — they work everywhere. :target-current is the progressive enhancement on top. A sticky TOC with counter-numbered items and :target-current highlighting gives you a complete reading companion that degrades gracefully: in older browsers, numbering still works; only the active highlight is lost.

Browser support

scroll-target-group and :target-current: Chrome 140+, Edge 140+. Safari and Firefox pending. Wrap in @supports selector(:target-current). CSS counters: baseline, no wrap needed.
