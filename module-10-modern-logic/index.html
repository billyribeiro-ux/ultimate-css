Module 10 · Logic

Modern CSS Logic and Functions

CSS is becoming a real language. This module covers the logic primitives that turn CSS from a styling sheet into a declarative computation layer: :is(), :where(), if(), @function, typed attr(), style container queries, and :target-current for scrollspy.

Module goal

Understand what computation you can now push into CSS — with the specificity and maintenance implications of each primitive — so the stylesheet expresses intent, and the DOM stays simple.

  • 10.2 The if() Function

  • 10.5 Container Style Queries
  • 10.6 :target-current and CSS Counters
