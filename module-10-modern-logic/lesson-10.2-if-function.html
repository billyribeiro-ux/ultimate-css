Lesson 10.2

Progressive enhancement

The if() Function

CSS has had conditional rules forever — @media, @supports, @container. What it has never had is a conditional value. if() changes that: it lets you pick a single value inline based on media, support, or style conditions.

The syntax

:root {
  --motion: if(
    media(prefers-reduced-motion: reduce): 0ms;
    else: var(--dur-fast)
  );
}

Three branches: a condition function, a value for that branch, and an else. The conditions available are media(), supports(), and style() — matching the three kinds of at-rules.

Why this matters

Before if(), expressing "use 200ms normally, 0ms with reduced motion" required two rules with duplicated selectors inside a media query. Multiplied across dozens of tokens, it turned the tokens file into a source-order minefield. if() collapses it to one declaration:

--dur-modal: if(media(prefers-reduced-motion: reduce): 0ms; else: 300ms);
--layout:    if(media(min-width: 50rem): grid; else: block);
--shadow:    if(supports(filter: drop-shadow(0 0 0 red)): drop-shadow(0 4px 8px #0002); else: 0 4px 8px #0002);

style() conditions

The most powerful form queries the value of another custom property on the same element:

.card {
  --elevation: 2;
  box-shadow: if(style(--elevation: 2): 0 4px 14px #0002; else: 0 1px 2px #0001);
}

This is a precursor to container style queries (Lesson 10.5) at the property level rather than the container level.

Browser support

Chrome 137+ (stable), Edge 137+. Safari and Firefox still implementing. Wrap in @supports (color: if(media(min-width: 0): red; else: red)) or fall through to explicit media queries.

Mini-exercise

Find one token in your tokens file that has a different value under prefers-color-scheme: dark or prefers-reduced-motion: reduce. Collapse it to a single if() declaration with a documented @supports fallback. Notice how the token definition now lives in exactly one place.
