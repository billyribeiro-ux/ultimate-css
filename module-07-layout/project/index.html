Module 7 · Project

A Responsive Page With Zero Media Queries

Build a complete marketing page using every primitive in this module. Container, stack, cluster, sidebar, grid, cover, and at least one container query. No viewport-width media queries anywhere in your CSS.

The brief

  1. Compose a hero with .cover.
  2. A features section with .container > .grid.
  3. An article-plus-sidebar section with .container > .sidebar.
  4. A tag cloud with .cluster.
  5. At least one card component that uses a container query to switch its internal layout at a specific inline-size.
  6. No @media (min-width: ...) or @media (max-width: ...) anywhere. The only media queries permitted are prefers-reduced-motion and prefers-color-scheme.

The complete layout layer

@layer layout {
  .container {
    inline-size: min(var(--container-max, 72rem), 100%);
    margin-inline: auto;
    padding-inline: var(--container-gap, 1.5rem);
  }

  .stack { display: flex; flex-direction: column; gap: var(--stack-gap, 1rem); }
  .stack > * { margin-block: 0; }
  .stack-lg { --stack-gap: 2rem; }

  .cluster {
    display: flex; flex-wrap: wrap;
    gap: var(--cluster-gap, .5rem);
    align-items: var(--cluster-align, center);
    justify-content: var(--cluster-justify, flex-start);
  }

  .sidebar { display: flex; flex-wrap: wrap; gap: var(--sidebar-gap, 2rem); }
  .sidebar > :first-child { flex-basis: var(--sidebar-width, 18rem); flex-grow: 1; }
  .sidebar > :last-child  { flex-basis: 0; flex-grow: 999; min-inline-size: var(--sidebar-min, 50%); }

  .grid {
    display: grid;
    grid-template-columns: repeat(auto-fit, minmax(min(100%, var(--grid-min, 16rem)), 1fr));
    gap: var(--grid-gap, 1rem);
  }

  .cover {
    display: grid; place-items: center;
    min-block-size: var(--cover-min-height, 100svh);
    padding: var(--cover-padding, 2rem);
  }

  .cq-inline { container-type: inline-size; }
}

Your deliverable

  1. Your layout.css — grep for @media and confirm only motion and color-scheme queries exist.
  2. Four screenshots of the same page: phone width, tablet width, laptop width, wide desktop. Every layout primitive adapts without a breakpoint.
  3. One screenshot showing the container-aware card in a wide grid and the same card in a narrow sidebar. Prove the card's layout changed based on its parent, not the viewport.
  4. A short note: which primitive surprised you the most when you realised how little CSS it took?
