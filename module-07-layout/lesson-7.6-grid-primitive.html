Lesson 7.6

The Grid Primitive

A responsive grid that fits as many columns as possible at the largest allowable track width, and drops columns automatically when the container narrows. One line of CSS replaces thirty lines of breakpoint-based column math — and it works without a single media query.

The rule

.grid {
  display: grid;
  grid-template-columns: repeat(
    auto-fit,
    minmax(var(--grid-min, 18rem), 1fr)
  );
  gap: var(--grid-gap, var(--space-md));
}

One declaration does all the work: repeat(auto-fit, minmax(18rem, 1fr)). Read it as: "repeat the column pattern as many times as fits. Each column is at minimum 18rem wide and can grow to an equal share of the available space."

auto-fit vs auto-fill

Both keywords tell the browser to create as many tracks as will fit. The difference is what they do with empty tracks:

  • auto-fill keeps empty tracks visible. If you ask for 18rem minimum and the container is 100rem wide, the browser creates five tracks even if you only have three items — the fourth and fifth are empty.
  • auto-fit collapses empty tracks. Three items in a five-track-capable container get three tracks, each expanded to fill the extra space.

Ninety percent of the time you want auto-fit — the grid adapts to how many items you have, not to how many items could theoretically fit. Use auto-fill when you need consistent column width regardless of item count (typically for an admin dashboard where the grid position of an item matters for alignment).

minmax(min, max)

The minimum is the narrowest column the grid will allow — when the container drops below one column worth of that minimum, the grid drops to one column. The maximum is 1fr, which means "share remaining space equally." Together they say: "never narrower than 18rem, never wider than an even share."

The overflow trap

A common bug: setting --grid-min: 20rem inside a parent that is only 18rem wide. The minmax lower bound wins, and the item becomes 20rem — overflowing the parent. The fix is to use min() in the lower bound:

grid-template-columns: repeat(
  auto-fit,
  minmax(min(100%, 18rem), 1fr)
);

Now the minimum is "the smaller of 100% of the parent and 18rem." In a 10rem parent, the column drops to 10rem and nothing overflows. Add this to the primitive in production — it costs nothing and prevents a real bug.

Grid vs cluster

Grid aligns items into columns. Cluster packs items into rows without column alignment. Use grid when the visual consistency of columns matters (product cards, photo galleries). Use cluster when items are different sizes and alignment would create ugly gaps (tag clouds, chip lists).

Mini-exercise

Change auto-fit to auto-fill and run. Then reduce the number of items in the HTML from six to two. With auto-fill, the two items stay at 14rem each with empty space on the right. With auto-fit, the two items expand to share the full row. Most of the time you want the latter — but the choice is deliberate.
