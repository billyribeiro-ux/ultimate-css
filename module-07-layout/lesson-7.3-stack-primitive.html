Lesson 7.3

The Stack Primitive

Stack is vertical flow with a consistent gap between children. It is the single most-used primitive in any real project, and the simplest to implement — but it only works reliably when it cooperates with a reset that zeroes margins on prose elements.

The rule

.stack {
  display: flex;
  flex-direction: column;
  gap: var(--stack-gap, var(--space-md));
}

Three declarations. Flex column gives you the axis; gap gives you the spacing; the custom property gives you the knob. Nothing else.

Why flex and not block

Block layout has margin-based spacing, and margins collapse. Two elements with margin-block: 1rem do not produce 2rem of space between them — they produce 1rem, because the margins overlap. That is fine for prose and catastrophic for layout. Flex gap does not collapse — the number you write is the number you get.

The belt-and-suspenders reset

Stack assumes its children have no block margins of their own. The PE7 reset already zeroes margins on prose elements (Lesson 5.3), but third-party content and certain user-generated HTML can introduce margins again. As a safety net, add an explicit override inside the primitive:

.stack > * {
  margin-block: 0;
}

This is one of the few cases where a layout primitive touches its children directly. The rationale is defensive — a stack that silently misbehaves because a child imported its own margin is worse than a tiny specificity bump.

Size variants as custom properties

.stack-sm { --stack-gap: var(--space-sm); }
.stack-lg { --stack-gap: var(--space-xl); }
.stack-xl { --stack-gap: var(--space-2xl); }

Three variants are almost always enough. More than that and you are re-inventing a spacing scale that should live in tokens. If a component needs a custom gap, set --stack-gap from the component layer without writing a new variant:

.hero .stack { --stack-gap: var(--space-3xl); }

Stack is not a vertical cluster

Stack always flows in one direction. It does not wrap. If you need horizontal flow that wraps, that is cluster (Lesson 7.4). The two are deliberately separate — a single primitive that "sometimes wraps" adds a conditional that is almost always the wrong default.

Nesting stacks

Stacks nest cleanly. The outer stack has its gap; the inner stack has its own. Both can be overridden via custom properties at any level. This is how you build a form: an outer stack for the form sections, inner stacks inside each section for the fields.

Mini-exercise

Add <p style="margin: 2rem 0">...</p> as a child of the outer stack and run. Without the .stack > * { margin-block: 0 } rule, the paragraph's own margin disrupts the gap. With it, the stack stays consistent. This is why the defensive rule exists — third-party content cannot break your layout.
