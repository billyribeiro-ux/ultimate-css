The Cluster Primitive

Cluster is horizontal flow that wraps. Tag clouds, breadcrumbs, button groups, chip lists, filter bars — any horizontally-arranged collection of items that must collapse to multiple rows when space runs out. Five lines of CSS, three custom-property knobs, and zero media queries.

The rule

.cluster {
  display: flex;
  flex-wrap: wrap;
  gap: var(--cluster-gap, var(--space-sm));
  align-items: var(--cluster-align, center);
  justify-content: var(--cluster-justify, flex-start);
}

The non-obvious decisions: flex-wrap: wrap is the entire reason cluster exists; align-items: center is the right default because items in a cluster are usually different heights (a tag and an icon, for example); justify-content: flex-start packs items to the inline-start.

Three knobs

  • --cluster-gap — space between items and between wrapped rows.
  • --cluster-align — cross-axis alignment. center, baseline, start.
  • --cluster-justify — inline alignment. flex-start, center, space-between, flex-end.

baseline alignment is worth calling out specifically — for clusters of text items with different font sizes (a breadcrumb trail, say), baseline alignment makes the text read as a single line regardless of size variation.

Use cases

  1. Tag cloud: default alignment, default justification, small gap.
  2. Breadcrumbs: baseline alignment, small gap, separators via pseudo-elements.
  3. Button group: center alignment, small gap, flex-end or flex-start justification.
  4. Form-field row: center alignment, medium gap, justify space-between for label/control pairs.
  5. Toolbar: center alignment, small gap, both start and end groupings via nested clusters.

Cluster vs grid

Cluster wraps but does not align items into columns. Grid aligns into columns but does not naturally wrap in the same way. The test: if you want the second row to line up with the first, you want grid. If you want the second row to pack tightly regardless of the first row, you want cluster. Breadcrumbs wrap into cluster. A product listing wraps into grid.

Row-gap vs column-gap

A single gap value applies to both axes. If you want different wrap-row spacing from inline spacing — wider row gap to emphasise grouping when the cluster wraps — use the two-value form: gap: 1rem 0.5rem (row-gap, column-gap). This is useful for dense tag clouds on narrow screens.

Mini-exercise

Resize the preview pane until the first cluster wraps. Watch how wrapping happens automatically with no media query. Now remove flex-wrap: wrap. The items overflow horizontally instead of wrapping. That one declaration is what separates cluster from a plain flex row.
