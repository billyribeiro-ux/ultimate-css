@layer layout: Primitives & Container Queries

Layout is structural, not visual. A handful of reusable primitives — container, stack, cluster, sidebar, grid, cover — compose into every layout any application will ever need. Add container queries and you can build a modern responsive system without writing a single media query.

Module goal

Learn the six structural primitives that cover 99% of real layouts, understand why they have no visual opinions, and use container queries to make them component-aware. The end state is a layout vocabulary you can reuse across projects without modification.

The single-responsibility rule for layout

Every rule in @layer layout answers exactly one question: "where do these children sit in relation to each other?" Not "what color are they," not "how big is their text," not "do they have a shadow" — only their spatial relationship. When a layout rule leaks visual opinion, it stops being reusable.
