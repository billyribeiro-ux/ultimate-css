Module 2 · Foundation

@layer Fundamentals

Module 1 left you frustrated with the cascade. This module hands you the one feature that fixes it: @layer. You will learn the syntax, the mental model, and the one rule that changes how you think about specificity forever.

Module goal

Master every part of the @layer at-rule — declaration, population, ordering, sub-layers, the unlayered escape hatch, and @import integration — so you can refactor any legacy stylesheet without touching a single selector. By the end, the Module 1 disaster will be a solved problem.

Browser support

@layer is production-ready in every modern browser: Chrome 99+, Firefox 97+, Safari 15.4+. Shipped in early 2022. You can use it today with no polyfill.
