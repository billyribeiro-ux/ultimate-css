Lesson 2.4

Layer Priority vs Specificity: The Core Insight

This is the lesson where @layer stops being syntax and becomes a worldview. One rule, correctly internalised, ends specificity wars forever.

The rule

A rule in a higher-priority layer always beats a rule in a lower-priority layer. Always. Even if the higher-layer rule has lower specificity. Even if the lower-layer rule is an ID. Even if the lower-layer rule comes later in the file.

Specificity only matters inside the same layer. Across layers, it is noise.

Why that fixes everything

Remember the Module 1 disaster: a third-party library shipped #site-header .ui-btn { ... !important }, and author code could not override it without escalating to another !important. That was a specificity war.

With layers, you put the library in a low layer (vendor) and put your overrides in a higher layer (components). Your .ui-btn class — specificity 0,1,0 — now beats their #site-header .ui-btn — specificity 1,1,0. The ID does not matter. The !important does not matter. The layer does.

The mental shift

Stop thinking "what is my specificity score?" Start thinking "what layer is this rule in, and should it be overriding the layer below?" That reframing is the whole product. Every rule below is a corollary.

Inside the same layer, specificity is still king

Do not misread the rule. Inside a single layer, the four cascade steps still apply exactly as in Module 1. Specificity, source order, the A/B/C columns — all of it. Layers only govern the between-layer decision. Once a layer wins, the within-layer fight resolves normally.

Live demo — class in high layer beats ID in low layer

#main-heading (1,0,0) in low layer vs .heading (0,1,0) in high layer

Under the old rules, the ID would win. With layers, the class wins. You see bold indigo, not regular gray.

Try it yourself

Mini-exercise

Add a third layer called vendor between low and high. Put #main-heading.heading.heading { color: red; } inside it — that is specificity 1,2,0, the highest score in the whole stylesheet. Predict the rendered color before running. Then explain, in one sentence, why your prediction was right.
