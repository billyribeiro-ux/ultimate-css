Module 23 · Special Contexts

CSS Beyond the Browser — Print & Email

CSS is not just for screens. Print stylesheets control how your pages look on paper. HTML email CSS has its own bizarre constraint universe. This module covers both — the techniques, the gotchas, and the production patterns.

Module goal

Master the two most important non-screen CSS contexts: print and HTML email. Print stylesheets let you control page breaks, margins, and layout linearization. Email CSS demands inline styles, table-based layouts, and progressive enhancement across dozens of rendering engines — from Apple Mail to Outlook's Word-based renderer. Both require you to think differently about what CSS can and cannot do.
