Lesson 23.1 · Print Stylesheets

Print Stylesheets: The Fundamentals

When a user hits Ctrl+P, your carefully crafted web page becomes a document on paper. Without a print stylesheet, they get navigation bars, sticky headers, and illegible dark backgrounds. With one, they get a clean, readable document. Here's how.

The @media print rule

Everything starts with the @media print block. Styles inside it only apply when the page is being printed or previewed for print:

@media print {
  /* These rules only apply on paper */
}

You can also use a separate stylesheet with a media attribute: <link rel="stylesheet" href="print.css" media="print">. The browser won't block rendering for print stylesheets, so there's no performance cost.

What to hide

The first job of any print stylesheet is removing elements that make no sense on paper:

@media print {
  nav,
  footer,
  .site-header,
  .sidebar,
  .cookie-banner,
  button,
  .no-print {
    display: none !important;
  }
}

Navigation, interactive controls, video embeds, chat widgets — none of these serve the reader on paper.

What to show: URLs after links

On screen, a link's destination is discoverable via hover. On paper, it's invisible. The classic technique uses generated content:

@media print {
  a[href^="http"]::after {
    content: " (" attr(href) ")";
    font-size: 0.85em;
    font-weight: normal;
    word-break: break-all;
  }
}

This appends the full URL after every external link, so readers know where to go.

Background colors don't print

By default, browsers strip background colors and images when printing (to save ink). If you need them — for branding, charts, or diagrams — you must explicitly opt in:

@media print {
  .brand-header {
    -webkit-print-color-adjust: exact;
    print-color-adjust: exact;
  }
}

Page margins with @page

The @page rule controls the physical page itself — margins, size, and orientation:

@page {
  margin: 2cm;
}

@page :first {
  margin-top: 4cm; /* Extra space on the first page */
}

Font sizing for print

Screen fonts are sized in px, rem, or em. Print fonts historically use pt (points) — 1pt = 1/72 inch. A good body text size for print is 11–12pt:

@media print {
  body {
    font-size: 12pt;
    line-height: 1.5;
    color: #000;
    background: #fff;
  }
}

Try it yourself

Mini-exercise

Open your browser's print preview (Ctrl+P / Cmd+P) on any page you've built. Notice what looks broken — sticky headers overlapping content, dark backgrounds wasting ink, invisible links. Add a @media print block that fixes at least three of these issues. Bonus: add abbr[title]::after { content: " (" attr(title) ")"; } to expand abbreviations on paper.
