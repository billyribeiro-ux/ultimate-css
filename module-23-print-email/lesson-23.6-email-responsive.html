Lesson 23.6 · HTML Email

Responsive HTML Emails

Over 60% of emails are opened on mobile. But with Gmail stripping styles and Outlook ignoring media queries, how do you make a responsive email? The answer is the fluid-hybrid method — responsive by default, no media queries required.

The @media query approach

Media queries work in Apple Mail, iOS Mail, and some Android clients. They do NOT work in Gmail (webmail) or Outlook desktop:

<style>
  @media screen and (max-width: 600px) {
    .container { width: 100% !important; }
    .column { display: block !important; width: 100% !important; }
    .mobile-hide { display: none !important; }
  }
</style>

Since Gmail strips <style> tags, media queries are an enhancement, not the base.

The fluid-hybrid method

This technique makes emails responsive without media queries using a combination of max-width, width: 100%, and Outlook-specific conditional comments:

<!--[if mso]>
<table role="presentation" cellpadding="0" cellspacing="0" width="600" align="center">
<tr><td>
<![endif]-->

<div style="max-width:600px;margin:0 auto;">
  <!-- Content flows at 100% width on mobile,
       capped at 600px on desktop -->
</div>

<!--[if mso]>
</td></tr></table>
<![endif]-->

Outlook ignores max-width but reads the conditional comment table. All other clients ignore the comments and use the div with max-width.

The 600px convention

Why 600px? It's the widest that fits in most email client preview panes (Outlook's reading pane, Gmail's layout). Wider emails get horizontal scrollbars. It's become the industry standard maximum.

The "spongy" outer container

The outer wrapper uses this pattern to be fluid on mobile, fixed on desktop:

<table role="presentation" cellpadding="0" cellspacing="0" border="0"
       style="width:100%;max-width:600px;margin:0 auto;">
  <tr>
    <td style="padding:20px;">
      <!-- Email content -->
    </td>
  </tr>
</table>

Fluid-hybrid columns

Two-column layouts use display:inline-block with percentage widths. On small screens, they stack naturally:

<!--[if mso]>
<table role="presentation" width="600"><tr>
<td width="290" valign="top">
<![endif]-->
<div style="display:inline-block;width:100%;max-width:290px;vertical-align:top;">
  Column 1 content
</div>
<!--[if mso]></td>
<td width="290" valign="top">
<![endif]-->
<div style="display:inline-block;width:100%;max-width:290px;vertical-align:top;">
  Column 2 content
</div>
<!--[if mso]></td></tr></table>
<![endif]-->

Dark mode in email

@media (prefers-color-scheme: dark) works in Apple Mail, iOS Mail, and Outlook on macOS. It's the enhancement layer for dark mode support:

@media (prefers-color-scheme: dark) {
  .email-body { background-color: #1a1a2e !important; }
  .email-text { color: #e0e0e0 !important; }
}

Resize the preview below 600px — the columns should stack naturally without any media query.
