Lesson 23.7 · HTML Email

Email Component Patterns

Every email is built from the same handful of components: buttons, images, spacers, dividers, columns, and hero sections. Each has a specific pattern that works across clients — especially the tricky ones. Here are the battle-tested implementations.

1. The button

You cannot use <button> in email — it won't work. The email button is a table cell with a background color containing a link:

<!-- The bulletproof button -->
<table role="presentation" cellpadding="0" cellspacing="0" border="0">
  <tr>
    <td style="border-radius:4px;background-color:#4a3fbf;">
      <a href="https://example.com"
         style="display:inline-block;padding:12px 28px;
                color:#ffffff;text-decoration:none;
                font-family:Arial,sans-serif;
                font-size:14px;font-weight:bold;">
        Click Here
      </a>
    </td>
  </tr>
</table>

The entire cell is visually the button, but only the link text is clickable. For a fully clickable button area in Outlook, use VML (Vector Markup Language) — a technique called the "bulletproof button."

2. The image

Always set width and height as HTML attributes (not just CSS) and add display:block to prevent phantom spacing:

<img src="hero.jpg" width="600" height="300"
     alt="Descriptive text"
     style="display:block;width:100%;max-width:600px;height:auto;">

The HTML attributes tell Outlook the dimensions. The inline styles make it fluid in modern clients.

3. The spacer

Need vertical space? A table row with a set height. Do not rely on margin:

<table role="presentation" cellpadding="0" cellspacing="0" border="0" width="100%">
  <tr>
    <td style="height:24px;font-size:1px;line-height:1px;">&nbsp;</td>
  </tr>
</table>

The &nbsp; prevents the cell from collapsing in Outlook. The tiny font-size keeps it from expanding.

4. The divider

A horizontal line between sections — implemented as a border on a table cell:

<table role="presentation" cellpadding="0" cellspacing="0" border="0" width="100%">
  <tr>
    <td style="border-bottom:1px solid #dddddd;
               height:1px;font-size:1px;line-height:1px;">
      &nbsp;
    </td>
  </tr>
</table>

5. The two-column layout

Two approaches: nested tables (Outlook-safe) or display:inline-block (fluid-hybrid):

<!-- Nested tables approach (Outlook-safe) -->
<table role="presentation" width="600" cellpadding="0" cellspacing="0">
  <tr>
    <td width="290" valign="top" style="padding-right:10px;">
      Left column
    </td>
    <td width="290" valign="top" style="padding-left:10px;">
      Right column
    </td>
  </tr>
</table>

6. The hero image with text overlay

True overlays require background images with VML fallbacks for Outlook:

<td style="background-image:url('hero.jpg');
           background-size:cover;background-position:center;
           padding:60px 30px;text-align:center;">
  <!--[if mso]>
  <v:rect xmlns:v="urn:schemas-microsoft-com:vml" fill="true" stroke="false"
    style="width:600px;height:300px;">
    <v:fill type="frame" src="hero.jpg" />
    <v:textbox inset="0,0,0,0">
  <![endif]-->
  <h1 style="color:#ffffff;font-size:28px;">Welcome</h1>
  <!--[if mso]></v:textbox></v:rect><![endif]-->
</td>
