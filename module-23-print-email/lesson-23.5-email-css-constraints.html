Lesson 23.5 · HTML Email

HTML Email CSS: The Constraint Universe

Forget everything you know about modern CSS. HTML email is a parallel universe where Outlook renders with Microsoft Word's engine, Gmail strips your style tags, and the year is effectively 2007. Here's what actually works.

What works everywhere

These CSS properties are safe across all major email clients (Outlook, Gmail, Apple Mail, Yahoo):

/* Safe in email */
color: #333333;
font-size: 16px;
font-family: Arial, sans-serif;
font-weight: bold;
line-height: 1.5;
text-align: center;
text-decoration: underline;
padding: 10px 20px;
margin: 0;
border: 1px solid #cccccc;
background-color: #f5f5f5;
width: 600px;
max-width: 600px;

What does NOT work

These modern CSS features will fail in one or more major clients:

FeatureFails in
display: flexOutlook (all versions)
display: gridOutlook (all versions)
--custom-propertiesMost clients
@layer, @scopeAll email clients
:has(), :is()Most clients
@supportsAll email clients
position: sticky/fixedAll email clients
oklch(), color()Most clients
:root {}Gmail (strips it)

Why Outlook uses tables

Outlook on Windows renders HTML using Microsoft Word's engine (since 2007). Word understands tables for layout but not flexbox, grid, or even floats properly. This is why every production email still uses <table> for structure:

<table role="presentation" cellpadding="0" cellspacing="0" border="0" width="600">
  <tr>
    <td style="padding: 20px; font-family: Arial, sans-serif;">
      Content here
    </td>
  </tr>
</table>

The role="presentation" attribute tells screen readers this table is for layout, not data.

Gmail strips <style> tags

Gmail (non-AMP) strips <style> blocks from the <head>. Your CSS must be inlined on each element. Tools like Juice, MJML, and Maizzle handle this inlining automatically in your build process.

The progressive enhancement strategy

The production approach is layered:

  1. Base layer — Table layout with inline styles. Works in Outlook and Gmail.
  2. Enhancement layer — <style> block in <head> with media queries for Apple Mail and modern clients.
  3. Dark mode layer — @media (prefers-color-scheme: dark) for clients that support it.
