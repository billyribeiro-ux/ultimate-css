Lesson 23.3 · Print Stylesheets

Print-Optimized Layouts

Grid layouts, flex cards, collapsed accordions, and scroll containers all look wrong on paper. A print stylesheet must linearize multi-column layouts, expand hidden content, and add page-specific affordances like page numbers and running headers.

Linearizing grid and flex layouts

A 3-column dashboard is great on screen. On paper, it produces cramped, unreadable columns. The fix: collapse to a single column:

@media print {
  .dashboard-grid {
    display: block; /* Overrides grid/flex */
  }
  .dashboard-grid > * {
    width: 100%;
    margin-bottom: 1rem;
  }
}

Expanding collapsed content

Accordions, tabs, and <details> elements hide content that the reader might need on paper. Force them open:

@media print {
  details {
    display: block !important;
  }
  details > summary {
    display: list-item; /* Keep summary visible */
  }
  details[open] > * {
    display: block;
  }
  /* Force all details open via attribute */
  details:not([open]) > *:not(summary) {
    display: block !important;
  }
}

Removing scroll containers

Tables inside overflow: auto containers get clipped on paper. Remove the constraint:

@media print {
  .table-wrapper {
    overflow: visible !important;
    max-height: none !important;
  }
  table {
    width: 100%;
    font-size: 9pt;
  }
}

QR codes for links

For important URLs, you can generate QR codes via CSS-referenced images or use a service URL in generated content. While CSS alone cannot render a QR code, you can show a pre-generated one:

@media print {
  .print-qr {
    display: block; /* Hidden on screen */
    width: 100px;
    height: 100px;
  }
}
@media screen {
  .print-qr { display: none; }
}

Page numbers with CSS counters

The @page rule supports margin boxes for page numbers (note: browser support is limited, but works in print-focused tools like Prince and WeasyPrint):

@page {
  @bottom-center {
    content: "Page " counter(page) " of " counter(pages);
    font-size: 9pt;
    color: #666;
  }
}

Running headers and footers

The CSS Paged Media spec defines margin boxes for running content. While browser support is experimental, the concept is production-ready in PDF generators:

@page {
  @top-left {
    content: "Company Report 2026";
    font-size: 8pt;
    color: #999;
  }
  @top-right {
    content: string(chapter-title);
  }
}
h2 { string-set: chapter-title content(); }
