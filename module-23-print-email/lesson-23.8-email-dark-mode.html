Lesson 23.8 · HTML Email

Dark Mode in Email Clients

Dark mode is everywhere — including email. But each client handles it differently. Apple Mail lets you control it fully. Gmail forces its own dark mode by inverting colors algorithmically. Outlook has partial support. Here's how to handle all three.

Client support landscape

  • Apple Mail / iOS Mail — Full support. Respects @media (prefers-color-scheme: dark) and meta color-scheme.
  • Outlook (macOS) — Full support for the media query.
  • Outlook (Windows) — Partial. Has its own dark mode that inverts colors unpredictably.
  • Gmail (Android) — Forced dark mode. Inverts light backgrounds to dark algorithmically. You cannot fully control it.
  • Gmail (web) — No dark mode transformation.
  • Yahoo Mail — Partial forced dark mode on mobile.

The meta tag

Signal dark mode support in the email <head>:

<meta name="color-scheme" content="light dark">
<meta name="supported-color-schemes" content="light dark">

This tells Apple Mail and iOS that your email is designed for both modes.

The CSS approach

<style>
  :root {
    color-scheme: light dark;
  }

  @media (prefers-color-scheme: dark) {
    .email-body {
      background-color: #1a1a2e !important;
    }
    .email-text {
      color: #e0e0e0 !important;
    }
    .email-heading {
      color: #ffffff !important;
    }
    .email-btn {
      background-color: #6c63ff !important;
    }
    .email-footer {
      background-color: #12121f !important;
      color: #999999 !important;
    }
  }
</style>

Gmail's forced dark mode

Gmail on Android forces dark mode by inverting colors. It applies a [data-ogsb] attribute to transformed elements. You can target this (though it's fragile):

/* Target Gmail's forced dark mode */
u + .body .email-body {
  background-color: #1a1a2e !important;
}

/* Or use the data attribute (Android Gmail) */
[data-ogsb] .email-text {
  color: #e0e0e0 !important;
}

The u + .body selector targets Gmail's specific DOM wrapping.

Transparent images

A logo with a white background looks terrible in dark mode. Use transparent PNGs instead:

<!-- Bad: white background logo -->
<img src="logo-white-bg.jpg">

<!-- Good: transparent PNG -->
<img src="logo-transparent.png">

<!-- Best: swap images for dark mode -->
<style>
  @media (prefers-color-scheme: dark) {
    .logo-light { display: none !important; }
    .logo-dark { display: block !important; }
  }
</style>
<img class="logo-light" src="logo-dark-text.png">
<img class="logo-dark" src="logo-light-text.png" style="display:none;">

Testing

You cannot test dark mode email in a browser alone. Tools like Litmus and Email on Acid provide previews across clients and modes. At minimum, test in:

  • Apple Mail (macOS) with dark mode on
  • iOS Mail with dark mode on
  • Gmail app (Android) with dark mode on
  • Outlook (Windows) with dark mode on
