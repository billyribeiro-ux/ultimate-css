Controlling Page Breaks

Nothing looks worse in a printed document than a heading orphaned at the bottom of a page, or a figure split from its caption. CSS gives you fine-grained control over where page breaks happen — and where they must not.

The break properties

CSS fragmentation is controlled by three properties:

/* Force a break before this element */
h1 { break-before: page; }

/* Prevent a break after this element */
h2, h3 { break-after: avoid; }

/* Prevent a break inside this element */
figure, .card { break-inside: avoid; }

The values include auto (default), avoid, page, left, right, column, and avoid-page.

Preventing orphaned headings

A heading at the bottom of a page with no content following it looks broken. The fix is simple:

@media print {
  h1, h2, h3, h4, h5, h6 {
    break-after: avoid;
  }
}

This tells the browser: if a heading would end up at the bottom of a page with nothing after it, move it to the next page instead.

Keeping figures with captions

A figure and its caption must stay together — splitting them across pages is confusing:

@media print {
  figure {
    break-inside: avoid;
  }
}

Chapter breaks

For long documents with chapters or major sections, force each chapter to start on a new page:

@media print {
  .chapter {
    break-before: page;
  }
  /* Start chapters on right-hand pages (for books) */
  .chapter-recto {
    break-before: right;
  }
}

Orphans and widows

These properties control how many lines of a paragraph must appear at the bottom of a page (orphans) or the top of the next page (widows):

@media print {
  p {
    orphans: 3; /* At least 3 lines before a break */
    widows: 3;  /* At least 3 lines after a break */
  }
}

The default is typically 2 for both. Setting 3 produces more professional-looking documents — no single-line dangling paragraphs.

Legacy properties

You may encounter page-break-before, page-break-after, and page-break-inside in older code. These are the old syntax — the break-* properties supersede them, but the legacy versions still work for backwards compatibility.
