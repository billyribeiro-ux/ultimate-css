Lesson 23.4 · Print & PDF

CSS for PDF Generation

Invoices, receipts, reports, contracts — the most common production use of CSS print is generating PDFs. Whether via the browser's print dialog, Puppeteer, or dedicated tools like WeasyPrint, CSS controls the output. Here's how to make it pixel-perfect.

The tools

CSS-to-PDF generation happens through several paths:

  • Browser print dialog — Ctrl+P, "Save as PDF." Uses the browser's print engine.
  • Puppeteer / Playwright — Headless Chrome, call page.pdf(). Same engine, automated.
  • wkhtmltopdf — WebKit-based CLI tool. Older but still widely used.
  • WeasyPrint / Prince — Dedicated CSS-to-PDF engines with better @page support.

Setting page size

The @page rule accepts a size property for explicit paper dimensions:

@page {
  size: A4;            /* 210mm x 297mm */
  margin: 20mm;
}

/* Or use US Letter */
@page {
  size: letter;        /* 8.5in x 11in */
  margin: 0.75in;
}

/* Or explicit dimensions */
@page {
  size: 210mm 297mm;
  margin: 15mm 20mm;
}

Bleed and crop marks

For professional printing (booklets, brochures), you need bleed area and crop marks:

@page {
  size: A4;
  marks: crop cross;   /* Crop marks + registration crosses */
  bleed: 3mm;          /* Content extends 3mm past trim */
}

Bleed ensures that full-bleed images extend past the cut line, preventing white edges after trimming.

Color considerations

CSS works in sRGB. Professional print uses CMYK. While CSS has no native CMYK mode, you can use the color() function with ICC profiles in some engines. For most web-to-PDF use cases (invoices, reports), sRGB is fine. For commercial printing, export to a design tool.

The invoice pattern

Invoices are the most common production CSS-to-PDF use case. The key patterns:

@page {
  size: A4;
  margin: 20mm;
}

.invoice {
  font-family: system-ui, sans-serif;
  font-size: 10pt;
  color: #333;
}

.invoice-header {
  display: flex;
  justify-content: space-between;
  margin-bottom: 2rem;
  -webkit-print-color-adjust: exact;
  print-color-adjust: exact;
}

.invoice-table {
  width: 100%;
  border-collapse: collapse;
}
.invoice-table th {
  background: #f5f5f5;
  padding: 8pt 12pt;
  text-align: left;
  border-bottom: 2px solid #333;
  -webkit-print-color-adjust: exact;
  print-color-adjust: exact;
}
.invoice-table td {
  padding: 8pt 12pt;
  border-bottom: 1px solid #ddd;
}
.invoice-total {
  font-size: 14pt;
  font-weight: 700;
  text-align: right;
  margin-top: 1rem;
}

Try it yourself

Mini-exercise

Build a receipt or invoice. Set @page { size: A4; margin: 20mm; }. Add a company logo area, line items in a table, and a total. Use print-color-adjust: exact on the table header background. Open print preview and verify it fits cleanly on one page. Bonus: add marks: crop cross and observe the marks (visible in some PDF viewers).
