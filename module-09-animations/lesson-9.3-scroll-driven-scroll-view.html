Lesson 9.3

Progressive enhancement

Scroll-Driven Animations

Scroll progress bars, reveal-on-scroll, parallax, sticky-until-past — for a decade these required IntersectionObserver plus requestAnimationFrame plus main-thread layout. The browser can now drive any animation directly from scroll position, off the main thread, in CSS.

Two timelines

Every scroll-driven animation binds to one of two timelines:

  • scroll() — progresses 0 → 100% as a scroll container scrolls from top to bottom. Perfect for reading progress bars.
  • view() — progresses 0 → 100% as a specific element enters and exits the scrollport. Perfect for reveal-on-scroll.

Progress bar

.progress {
  position: fixed; inset-block-start: 0; inset-inline: 0;
  block-size: 4px; transform-origin: 0 50%;
  animation: grow linear;
  animation-timeline: scroll(root block);
}
@keyframes grow { from { transform: scaleX(0); } to { transform: scaleX(1); } }

No event listener, no throttling, no main-thread work. The browser runs the animation on the compositor.

Reveal on scroll

.reveal {
  animation: fade-up linear;
  animation-timeline: view();
  animation-range: entry 0% entry 40%;
}
@keyframes fade-up {
  from { opacity: 0; transform: translateY(2rem); }
  to   { opacity: 1; transform: translateY(0); }
}

animation-range: entry 0% entry 40% means "start the animation the moment the element enters the scrollport; finish it when it is 40% of the way in". The range syntax is the scroll-driven equivalent of a duration.

Browser support

Chrome 115+, Edge 115+, Safari 26+, Firefox experimental. Always wrap in @supports (animation-timeline: scroll()). The fallback is: element is simply visible in its final state.

Try it yourself

Mini-exercise

Change animation-range to cover 0% cover 100%. Scroll through the preview and watch the animation now span the element's entire time in the viewport. Try exit 0% exit 100% — now the card only animates on the way out. Each keyword range is a different story the animation can tell about the element's relationship to the scrollport.
