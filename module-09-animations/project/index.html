Module 9 · Project

Motion System Demo

One page. One animations layer. Five motion patterns. One reduced-motion override that turns them all off. This is what a production motion system actually looks like.

The brief

Ship a demo page that exercises every motion primitive from this module: a scroll progress bar, scroll-driven section reveals, a staggered card grid, a modal with @starting-style, and a global prefers-reduced-motion kill-switch verified to strip everything.

Deliverable

Enable "Reduce motion" in your OS. Reload this page. Verify: progress bar does not animate, sections appear instantly, stagger is gone, modal toggles without animation. Then turn it back off and watch the whole system return. That verification is the deliverable — a working motion system is one you can confidently switch off.
