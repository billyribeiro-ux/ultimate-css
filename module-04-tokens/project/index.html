Module 4 · Project

Complete Token System

A single-page showcase for a full PE7 token layer: colour scale, spacing scale, type scale, motion preview, and a data-attribute theme switcher — every value driven by primitives, every consumer reading semantics.

The brief

Build a living style reference page that proves the token system is complete. The page itself must be styled using only tokens — no hex, no raw pixels, no magic numbers. Swap the theme; every section updates. That is the acceptance test.

What is covered

  • Full 9-stop purple scale plus gray, green, amber, red.
  • Semantic aliases for surface, text, brand, status colours.
  • Spacing scale from --space-1 through --space-16.
  • Type scale from --text-xs through --text-4xl.
  • Motion durations and easings with an animated demo.
  • Two themes switched via [data-theme] on the showcase root.

The architecture, end to end

Everything above proves one thing: primitives are stable, semantics carry intent, components consume semantics, and themes are just a different set of semantic aliases. When a designer changes the brand hue, you edit one primitive. When the product adds high-contrast mode, you add one data-theme block. When a component needs a variant, you expose a component token. No specificity wars, no duplicated palettes, no rebrands that take a sprint.
