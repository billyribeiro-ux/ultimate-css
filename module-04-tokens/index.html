Module 4 · Tokens

@layer tokens: Design Tokens with OKLCH

Tokens are the data your design system runs on. This module builds a complete token stack — colour in OKLCH, T-shirt spacing, a typographic scale, motion vocabulary, and typed custom properties via @property — from first principles.

Module goal

Ship a production-grade tokens layer. By the end you will know why OKLCH replaces every previous colour model, how to build a palette that a designer can trust, how to scale every other design category with the same discipline, and how @property lets you animate values that used to be animation-hostile.
