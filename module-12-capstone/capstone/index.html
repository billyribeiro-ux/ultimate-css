Questions, answered.

Do I need a framework to use Prism?

No. Prism outputs raw CSS custom properties and standards-compliant web components. It works with React, Vue, Svelte, Angular, or plain HTML — or all of them at once.

How does Prism handle dark mode?

Every semantic color token is defined with light-dark(). Dark mode follows the user's OS preference by default, with no class toggling or JavaScript required.

Can I self-host Prism?

Yes. The Enterprise plan includes an on-premise option with Docker images and a documented install path.

What browsers does Prism output support?

Prism output targets Chrome, Firefox, Safari, and Edge — all evergreen versions. Modern features like container queries, @layer, and OKLCH are required.

Is there a free tier?

Yes. The Starter plan is free forever for up to 50 tokens and 3 components — enough for individual developers and small side projects.
