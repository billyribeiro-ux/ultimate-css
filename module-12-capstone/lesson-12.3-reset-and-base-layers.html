Lesson 12.3

Reset and Base Layers

Apply the production reset from Module 5 and build the base layer for Prism using only the tokens from 12.2. With just these two layers, the page should already be legible and accessible.

What you are building

  • capstone/css/reset.css — the complete PE7 reset (from Module 5), :where()-wrapped, with the prefers-reduced-motion override.
  • capstone/css/base.css — body defaults using tokens, heading hierarchy with text-wrap: balance, paragraph with text-wrap: pretty and max-inline-size: 65ch, :focus-visible styles, dark mode via light-dark().

Verification checkpoint

Load the capstone HTML with only tokens.css, reset.css, and base.css applied. The page should be: legible prose, navigable by keyboard with visible focus rings, correctly rendered in both light and dark mode via the OS preference. No layout yet, no components yet — just clean type on a clean background.

The single rule, reinforced

Every property value in base.css is var(--token). If you catch yourself typing a hex code, stop and add a token to tokens.css first.

Demo — base layer in action

Legible before a single component is written

Only tokens, reset, and base. Typography, color, focus, and dark mode all work. The layout layer adds structure next; components add visual identity. But the page is already readable and accessible to a screen reader.

Try it yourself

Mini-exercise

Toggle your OS to dark mode. Watch the editor preview swap automatically via light-dark(). Confirm contrast stays comfortable in both. No JavaScript. No class toggle.
