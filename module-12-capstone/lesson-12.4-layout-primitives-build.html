Lesson 12.4

Layout Primitives Build

Build every layout primitive the capstone needs. With layout applied on top of base, the page structure is correct at all viewport sizes without a single media query.

What you are building

capstone/css/layout.css containing: .container, .stack (with .stack-lg / .stack-xl variants), .cluster, .grid, .cover. Every primitive exposes custom properties. Zero visual styling.

Container query contexts

Mark the feature-card wrapper and testimonial-slide wrapper with container-type: inline-size so those components can adapt to their container width in Lesson 12.5 — not the viewport.

Verify

With tokens + reset + base + layout applied but no components yet, the page is a structured skeleton: hero centered, features in a responsive grid, pricing cards in a grid, footer clustered. The structure is correct. Nothing is yet styled visually.
