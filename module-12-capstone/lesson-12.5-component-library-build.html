Lesson 12.5

Component Library Build

Build every component Prism needs, using @scope for internal styling and component-scoped custom properties for the variant API.

The component list

  • nav — sticky bar with anchor-positioned dropdown
  • hero — gradient heading, CTA pair
  • feature-card — responsive via container queries
  • pricing-card — three tiers, a "popular" variant using only a custom property override
  • testimonial-slide — carousel slide inside a ::scroll-marker-enabled list
  • faq-item — built on <details>/<summary>
  • cookie-banner — popover API
  • footer — cluster layout

The component contract

Every component: one class at the root, a documented custom property API, @scope for internal element styling, zero JavaScript for state. Variants override only custom properties — never specificity.
