Lesson 12.2

Token System Build

The tokens layer is the first file you write and the only place design decisions live. Build it before anything else touches it.

What you are building

A complete capstone/css/tokens.css file with: OKLCH primitive scales for neutral and brand colors, semantic colors with light-dark(), 9-stop spacing, 6-stop type scale, motion durations and easings, radii, and z-index.

The single rule

Every subsequent file in the capstone references this layer exclusively. If a property value in base.css, components.css, or any other file is not a var(--token) reference, that is a bug — not a convenience.

Verify

Load the tokens file with no other CSS. The page should be entirely unstyled, but every custom property should be readable in DevTools' Computed panel on :root. This is the checkpoint before Lesson 12.3.

View the result

Open capstone/css/tokens.css to see the finished file.

Try it yourself

Mini-exercise

Change --h to 150 (teal) or 25 (red). Watch how the entire scale stays perceptually consistent — L and C values unchanged, only H rotated. This is the single reason OKLCH is architecturally superior to hex for design systems.
