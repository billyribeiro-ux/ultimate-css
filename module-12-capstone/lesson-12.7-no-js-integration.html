Lesson 12.7

No-JS UI Patterns Integration

Wire every interactive UI pattern in Prism without writing a single line of JavaScript. The browser already ships everything we need.

What plugs in

  • Nav dropdown — anchor positioning + popover attribute.
  • FAQ accordion — <details>/<summary> with animated icon and content.
  • Cookie consent banner — popover API; browser manages focus and ESC.
  • Testimonial carousel — native scroll snap + ::scroll-marker dots with @supports fallback.
  • Pricing tab switcher (monthly/yearly) — :has() on a radio group swaps displayed prices via custom-property flip. No JS.

The acceptance check

Tab through the entire capstone. Every interactive element is reachable. Every focus ring is visible. Every open/close pattern responds to Enter, Space, and Escape where appropriate. Disable JavaScript entirely in DevTools. Nothing about the page should change except the live editors on lesson pages.

Demo — FAQ with animated disclosure

Is this really zero JavaScript?

Yes. The browser handles open and close state natively. Keyboard support is free.

What about the animation?

The icon rotates via a CSS transition on details[open] summary::after.

Try it yourself

Mini-exercise

Tab into a <details>, press Space to open it, Space again to close. That is the entire API. Zero lines of JavaScript. Every framework accordion you have ever used is reimplementing this.
