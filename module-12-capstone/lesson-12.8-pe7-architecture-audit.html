Lesson 12.8

PE7 Architecture Audit

A structured review of the complete capstone against every PE7 rule. Any violation is fixed before submission. No exceptions, no excuses.

The audit checklist

  1. Layer order declared first in one line — @layer reset, tokens, base, layout, components, animations;
  2. All six layers present and populated.
  3. No layer boundary violations — run through the seven boundary rules from Lesson 3.9.
  4. No hard-coded values in base, layout, components, or animations — every property value is var(--token).
  5. Logical properties exclusively in reset and base — grep for margin-left, padding-right, etc. The only legitimate hit should be zero.
  6. @scope on every component's internal styling.
  7. Zero !important except the prefers-reduced-motion override in the animations layer.
  8. Every modern / progressive-enhancement CSS feature wrapped in @supports with a documented fallback.
  9. Light and dark mode via light-dark() — no class toggling, no JavaScript.
  10. Keyboard navigation complete — every interactive element reachable by Tab.
  11. Screen reader accessibility — every control has an accessible name; headings form a correct outline.
  12. Contrast ratios pass WCAG AA (4.5:1 for text, 3:1 for large text and non-text) in both light and dark mode.

The auditor's mindset

When you find a violation, do not rationalize it. Fix it. The entire value of this architecture is that every rule has an unambiguous home. "I had to break the boundary because…" is the sentence that introduces technical debt into your codebase.

Verify against the finished capstone

Open the finished capstone page and run the checklist against its stylesheets in capstone/css/. Every item passes. If one does not, the capstone is not done.

Demo — the final layer declaration

/* capstone/css/main.css */

@layer reset, tokens, base, layout, components, animations;

@import url("./reset.css");
@import url("./tokens.css");
@import url("./base.css");
@import url("./layout.css");
@import url("./components.css");
@import url("./animations.css");
