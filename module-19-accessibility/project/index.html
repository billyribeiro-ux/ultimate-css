Test this page

  • Keyboard: Tab through every component. Each interactive element shows a visible focus ring. The accordion toggles open/close with Enter or Space.
  • Screen reader: Enable VoiceOver (Cmd+F5 on Mac) or NVDA (Windows). Navigate to the nav bar — it announces "current page" on Products. The accordion announces "expanded" or "collapsed."
  • Zoom: Set browser zoom to 200%. All components reflow to a single column. No horizontal scrollbar appears. Text remains readable.
  • Forced colors: In DevTools Rendering panel, emulate forced-colors: active. Cards and buttons retain visible borders. The nav bar has a border around the active item.
  • Reduced motion: In DevTools Rendering panel, emulate prefers-reduced-motion: reduce. All transitions and animations are suppressed. The accordion still works but without animation.
  • Touch targets: Inspect any button or link — minimum dimensions are 44x44px. The gap between adjacent interactive elements is at least 8px.
