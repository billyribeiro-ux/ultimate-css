Dark Mode as an Accessibility Feature

Dark mode is not just aesthetic — it reduces eye strain for photosensitive users, helps people with migraines, and saves battery on OLED screens. It is an accessibility feature that happens to also be popular. Here is how to implement it correctly.

Why dark mode is accessibility

Bright screens in dark environments cause eye fatigue. For users with photophobia (light sensitivity, common in migraine sufferers), a white background is physically painful. Dark mode inverts the luminance relationship, reducing total light emission by 60-80% on OLED displays.

The light-dark() function

:root {
  color-scheme: light dark;
}
body {
  background: light-dark(oklch(98% 0.01 275), oklch(15% 0.02 275));
  color: light-dark(oklch(20% 0.03 275), oklch(90% 0.02 275));
}

The light-dark() function picks the first value in light mode and the second in dark mode. Combined with color-scheme: light dark, it respects the user's system preference automatically.

Common dark-mode contrast failures

  • Text too dim: Using oklch(60%) text on oklch(15%) background gives only ~3:1 ratio. Push text to at least oklch(80%) for body copy.
  • Borders invisible: oklch(30%) borders on oklch(15%) background vanish. Use at least oklch(40%) for subtle borders.
  • Links indistinguishable: Standard link blue fails on dark backgrounds. Use oklch(75% 0.15 250) or similar high-lightness variant.

Image adaptation

Full-brightness images on a dark background create painful contrast. A subtle filter reduces this:

@media (prefers-color-scheme: dark) {
  img:not([src*=".svg"]) {
    filter: brightness(0.9) contrast(0.95);
  }
}

Testing both modes

Chrome DevTools: Rendering panel, emulate prefers-color-scheme. Always verify contrast ratios in BOTH modes — a color pair that passes in light mode may fail in dark mode and vice versa.

Try it yourself

Mini-exercise

Toggle your system between light and dark mode (or use DevTools emulation). Verify that every text element passes at least 4.5:1 contrast in both modes. Intentionally break it by setting the dark-mode card text to oklch(55% 0.02 275) — watch the contrast drop below AA. Fix it by pushing the lightness to 80%+.
