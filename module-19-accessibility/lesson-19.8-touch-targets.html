Lesson 19.8 · Inclusive Design

Touch Target Sizing & Spacing

A finger is not a pixel-precise pointer. WCAG 2.5.8 requires a minimum 24x24px target size (AA), with 44x44px as the recommended target. Undersized touch targets are the most common mobile accessibility failure — and the easiest to fix with CSS.

The requirement

WCAG 2.5.8 (Target Size - Minimum) at AA requires 24x24 CSS pixels. The older WCAG 2.5.5 (Enhanced) and Apple/Google guidelines recommend 44x44px. For comfortable touch interaction, 44px is the practical target. The average adult fingertip covers approximately 48px of screen area.

Padding-based enlargement

The simplest approach: add enough padding so the interactive element reaches 44px in both dimensions:

.nav-link {
  display: inline-flex;
  align-items: center;
  min-block-size: 44px;
  min-inline-size: 44px;
  padding: 0.5rem 1rem;
}

The ::after stretch pattern

When you cannot change the visual size of an element (e.g., a small icon button), extend the hit area with an invisible pseudo-element:

.icon-btn {
  position: relative;
}
.icon-btn::after {
  content: "";
  position: absolute;
  inset: -8px; /* extends 8px in every direction */
  /* no background — invisible but clickable */
}

This makes the clickable area larger without changing the visual footprint.

Spacing between targets

Adjacent targets must have enough space that a tap on one does not accidentally activate the other. A minimum gap of 8px between targets is recommended. In a tight toolbar, gap: 0.5rem (8px) between buttons prevents mis-taps.

min-height vs height

Use min-block-size: 44px rather than block-size: 44px. Fixed height can clip content when text wraps or when the user increases font size. Minimum height ensures accessibility without breaking content flow.

Try it yourself

Mini-exercise

Inspect the icon links in DevTools. Hover over the ::after pseudo-element — you will see the extended hit area highlighted. Now remove the ::after rule and try tapping the icons on a touch device (or in mobile simulation). The miss rate increases significantly. Add the rule back and increase inset: -10px to inset: -14px for an even more forgiving target.
