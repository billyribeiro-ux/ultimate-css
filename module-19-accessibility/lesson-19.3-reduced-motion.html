Lesson 19.3 · Inclusive Design

prefers-reduced-motion: The Complete Guide

For people with vestibular disorders, motion on screen can trigger vertigo, nausea, and migraines. The prefers-reduced-motion media query lets us respect their system preference and still deliver a polished experience.

What vestibular disorders are

The vestibular system controls balance and spatial orientation. Disorders of this system affect roughly 35% of adults over 40 to some degree. Parallax scrolling, fly-in animations, auto-playing carousels, and zoom transitions can cause genuine physical discomfort: dizziness, nausea, disorientation.

The three tiers

no-preference: Full animations — the user has not set a preference. reduce: The user has explicitly asked for less motion. Only essential motion should remain. Coming soon: prefers-reduced-transparency for users who struggle with translucent overlays.

The PE7 pattern

In PE7, animations live in their own layer. The reduced-motion override goes at the top of that layer:

@layer animations {
  @media (prefers-reduced-motion: reduce) {
    *, *::before, *::after {
      animation-duration: 0.01ms !important;
      animation-iteration-count: 1 !important;
      transition-duration: 0.01ms !important;
      scroll-behavior: auto !important;
    }
  }
}

This kills all motion globally. Individual components can then opt back into essential motion (opacity crossfades) with explicit overrides below this rule.

What counts as "essential motion"

Safe: opacity crossfades (0 to 1), color transitions, border changes. Unsafe: translateX/Y slides, scale transforms, parallax, rotate, path animations. The heuristic: if removing the animation would confuse the user about what happened, it is essential. A fade-in is essential (it shows new content arrived). A bounce-in is not (the fade alone communicates the same thing).

Testing

In Chrome DevTools: Rendering panel, check "Emulate CSS media feature prefers-reduced-motion." In macOS: System Preferences, Accessibility, Display, Reduce Motion. In Windows: Settings, Ease of Access, Display, Show animations.

Mini-exercise

Enable "Reduce motion" in your OS settings (or use DevTools). Reload the page. The cards should fade in without any horizontal movement. Now add a third card that uses a scale animation (scale(0.8) to scale(1)). In the reduced-motion block, replace the scale with a simple opacity fade.
