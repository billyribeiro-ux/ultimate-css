Forced Colors & High Contrast Mode

Windows High Contrast Mode strips your carefully chosen colors, shadows, and backgrounds — leaving only structure. If your UI relies on color alone to convey meaning, it breaks. The forced-colors media query lets you provide targeted fixes.

What Windows High Contrast Mode does

When forced colors are active, the browser overrides nearly all color-related properties with system colors. Backgrounds become a uniform color (usually black or white), text becomes a high-contrast system color, and custom colors on borders, backgrounds, and shadows are stripped. Only a handful of system colors survive.

The forced-colors media query

@media (forced-colors: active) {
  .card {
    border: 2px solid CanvasText;
  }
  .btn {
    border: 1px solid ButtonText;
  }
}

This query fires when the user has enabled forced colors (Windows High Contrast, or browser-level forced colors). Inside it, you can apply targeted fixes — usually adding borders that would otherwise be invisible.

System colors

These are the colors you can use inside forced-colors: active:

  • Canvas — page background
  • CanvasText — default text color
  • LinkText — link color
  • VisitedText — visited link color
  • ButtonFace — button background
  • ButtonText — button text
  • Field — input background
  • FieldText — input text
  • Highlight — selection/focus background
  • HighlightText — selection/focus text
  • GrayText — disabled text

forced-color-adjust

forced-color-adjust: none tells the browser not to override colors on a specific element. Use sparingly — only for things like syntax-highlighted code blocks where color IS the content. Default is auto (let the browser adjust).

Common fixes

Cards that rely on background color for boundaries need an explicit border. Buttons that use background-only styling (no border) disappear. Icons that use currentColor work well; those using custom fills do not. Add border: 1px solid inside the forced-colors query for any element that has no border in normal mode but needs visual separation.

Try it yourself

Mini-exercise

In Chrome DevTools, go to Rendering and enable "Emulate CSS media feature forced-colors: active." Your cards should still have clear boundaries thanks to the border fix. Now remove the @media (forced-colors: active) block and re-emulate — the cards lose their visual separation entirely.
