Lesson 19.10 · Inclusive Design

CSS + ARIA: Patterns That Work Together

The best pattern: HTML carries the state (via ARIA attributes), and CSS styles the state (via attribute selectors). No extra classes, no duplication. The ARIA attribute is the single source of truth for both assistive technology and visual presentation.

The philosophy

When you use [aria-expanded="true"] as your CSS selector, you are guaranteed that the visual state matches the accessible state. If you use a separate .is-open class, you risk them getting out of sync — the drawer looks open but the screen reader says it is closed. ARIA as the styling hook eliminates this bug class entirely.

[aria-expanded] for open/closed states

.accordion-trigger[aria-expanded="true"] .icon {
  transform: rotate(180deg);
}
.accordion-panel[aria-hidden="false"] {
  display: block;
}
.accordion-panel[aria-hidden="true"] {
  display: none;
}

[aria-current="page"] for navigation

nav a[aria-current="page"] {
  font-weight: 700;
  border-block-end: 2px solid oklch(55% 0.25 275);
  color: oklch(30% 0.15 275);
}

Screen readers announce "current page" — and your CSS highlights it visually. One attribute, two purposes.

[aria-disabled="true"] vs :disabled

:disabled only works on form elements. [aria-disabled="true"] works on any element (divs acting as buttons, custom components). Style both to cover all cases:

[aria-disabled="true"],
:disabled {
  opacity: 0.5;
  cursor: not-allowed;
  pointer-events: none;
}

[aria-invalid="true"] vs :invalid

:invalid fires immediately on empty required fields (before the user has typed anything). [aria-invalid="true"] is set by JavaScript after validation, giving you control over timing. Style it for post-submission error states:

input[aria-invalid="true"] {
  border-color: oklch(55% 0.22 25);
  background: oklch(97% 0.03 25);
}
input[aria-invalid="true"] + .error-msg {
  display: block;
}

[aria-hidden="true"] vs display:none

aria-hidden="true" removes from the a11y tree but keeps the element visible. display:none removes from both. Use aria-hidden for decorative visuals; use display:none when the content should be gone for everyone.
