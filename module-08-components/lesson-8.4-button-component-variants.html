Lesson 8.4

Button Component: Variants via Tokens

The button is the smallest non-trivial component and the one most teams get wrong. Done properly, it is thirty lines of CSS. Done improperly, it is two hundred lines plus a Sass mixin plus a React wrapper. We are doing it properly.

The contract

A button exposes four tokens and nothing else:

.btn {
  --btn-bg:       var(--color-primary);
  --btn-bg-hover: var(--color-primary-hover);
  --btn-color:    var(--color-text-on-primary);
  --btn-border:   transparent;
}

Every declared rule in the component body references these four properties. Not background: blue. Not color: white. Only the tokens. This is what makes variants trivial.

Variants override tokens only

.btn-ghost     { --btn-bg: transparent; --btn-color: var(--color-primary); --btn-border: var(--color-border-strong); }
.btn-danger    { --btn-bg: var(--color-danger); --btn-bg-hover: oklch(52% 0.22 25); }
.btn-secondary { --btn-bg: var(--color-surface-raised); --btn-color: var(--color-text-primary); --btn-border: var(--color-border-strong); }

Notice what variants do not do: redeclare padding, redeclare border-radius, redeclare font-size. Those are structural — they belong to the component, not the variant. A variant that sets padding is a code smell indicating it should be a different component.

States: :hover, :focus-visible, :disabled

Three selectors, three lines:

.btn:hover                 { background-color: var(--btn-bg-hover); }
.btn:focus-visible         { outline: 2px solid var(--color-focus); outline-offset: 2px; }
.btn:disabled,
.btn[aria-disabled="true"] { opacity: .5; cursor: not-allowed; }

Use :focus-visible, not :focus. The former only shows the ring for keyboard users, which is what your designers actually wanted when they asked you to "remove the focus outline". Including [aria-disabled="true"] catches buttons that must remain focusable for screen readers while being logically disabled.

Why the token indirection matters

When a designer asks "can we make the danger button use the new critical-red?", you change one token value in the tokens layer. Every danger button on the site updates. No grep, no replace, no migration PR.
