Lesson 8.1

What Belongs in @layer components

A component is not "styled HTML". A component is a named contract: a public API of CSS custom properties, a protected internal implementation, and a set of states. If your rule doesn't fit that description, it doesn't belong here.

The definition

In the PE7 stack, a component is a CSS object that satisfies four rules:

  1. It has exactly one class name as its entry point — the component's identity. No element selectors at the top level.
  2. It exposes a scoped custom property API. Consumers never set background-color; they set --btn-bg. The component's internals derive from tokens.
  3. It is scoped. Its internals cannot leak outward and its consumers cannot accidentally depend on private descendants.
  4. It owns its states — :hover, :focus-visible, :disabled, [aria-expanded], :has() conditions — not JavaScript.

Why utilities are not components

A utility class like .mt-4 changes exactly one declaration. It has no states, no internals, no API. Utilities belong in a utilities layer above components. Mixing them is how you end up with .btn.mt-4.bg-red.flex — a class list that screams "I gave up on naming things". Components and utilities serve different purposes and live in different layers.

The "one class name" discipline

When a component's public entry is a single class, refactoring is trivial: rename the class, every consumer breaks loudly. When the entry is article.post > header .title, refactoring means grepping the entire codebase for four selectors in order. The one-class rule is not dogma — it is the thing that makes the component survive its second year.

The scoped custom property API

Every component declares its knobs at the root:

.btn {
  --btn-bg:       var(--color-primary);
  --btn-bg-hover: var(--color-primary-hover);
  --btn-color:    var(--color-text-on-primary);
  background-color: var(--btn-bg);
}

Variants then only override the tokens:

.btn-danger { --btn-bg: var(--color-danger); --btn-bg-hover: oklch(52% 0.22 25); }

This is the single most important habit in the entire components layer. It means there is exactly one place the button's visual identity is defined, and exactly one way to extend it.

Mini-exercise

Pick one component you have already shipped in a real project. Write down its public API as a list of custom properties — no more than six. If you cannot, the component is not yet a component; it is a snapshot of CSS that happens to work.
