Module 8 · Components

@layer components: Scoped UI & Modern Selectors

Components are the layer where named UI patterns live. This module teaches the selectors and scoping primitives that finally make CSS components as disciplined as their JavaScript counterparts — @scope, :has(), anchor positioning, popover, customizable selects, and scroll-driven navigation.

Module goal

Build real components whose contract is a small set of scoped custom properties, whose internals are protected by @scope, and whose behavior uses modern selectors instead of JavaScript class toggling. After this module you will stop reaching for a framework for the 80% of UI that the platform already handles.
