Lesson 8.8

Progressive enhancement

Customizable Select: appearance: base-select

For thirty years, every design system has reinvented the <select> because the native one couldn't be styled. The web platform has finally fixed it. appearance: base-select gives you a native select you can style like any other element — options, popup, chevron, focus ring, all of it.

The old problem

Native <select> was a black box. You could style the closed button a little; the dropdown panel was controlled entirely by the OS. So every design system built a div role="combobox" replacement — with its own focus management, keyboard handling, ARIA contract, virtualization, and accessibility bugs. Thousands of engineering hours poured into a custom control that is still worse than the native one.

The new primitive

select { appearance: base-select; }
select::picker(select) { /* the popup panel */ }
option { /* the option items */ }
option:hover, option:checked { /* states */ }

appearance: base-select opts the element into the new fully-stylable rendering. The browser still owns keyboard handling, focus trapping, ESC dismissal, and ARIA — you just paint over it.

The pseudo-elements

  • ::picker(select) — the popup panel itself. Size, background, shadow, animation all live here.
  • ::picker-icon — the chevron/arrow on the button.
  • option — now styleable like any element, including hover and :checked.

Browser support

Chrome 135+ and Edge 135+ only as of early 2026. Safari and Firefox have not shipped. Always wrap in @supports (appearance: base-select). The fallback is the default native select — which works fine; it just uses the OS rendering.

Live demo — styled native select

In Chrome 135+ the dropdown picks up the custom styles. In other browsers the native select still works.

Try it yourself

Mini-exercise

Count the lines of custom select code in your current project (the framework one you built to replace <select>). Multiply by engineering hours per line. That's the technical debt appearance: base-select is about to retire.
