Challenge 4 · Intermediate

Add Dark Mode in Under 20 Lines

You have a fully styled light-mode page. Add complete dark mode support using light-dark() and color-scheme — in 20 lines of CSS or fewer.

The scenario

The page below is complete and polished in light mode. Your job: make it look equally polished in dark mode by adding no more than 20 lines of CSS. The trick is that light-dark() lets you define both modes inline, and color-scheme tells the browser which modes you support.

Constraints

  • Maximum 20 lines of CSS added (the color-scheme line counts)
  • Must use light-dark() function for all color switches
  • Must declare color-scheme: light dark on :root
  • No @media (prefers-color-scheme: dark) allowed
  • Dark mode must look intentional, not just "inverted"
  • Form inputs and buttons must also adapt

Hint

The approach: (1) Add color-scheme: light dark to :root. (2) Replace hardcoded colors in the existing rules with light-dark(lightValue, darkValue). Each color you wrap in light-dark() counts as modifying that line, not adding a new one. The key is identifying which properties actually need to change — background, text color, card surface, shadow opacity, border color, and accent color. That's about 8-10 properties.
