Challenge 3 · Intermediate

Responsive Layout, Zero Media Queries

Build a 4-section page that works beautifully from 320px to 2560px — without a single @media rule. Only intrinsic sizing: auto-fit, min(), clamp(), and flex-wrap.

The scenario

You're building a landing page with four distinct sections: a hero, a feature grid, a testimonial row, and a footer. Each must reflow naturally at any viewport width. The constraint is absolute: zero @media queries. The layout must be entirely intrinsic — it adapts because of how CSS calculates sizes, not because you told it to change at a breakpoint.

Constraints

  • Zero @media queries — not even for font sizes
  • Must work from 320px to 2560px viewport width
  • Hero: centered text with fluid type, constrained max-width
  • Features: 3-column grid that collapses to 1 column on narrow screens
  • Testimonials: horizontal scroll or wrap depending on space
  • Footer: multi-column that stacks naturally
  • Allowed tools: auto-fit, min(), max(), clamp(), flex-wrap, minmax()
