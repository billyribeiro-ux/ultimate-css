Build an Accessible Modal

Build a modal dialog with enter/exit animation, backdrop blur, keyboard dismissal, visible focus indicators, and reduced-motion support — all without JavaScript for open/close mechanics.

Requirements

  • Open/close: Use the Popover API (popover attribute) or <dialog> with ::backdrop — no JS needed for toggle
  • Enter animation: Modal scales up + fades in using @starting-style
  • Exit animation: Modal scales down + fades out (requires transition-behavior: allow-discrete and overlay transition)
  • Backdrop: Dark overlay with backdrop-filter: blur()
  • Close on Escape: Built-in with popover/dialog
  • Close on backdrop click: Built-in with popover (light-dismiss)
  • Focus indicators: Visible, high-contrast focus rings on all interactive elements
  • ARIA: Proper role, aria-labelledby, aria-describedby
  • Reduced motion: Instant open/close, no animation

Constraints

  • Zero JavaScript for open/close (popover API or dialog with form method)
  • Enter AND exit must both animate (the hard part)
  • Must use @starting-style for the entry state
  • Must include transition-behavior: allow-discrete for the exit
  • All colors in OKLCH
  • Must pass basic accessibility: focus management, ARIA labels, screen-reader-friendly

Hint

The key to exit animation: [popover] { transition: opacity 200ms, transform 200ms, display 200ms, overlay 200ms; transition-behavior: allow-discrete; }. The overlay transition keeps the element in the top layer during exit. @starting-style goes inside [popover]:popover-open or as a separate block. For the backdrop: [popover]::backdrop { backdrop-filter: blur(4px); transition: opacity 200ms, display 200ms; transition-behavior: allow-discrete; }.
