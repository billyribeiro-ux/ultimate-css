Challenge 9 · Expert

Draw a Scene with One Element

Create a landscape scene — sun, sky, mountains, and water — using a SINGLE <div> element. Only ::before, ::after, box-shadow, and gradients allowed.

The challenge

CSS art pushed to its limit: a recognizable landscape using one HTML element. You have three "layers" — the element itself, ::before, and ::after. For additional shapes, you must use box-shadow (which can create unlimited copies of a shape) and multiple backgrounds with gradients.

Constraints

  • Only ONE <div> element in HTML — no additional elements
  • Only ::before and ::after pseudo-elements allowed
  • No external images, SVGs, or URLs
  • Must use gradients for sky, mountains, and water
  • Must use box-shadow for the sun (and optionally clouds)
  • The scene must be recognizable as a landscape
  • Colors must use OKLCH

Techniques available

  • background: linear-gradient(), radial-gradient() — layered, for sky and terrain
  • box-shadow — for duplicating shapes (sun, clouds, reflections)
  • ::before / ::after — for additional shaped elements (mountains, sun disc)
  • border-radius — for rounded shapes
  • clip-path — for mountain peaks (polygon)

The box-shadow trick

Each box-shadow value creates a clone of the element's shape at an offset. A small circle (border-radius: 50%) with multiple box-shadow values becomes many circles — clouds, stars, or scattered shapes. The syntax for each clone: offsetX offsetY blurRadius spreadRadius color.

/* One small circle becomes 3 clouds */
.element::before {
  width: 2rem;
  height: 2rem;
  border-radius: 50%;
  background: oklch(95% 0.01 260 / 0.8);
  box-shadow:
    1.5rem 0 0 0.5rem oklch(95% 0.01 260 / 0.6),
    3rem -0.5rem 0 0.3rem oklch(95% 0.01 260 / 0.5),
    -1rem 0.3rem 0 0.2rem oklch(95% 0.01 260 / 0.4);
}

Multiple backgrounds

A single element can have unlimited background layers. Each layer is a gradient that covers a specific portion of the element. The first gradient listed is on top, the last is on the bottom. Use transparent stops to let lower layers show through:

background:
  /* Top: sky gradient */
  linear-gradient(180deg, skyblue 0%, lightyellow 40%, transparent 40%),
  /* Bottom: water */
  linear-gradient(180deg, transparent 60%, darkblue 60%, navy 100%),
  /* Base: horizon glow */
  radial-gradient(ellipse at 70% 40%, gold, transparent 30%);

Approach strategy

Plan your three layers: (1) The .scene div itself handles sky + water via stacked gradients. (2) ::before becomes the sun — a small positioned circle with box-shadow for glow and cloud clones. (3) ::after becomes the mountains — a large shape using clip-path: polygon() with a dark gradient fill. Work from back to front.

Target — single-element landscape

One <div>, zero images — only CSS gradients, box-shadow, and clip-path

Your challenge

Hint

The main .scene div handles sky + water via layered gradients (top = sky blue, middle = horizon glow, bottom = water blue). ::before is a small circle (border-radius: 50%) positioned top-right for the sun, with box-shadow for the glow and cloud shapes. ::after covers the bottom portion with clip-path: polygon(...) creating mountain peaks, colored in dark greens/browns.
