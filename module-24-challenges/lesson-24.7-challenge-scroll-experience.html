Challenge 7 · Advanced

Build a Scroll-Driven Story

Build a cinematic scrolling page where each section reveals with a different animation, a progress bar fills as you scroll, and a sticky heading updates. All using animation-timeline: view() and scroll().

Requirements

  1. Progress bar: A thin bar at the very top fills from 0% to 100% width as you scroll the page. Uses animation-timeline: scroll().
  2. Section reveals: Four content sections, each with a different entrance animation:
    • Section 1: fade-up (translateY + opacity)
    • Section 2: slide-left (translateX + opacity)
    • Section 3: scale (scale + opacity)
    • Section 4: rotate-in (rotate + opacity)
    Each uses animation-timeline: view().
  3. Sticky heading: A position-sticky element near the top that persists as you scroll.
  4. Fallback: Wrap scroll-driven features in @supports (animation-timeline: view()) so unsupported browsers see static content.

Constraints

  • Pure CSS — zero JavaScript
  • All scroll animations must use the Scroll-Driven Animations API (animation-timeline)
  • Must include @supports fallback for every scroll-driven feature
  • Must respect prefers-reduced-motion
  • Content must be readable even without the animations

Target — scroll behavior preview

Hint

For the progress bar: @keyframes fill { from { width: 0% } to { width: 100% } } with animation: fill linear; animation-timeline: scroll();. For section reveals: define separate @keyframes for each animation type, then apply with animation-timeline: view(); animation-range: entry 0% cover 40%;. The animation-range controls when in the scroll the animation plays.
