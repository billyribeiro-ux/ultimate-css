Challenge 1 · Beginner

Fix the Specificity War

You've inherited a stylesheet where 6 rules conflict with each other. Colors are wrong, spacing is off, fonts are overridden. Your mission: fix all 6 conflicts using ONLY @layer — no selector changes, no !important.

The scenario

A previous developer wrote CSS in no particular order. A card component has rules scattered across a utility file, a component file, and inline overrides. The result: the card looks nothing like the design. Your job is to wrap the existing rules in @layer declarations to establish the correct cascade order — without touching any selectors or adding !important.

Constraints

  • You may ONLY add @layer declarations and the layer order statement
  • You may NOT change any selector
  • You may NOT add !important
  • You may NOT delete any existing rule
  • You may NOT add new property declarations
  • All 6 conflicts must resolve to match the target

Target result

When correctly layered, the card should show:

  • Background: the teal color from the component layer
  • Text color: white from the component layer
  • Padding: the larger padding from the component layer
  • Border-radius: the rounded corners from the component layer
  • Font-size: the size from the base layer
  • Box-shadow: the shadow from the utility layer

Target — correctly layered card

Target rendering

Your challenge

Hint

The layer order statement goes at the very top: @layer base, utilities, components; — this establishes priority regardless of source order. Then wrap each group in its corresponding @layer name { ... } block. The component layer wins because it's declared last in the order.
