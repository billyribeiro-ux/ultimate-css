Challenge 6 · Advanced

Orchestrate a 5-Step Animation

Build a hero section entrance animation with 5 sequential steps — pure CSS, using @starting-style and staggered transition-delay. No JavaScript, no @keyframes required (though allowed).

The sequence

  1. Step 1: Background gradient fades in (0ms delay)
  2. Step 2: Headline slides up + fades in (100ms delay)
  3. Step 3: Subheadline slides up + fades in (200ms delay)
  4. Step 4: CTA buttons scale in + fade in (300ms delay)
  5. Step 5: Decorative element rotates in + fades in (500ms delay)

How @starting-style works for entrance animations

Before @starting-style, creating page-load animations required @keyframes with animation-fill-mode: backwards. The new approach is simpler: you define where the element ends up (its normal CSS), and @starting-style defines where it starts FROM. The browser automatically transitions between these states when the element first renders.

The syntax is either nested inside the element's rule or as a standalone block:

.element {
  opacity: 1;
  transform: translateY(0);
  transition: opacity 500ms, transform 500ms;

  @starting-style {
    opacity: 0;
    transform: translateY(1.5rem);
  }
}

Staggering with transition-delay

Each element in the sequence gets an increasing transition-delay. The first element has 0ms, the second 100ms, the third 200ms, and so on. The delay applies to the transition FROM the @starting-style state, so each element waits its turn before beginning its entrance.

Constraints

  • Pure CSS — zero JavaScript
  • Use @starting-style for initial (hidden) state
  • Stagger using transition-delay
  • Each element transitions from hidden to visible on page load
  • Must respect prefers-reduced-motion (instant reveal, no animation)
  • Total sequence should complete in under 1.5 seconds
  • Use cubic-bezier(0.16, 1, 0.3, 1) for a natural ease-out feel

Reduced motion

Users who prefer reduced motion should see everything instantly — no animation, no stagger. Wrap your transitions in a check: @media (prefers-reduced-motion: no-preference) { ... } or set transition-duration: 0s inside a prefers-reduced-motion: reduce query.

Hint

The pattern for each element: set its final state in normal CSS (opacity: 1, transform: none). Then in @starting-style, define the hidden state (opacity: 0, transform: translateY(1.5rem)). Add transition: opacity 500ms, transform 500ms with increasing transition-delay values. For the hero background, animate from opacity: 0 on the whole section. The reduced-motion query should set transition-duration: 0s on everything.

Example structure

.hero {
  opacity: 1;
  transition: opacity 600ms ease;
  transition-delay: 0ms;
  @starting-style { opacity: 0; }
}

.hero h1 {
  opacity: 1;
  transform: translateY(0);
  transition: opacity 500ms ease, transform 500ms cubic-bezier(0.16, 1, 0.3, 1);
  transition-delay: 100ms;
  @starting-style {
    opacity: 0;
    transform: translateY(1.5rem);
  }
}

/* Repeat for .subtitle (200ms), .cta-group (300ms), .deco (500ms) */

@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    transition-duration: 0s !important;
    transition-delay: 0s !important;
  }
}
