Challenge 12 · Boss

The Final Boss

Build a complete single-page portfolio site from scratch — hero with parallax, scroll reveals, project grid with hover effects, contact form with validation, dark mode, fully responsive, fully accessible — all in under 500 lines of CSS. Zero JavaScript.

The ultimate test

This challenge combines every technique from the entire course into one deliverable. You're building a production-quality portfolio page that would impress a hiring manager — not because of flashy gimmicks, but because of the architectural quality of the CSS.

Required sections

  1. Hero: Full-viewport hero with parallax scroll effect, fluid heading, entrance animation via @starting-style
  2. About: Two-column text+skills layout that reflows to single column, reveals on scroll using animation-timeline: view()
  3. Projects: Auto-fit grid of project cards with hover scale + shadow transition, gradient placeholders for images
  4. Testimonials: Horizontal scroll or wrap section with quote cards
  5. Contact: Form with CSS-only validation (required fields, email pattern, visual feedback)

Required features

  • Dark mode: Toggle via color-scheme + light-dark() throughout
  • Responsive: 320px to 2560px, zero media queries (intrinsic only — or minimal media queries for the toggle)
  • Accessible: Focus indicators, reduced-motion support, semantic HTML, proper contrast
  • Animated: Entry animations, scroll reveals, hover effects — all respecting prefers-reduced-motion
  • Architecture: PE7 layers (@layer tokens, reset, base, layout, components, animations, utilities)

Constraints

  • Under 500 lines of CSS (excluding the HTML)
  • Zero JavaScript
  • No external images — gradients and shapes only
  • PE7 architecture with proper @layer organization
  • Must pass: keyboard navigation, screen reader basics, color contrast

Target — portfolio preview

Your challenge

Strategy

Work in layers: (1) Set up the @layer order and tokens first. (2) Add reset + base typography. (3) Build the layout — the portfolio is a single-column stack. (4) Style each component section. (5) Add animations last — entrance via @starting-style, scroll reveals via animation-timeline: view(), hover effects on cards. (6) Add dark mode by replacing token values with light-dark(). (7) Add reduced-motion support. Count your lines — stay under 500.
