Clone a Real UI from Memory

Study the simplified music player interface below, then build it from scratch. Sidebar, album grid, player bar — the complete layout. Use PE7 architecture: proper layers, tokens, and @scope.

The scenario

Below is a simplified music player interface. Study it carefully — the sidebar navigation, the album grid content area, and the persistent player bar at the bottom. Then build it from scratch using PE7 architecture.

Constraints

  • Must use @layer for PE7 layer ordering (tokens, reset, base, layout, components)
  • Must define tokens as custom properties
  • Must use @scope for at least one component boundary
  • Layout must use CSS Grid for the overall page structure
  • Album grid must use auto-fit for responsive columns
  • Player bar must be fixed at the bottom
  • No external images — use gradients for album art placeholders
  • Dark theme (the music player aesthetic)

Target — music player UI
