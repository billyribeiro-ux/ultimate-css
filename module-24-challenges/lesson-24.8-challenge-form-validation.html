Challenge 8 · Advanced

Complete Form Validation, Zero JS

Build a registration form with real-time validation styling, error messages, a password strength meter, and a submit button that's visually disabled until valid — all without a single line of JavaScript.

Requirements

  • Fields: Name (required, min 2 chars), Email (required, valid email), Password (required, min 8 chars), Confirm password
  • Real-time styling: Green border + checkmark indicator when valid, red border + error message when invalid (only after user interaction — use :user-valid / :user-invalid or :not(:placeholder-shown):valid)
  • Password strength: A visual meter that changes width/color based on pattern matching (short = red, medium = amber, strong = green) using CSS attribute selectors on the pattern
  • Submit button: Visually disabled (grayed out, no pointer events) until ALL fields are valid — use :has() on the form

Constraints

  • Zero JavaScript
  • Validation must use HTML5 attributes (required, pattern, type="email", minlength)
  • Visual feedback must use CSS pseudo-classes (:valid, :invalid, :placeholder-shown, :has())
  • Error messages must be hidden until the field is interacted with and invalid
  • The form must be accessible (proper labels, visible focus indicators)

Target — validated form states

Hint

Key patterns: .error, .success { display: none; }. Then input:not(:placeholder-shown):invalid ~ .error { display: block; } and input:not(:placeholder-shown):valid ~ .success { display: block; }. For the submit button: .register-form:has(input:invalid) .submit-btn { opacity: 0.5; pointer-events: none; }. The :not(:placeholder-shown) ensures feedback only appears after the user has typed something.
