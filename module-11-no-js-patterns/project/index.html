Module 11 · Project

No-JS Pattern Library

Six production UI patterns, one page, zero JavaScript. Accordion, tabs, modal, TOC, carousel, dropdown. Open DevTools and search the HTML for <script> — you will not find one.

The brief

Deliver a single HTML file that demonstrates every pattern from Module 11. Each pattern must be keyboard-accessible and work with JavaScript disabled. Modern-browser enhancements (popover animation, :target-current, scroll markers) are wrapped in @supports.

Deliverable

Verify three things: (1) the page works with JavaScript disabled in the browser — every pattern still functions; (2) every interactive element is reachable and usable by keyboard alone; (3) screen-reader announcements are sensible on the accordion and modal. That is your acceptance test.
