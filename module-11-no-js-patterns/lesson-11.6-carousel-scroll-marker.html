Lesson 11.6

Progressive enhancement

Carousel: scroll-marker + snap

Every carousel library ever shipped reinvents the same four things: a scroll container, snap alignment, navigation dots, prev/next buttons. CSS now provides all four primitives. A production carousel is about fifteen lines of CSS and zero lines of JavaScript.

The base layer (universal)

.carousel {
  display: flex;
  gap: 1rem;
  overflow-x: auto;
  scroll-snap-type: x mandatory;
}
.carousel > * {
  flex: 0 0 90%;
  scroll-snap-align: center;
}

Baseline since 2019. Works in every browser. Scrolls horizontally, snaps to each slide, supports touch and trackpad natively. This alone is a usable carousel.

The enhancement layer

.carousel { scroll-marker-group: after; }
.carousel > *::scroll-marker {
  content: "";
  inline-size: .6rem; block-size: .6rem;
  border-radius: 50%;
  background: var(--color-border-strong);
}
.carousel > *::scroll-marker:target-current {
  background: var(--color-primary);
}
.carousel::scroll-button(left),
.carousel::scroll-button(right) {
  content: "";
  /* style prev/next buttons here */
}

scroll-marker-group: after tells the browser "render a marker group after this scroller". Each snap child contributes a ::scroll-marker pseudo-element — the dots. ::scroll-button(left) and ::scroll-button(right) generate prev/next buttons that are keyboard-focusable and automatically disabled at the ends.

The :target-current dot

The marker for the currently-snapped slide automatically matches :target-current, so you get the active-dot state without writing any tracking code. This is the same primitive we used for the TOC scrollspy in Lesson 11.5, applied to carousel slides.

Graceful degradation

Wrap the marker and button rules in @supports (scroll-marker-group: after). In non-supporting browsers you still have a perfectly usable scroll-snap carousel — just without dots or explicit buttons. The user can still swipe, arrow-key, and scroll. Nothing is broken.

Browser support

Scroll snap: baseline. scroll-marker-group, ::scroll-marker, ::scroll-button(): Chrome 135+, Edge 135+. Safari and Firefox pending. Always the @supports wrap.
