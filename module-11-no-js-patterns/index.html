Module 11 · No-JS patterns

No-JS UI Patterns: What CSS Can Do Alone

This module is not anti-JavaScript. It is pro-platform. For six common UI patterns — accordions, tabs, modals, tables of contents, carousels, dropdowns — the native web platform now does the job better than any framework. This module shows you exactly which patterns, and exactly where the line still sits.

Module goal

Be able to look at any UI requirement and know, within five seconds, whether it belongs in CSS, in HTML, or in JavaScript. Then build each pattern with the minimum tool that meets the bar.
