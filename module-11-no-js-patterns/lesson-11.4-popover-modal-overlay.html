Lesson 11.4

Modal: popover + ::backdrop

The popover attribute is the single biggest no-JS win of the last five years. It promotes any element to the top layer, handles ESC dismissal, light-dismiss, focus trapping, and keyboard navigation — for free. A modal that used to be 200 lines of JavaScript is now one HTML attribute.

The minimum modal

<button popovertarget="my-modal">Open</button>
<div id="my-modal" popover="auto">
  <h2>Modal title</h2>
  <p>Modal body.</p>
  <button popovertarget="my-modal" popovertargetaction="hide">Close</button>
</div>

That's the whole thing. The button opens the popover. ESC closes it. Click outside closes it. Focus is managed. The element is rendered above every ancestor's stacking context. No JavaScript.

popover="auto" vs popover="manual"

  • popover="auto" (default when you write just popover) — light-dismiss on outside click, ESC dismissal, only one auto popover open at a time. Perfect for modals and dropdowns.
  • popover="manual" — no light-dismiss, you control visibility via the popovertarget buttons. Use for persistent toolbars.

Styling the backdrop

[popover]::backdrop {
  background: oklch(0% 0 0 / .5);
  backdrop-filter: blur(4px);
}

The ::backdrop pseudo-element exists only while the popover is open and sits between it and the rest of the page. Style it as you would any element.

Smooth enter/exit

Popovers use display: none when closed, which historically was not transitionable. The new allow-discrete flag fixes this:

[popover] {
  opacity: 1; transform: translateY(0);
  transition:
    opacity 250ms,
    transform 250ms,
    display 250ms allow-discrete,
    overlay 250ms allow-discrete;
}
[popover]:not(:popover-open) { opacity: 0; transform: translateY(.5rem); }
@starting-style {
  [popover]:popover-open { opacity: 0; transform: translateY(.5rem); }
}

Browser support

popover: Chrome 114+, Safari 17+, Firefox 125+. Baseline. @starting-style + allow-discrete for smooth exit: Chrome 117+, Safari 17.5+, Firefox 129+. Without these, the popover still opens and closes — it just snaps instead of fading.
