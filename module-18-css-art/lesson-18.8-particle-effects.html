Lesson 18.8 · Particles

CSS Particle Systems

Four distinct particle effects — confetti bursts, fireflies, snowfall, and fireworks — all built with CSS animations, box-shadow multiplication, and staggered delays. Triggered on :hover or :active without JavaScript.

Confetti burst

Multiple box-shadow values on a single element, each offset randomly. On trigger, the shadows animate outward from the center using @keyframes that transition the shadow offsets from (0, 0) to their final positions while fading opacity.

Fireflies

Small elements with a box-shadow glow that pulses in opacity. Each firefly has a unique animation delay and slightly different timing, creating an organic flickering effect across the container.

Snowfall

Elements falling via translateY from top to bottom, with a gentle horizontal sine-wave drift achieved by combining two animations: one vertical (linear) and one horizontal (ease-in-out alternating).

Firework

A central dot that "launches" upward (translateY keyframe), then at the apex spawns a radial burst using box-shadow values that animate outward in a circular pattern while changing color and fading.

Challenge

Create a "rain" effect: thin vertical lines (2px wide, 15px tall) falling at a slight angle using skewX(-5deg). Add splash effects at the bottom using small radial box-shadow bursts that trigger on a delayed keyframe. Make the rain responsive to a checkbox that switches between "light drizzle" (fewer, slower particles) and "heavy storm" (more, faster, with wind angle).
