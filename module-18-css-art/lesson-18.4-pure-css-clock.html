Lesson 18.4 · CSS Clock

A Working Analog Clock in Pure CSS

A clock face with rotating hands driven entirely by CSS animations. The second hand ticks 60 steps per revolution, the minute hand completes a cycle in 3600 seconds, and the hour hand in 43200 seconds. Negative animation-delay syncs each hand to the current time.

The animation trick

CSS animations run continuously from page load. By setting a negative animation-delay, we jump the animation forward to the correct position. If the current time is 3:15:45, the second hand needs animation-delay: -45s, the minute needs -945s (15 minutes and 45 seconds), and the hour needs -11745s (3 hours, 15 minutes, 45 seconds in seconds).

Stepped vs smooth

The second hand uses steps(60) for a ticking effect. The minute and hour hands use linear for smooth continuous motion. You could make the minute hand step too with steps(3600).

The clock face

Hour markers are created with a conic-gradient — 12 thin colored slices with transparent gaps between them. Minute ticks could be added with a second conic-gradient layer of 60 even thinner slices.

Dark and light themes

Using prefers-color-scheme, the clock face switches between a light dial with dark hands and a dark dial with light hands, demonstrating how custom properties make theming trivial.

Calculating animation-delay

The formula for syncing to current time: take the current hours (0-11), minutes, and seconds. For the second hand: animation-delay: -(seconds)s. For the minute hand: animation-delay: -(minutes * 60 + seconds)s. For the hour hand: animation-delay: -(hours * 3600 + minutes * 60 + seconds)s. A one-line inline style attribute sets these at page load.

The center pivot

Each hand uses transform-origin: bottom center so rotation happens around the base. The hand is positioned with its bottom edge at the clock center using position: absolute; bottom: 50%. The center dot covers the pivot point for a polished look.

Adding minute tick marks

A second conic-gradient layer with 60 thinner slices (1deg each) can represent minute markers. Use mask: radial-gradient() to limit the ticks to just the outer ring, keeping the face interior clean.

Responsive sizing

Defining the clock size as a custom property (--clock-size) and deriving all hand lengths as percentages of that value makes the entire clock scalable. Container queries can then resize the clock within card layouts.

Challenge
