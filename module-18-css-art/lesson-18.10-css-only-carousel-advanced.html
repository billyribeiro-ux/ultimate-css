Lesson 18.10 · Carousel

The Advanced CSS-Only Image Carousel

A full-featured carousel using scroll-snap for positioning, CSS ::scroll-marker dots and ::scroll-button prev/next arrows (with @supports fallback), auto-play via animation paused on hover, crossfade transitions, a thumbnail strip, and a fullscreen view using popover.

Scroll-snap foundation

The carousel track is a horizontal flex container with scroll-snap-type: x mandatory and overflow-x: auto. Each slide has scroll-snap-align: start so it always lands perfectly aligned.

Navigation dots and buttons

Modern CSS introduces ::scroll-marker and ::scroll-button() pseudo-elements for native scroll navigation. We use @supports to detect these and fall back to anchor-based navigation with hidden radio inputs for older browsers.

Auto-play with pause on hover

A @keyframes animation scrolls through slides by animating transform: translateX() on the track. The :hover state sets animation-play-state: paused, giving users control.

Crossfade via opacity

When scroll-driven animations are available, each slide's opacity can be tied to its scroll position, creating a crossfade instead of a slide effect. This uses animation-timeline: scroll().

Thumbnail strip

A row of miniature versions below the main carousel. Each thumbnail is an anchor link to its corresponding slide, styled with a highlighted border when the slide is in view.

Fullscreen via popover

Each slide contains a button with popovertarget pointing to a [popover] element that displays the slide content at full viewport size, dismissible by clicking outside or pressing Escape.
