Lesson 18.2 · Animated Icons

Animated SVG-Free Icons

Every icon in this lesson is built from a single element (plus its two pseudo-elements at most). No SVG, no icon fonts, no images. Just borders, backgrounds, clip-paths, and @keyframes.

The constraint

One element. Two pseudo-elements. That is the budget. The element itself provides one shape (via border, border-radius, background). ::before and ::after provide two more. Between them, you can construct any icon that decomposes into three or fewer geometric primitives — which covers almost every UI icon in existence.

Animation approach

Each icon has a resting state and an active state. The transition between them uses either transition (for simple two-state morphs) or @keyframes (for multi-step sequences). Hover or checkbox state triggers the animation.

Why not SVG?

In production, SVG is better for icons. This exercise exists to prove you understand CSS geometry, transforms, and animation deeply enough to reconstruct any shape from first principles. That understanding makes you better at styling SVG too.

Challenge
