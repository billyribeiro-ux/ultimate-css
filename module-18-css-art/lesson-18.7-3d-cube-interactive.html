Lesson 18.7 · 3D Transforms

Interactive 3D CSS Cube

Six faces positioned with rotateX/Y/Z and translateZ inside a preserve-3d container. Auto-rotation keyframes spin the cube continuously, while checkbox controls toggle rotation, explode the faces outward, and switch to wireframe mode.

Setting up 3D space

The parent container needs perspective: 800px to create depth. The cube wrapper uses transform-style: preserve-3d so child elements exist in true 3D space rather than being flattened.

Positioning six faces

Each face starts as a square, then is rotated to its position: front (no rotation), back (rotateY 180deg), left (rotateY -90deg), right (rotateY 90deg), top (rotateX 90deg), bottom (rotateX -90deg). Each also gets translateZ(half-width) to push it outward from the center.

Auto-rotation

A keyframe animates rotateX and rotateY through 360 degrees. The animation duration controls speed (8-12s is visually pleasing). A checkbox with :checked can toggle animation-play-state between running and paused.

Explode and wireframe modes

Explode view increases translateZ on each face via a transition. Wireframe mode sets background: transparent and adds a visible border. Both are toggled with CSS-only checkboxes.

Perspective distance

The perspective value controls how dramatic the 3D effect appears. Lower values (300-500px) create strong foreshortening — faces closer to the viewer appear much larger. Higher values (1000-2000px) produce a flatter, more isometric look. 800px is a good middle ground for a cube this size.

Backface visibility

By default, backface-visibility: visible means you see the back of each face when it rotates away. Setting it to hidden makes faces disappear when facing away, which is useful for card-flip effects but looks odd on cubes where you expect to see through to inner faces.

Face content and styling

Each face can contain any HTML content — text, images, nested layouts. The content rotates with the face naturally. Using different OKLCH hues for each face (spaced 60 degrees apart on the hue wheel) creates a harmonious palette that helps distinguish faces during rotation.

CSS-only controls with :has()

The :has() selector lets us place checkboxes anywhere in the DOM and still affect the cube. The pattern .demo:has(#checkbox:checked) .cube selects the cube when the checkbox is checked, regardless of their DOM relationship. This is more flexible than the older sibling combinator approach.

Performance considerations

3D transforms are GPU-accelerated in all modern browsers. However, preserve-3d contexts create new stacking contexts and can interfere with overflow: hidden on parent elements. Test 3D effects on mobile where GPU memory may be more constrained.

Try it yourself

Challenge

Transform the cube into a dodecahedron (12 pentagonal faces). You will need to calculate the rotation angles for each face using the golden ratio. Alternatively, make a simpler octahedron (8 triangular faces) using clip-path to create the triangles. Add a fourth checkbox that switches between cube/octahedron shapes by transitioning all face transforms simultaneously.
