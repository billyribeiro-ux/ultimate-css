Lesson 18.9 · Text Effects

Text Animation Showcase

Eight distinct text animation techniques: gradient text, glitch, wave, typing loop, 3D extrude, reveal wipe, outline-to-fill, and scramble. Each demonstrates a different CSS capability — from background-clip to text-shadow stacking to clip-path transitions.

1. Gradient text

Apply a gradient background to the text element, then use -webkit-background-clip: text and color: transparent to reveal the gradient through the letterforms. Animate background-position for a flowing effect.

2. Glitch effect

Layer ::before and ::after with the same text content but offset clip-path slices and contrasting colors. Animate the clip-path rapidly for a digital distortion look.

3. Wave

Wrap each character in a <span> and stagger animation-delay on a translateY keyframe. The wave propagates through the word letter by letter.

4. Typing and deleting

A fixed-width container with overflow: hidden and border-right (cursor). The width animates from 0 to full via steps(n) matching character count, then reverses.

5. 3D extrude

Stack multiple text-shadow values, each offset by 1px more in X and Y, with progressively darker colors. The result resembles extruded 3D lettering.

6. Reveal wipe

A clip-path: inset() animation that reveals text from left to right (or any direction) by animating the clip edge from 100% to 0%.

7. Outline to fill

-webkit-text-stroke provides the outline. On hover, transition color from transparent to solid, filling the letters while the stroke remains.

8. Scramble

Using ::before with content that swaps rapidly through characters via keyframes, settling on the final text. Pure CSS version uses a multi-step animation with discrete content values.

Try it yourself

Challenge

Create a ninth effect: "neon glow." Use text-shadow with multiple layers of increasing blur (4px, 8px, 16px, 32px) in a vibrant color. Animate the shadow opacity on/off rapidly to simulate a flickering neon sign. Add a ::after pseudo-element as a subtle reflection below the text using scaleY(-1) with reduced opacity.
