Lesson 18.5 · Color Picker

CSS-Only Color Picker

Three range inputs control Hue, Saturation, and Lightness via custom properties. The selected color renders in a preview swatch using oklch(), while complementary, analogous, and triadic harmonies are generated with calc() on the hue value.

Range inputs as CSS controllers

HTML range inputs with min, max, and value attributes can drive CSS custom properties when combined with the @property rule. The trick is using the input's value directly in a style attribute that sets a custom property, which CSS then picks up for calculations.

The OKLCH color model

OKLCH separates color into Lightness (0-100%), Chroma (0-0.4), and Hue (0-360). This perceptual model means equal lightness steps look equally bright, making it ideal for generating harmonious palettes.

Color harmonies via calc()

A complementary color is the base hue + 180 degrees. Analogous colors are +/- 30 degrees. Triadic colors are +/- 120 degrees. All achieved with simple calc(var(--hue) + 180) expressions.

The hue spectrum strip

Behind the hue slider, a conic-gradient (or linear-gradient with multiple color stops at hue intervals) creates a full spectrum, giving the user visual feedback about which hue they are selecting.
