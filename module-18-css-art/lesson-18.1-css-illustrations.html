Lesson 18.1 · CSS Illustrations

Drawing with CSS: Shapes, Gradients & Clip-Paths

Every CSS property is a drawing tool. Border-radius draws curves, gradients paint fills, clip-path carves silhouettes, and box-shadow stamps copies. Combined, they turn a single <div> into a canvas. Here are four illustrations that prove it.

The single-element philosophy

CSS art practitioners aim to minimize HTML. One element gives you three drawing surfaces: the element itself, ::before, and ::after. Add box-shadow (which duplicates the element's shape at arbitrary offsets) and layered background gradients, and a single div becomes a full illustration toolkit.

Technique 1: Layered backgrounds

CSS allows unlimited background layers separated by commas. Each layer can be a linear-gradient, radial-gradient, or conic-gradient with independent sizing and positioning. The first declared layer sits on top.

Technique 2: Clip-path polygons

clip-path: polygon() carves any shape from a rectangle. Mountain silhouettes are just polygons with jagged top edges and a flat bottom. Combined with pseudo-elements, one div can hold multiple overlapping silhouettes.

Technique 3: Box-shadow multiplication

Each box-shadow value clones the element's shape (including border-radius) at a given offset. Stars in a night sky, dots in a pattern, petals on a flower — all achievable by listing dozens of shadow values on one element.

Technique 4: Transform reflections

transform: scaleY(-1) creates a mirror image. Combined with reduced opacity and a slight blur, this produces water reflections, floor reflections, or shadow effects with zero extra markup.

Try it yourself

Challenge

Take the coffee cup illustration and add a saucer beneath it using only box-shadow on the main element. The saucer is an ellipse: a box-shadow with a large spread-radius and zero blur, offset downward. Then add a cookie next to the cup using a second box-shadow with a different border-radius achieved via a separate element — or accept that box-shadow clones inherit the parent's radius and get creative with the cup's shape.
