Lesson 18.6 · Animated Scene

Animated Landscape Scene

A continuously animated landscape that cycles through dawn, day, and dusk. The sky gradient shifts hue using @property, a sun arcs across the sky, clouds drift at parallax speeds, birds fly in V-formation, and stars fade in as darkness falls.

@property for animated gradients

Standard CSS cannot animate gradient color stops. But by registering a custom property with @property and a specific syntax (like <number>), we can animate that property and use it inside gradient functions. This is how the sky smoothly transitions from warm dawn hues to cool blue daylight to deep dusk tones.

Parallax with staggered speeds

Clouds at different "distances" move at different speeds. Far clouds drift slowly with lower opacity; near clouds move faster with full opacity. This creates depth without any 3D transforms.

Clip-path for terrain

Rolling hills are polygon() clip-paths applied to solid-colored divs layered from back to front with slight vertical offsets. Each layer uses a slightly different green shade for depth.

Water reflections

A semi-transparent gradient over a repeated wave pattern (via alternating border-radius on a repeating element or a gradient trick) simulates water. The wave animation is a horizontal shift of the background position.
