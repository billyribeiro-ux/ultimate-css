Lesson 14.27 · Apple Human Interface Guidelines

Apple HIG: Component Patterns in CSS

Apple's UI components have exact dimensions, specific animation curves, and pixel-precise details that make iOS feel like iOS. The navigation bar is exactly 44px. The tab bar is 49px. The toggle is 31x51px. These are not suggestions — they are the system. Here is how to rebuild them in CSS.

Navigation bar

The iOS navigation bar is 44px tall (plus safe area), uses SF Pro at 17px semibold for the inline title, and has a blur background. The "large title" mode starts at 34px bold and collapses on scroll via scroll-driven animation. The 0.5px border is the retina hairline — on 2x displays it renders as a true 1-device-pixel line:

.hig-navbar {
  position: sticky;
  inset-block-start: 0;
  block-size: 2.75rem; /* 44px */
  display: flex;
  align-items: center;
  padding-inline: 1rem;
  backdrop-filter: saturate(180%) blur(20px);
  background: oklch(98% 0.005 264 / 0.72);
  border-block-end: 0.5px solid oklch(80% 0.01 264 / 0.5);
}

Tab bar

49px tall (plus safe area inset), centered icon-label pairs. Selected tab uses the system tint; unselected tabs are gray:

.hig-tabbar {
  display: flex;
  justify-content: space-around;
  block-size: 3.0625rem; /* 49px */
  padding-block-end: env(safe-area-inset-bottom);
  backdrop-filter: saturate(180%) blur(20px);
  border-block-start: 0.5px solid oklch(80% 0.01 264 / 0.5);
}

Action sheet

Slides up from the bottom with @starting-style, rounded top corners, backdrop blur, grouped buttons with hairline separators:

[popover].action-sheet {
  position: fixed;
  inset: auto 0.5rem 0.5rem;
  margin: 0 auto;
  max-inline-size: 24rem;
  border-radius: 0.875rem;
  background: oklch(96% 0.005 264 / 0.85);
  backdrop-filter: saturate(180%) blur(30px);
  opacity: 1; translate: 0 0;
  transition: opacity 300ms, translate 300ms,
              display 300ms allow-discrete;
}
[popover].action-sheet:not(:popover-open) {
  opacity: 0; translate: 0 100%;
}
@starting-style {
  [popover].action-sheet:popover-open {
    opacity: 0; translate: 0 100%;
  }
}

Toggle (UISwitch)

Exactly 31px tall and 51px wide. The knob is 27px (2px inset). Green on-state, gray off-state. Apple's standard curve at 200ms:

.hig-toggle {
  appearance: none;
  width: 3.1875rem;  /* 51px */
  height: 1.9375rem; /* 31px */
  border-radius: 1rem;
  background: oklch(88% 0.01 264);
  position: relative; cursor: pointer; border: none;
  transition: background 200ms cubic-bezier(0.4, 0, 0.2, 1);
}
.hig-toggle::before {
  content: "";
  position: absolute; top: 0.125rem; left: 0.125rem;
  width: 1.6875rem; height: 1.6875rem;
  border-radius: 50%; background: oklch(100% 0 0);
  box-shadow: 0 1px 3px oklch(0% 0 0 / 0.15);
  transition: translate 200ms cubic-bezier(0.4, 0, 0.2, 1);
}
.hig-toggle:checked { background: oklch(65% 0.2 145); }
.hig-toggle:checked::before { translate: 1.25rem 0; }

Segmented control

Equally sized segments with a pill-shaped sliding indicator. The indicator translates on selection change via a --active custom property:

.segmented {
  display: grid; grid-auto-columns: 1fr; grid-auto-flow: column;
  position: relative; background: oklch(92% 0.005 264);
  border-radius: 0.5rem; padding: 0.125rem;
}
.segmented::before {
  content: ""; position: absolute; inset-block: 0.125rem;
  inline-size: calc(100% / var(--seg-count));
  border-radius: 0.4375rem; background: oklch(100% 0 0);
  box-shadow: 0 1px 3px oklch(0% 0 0 / 0.08);
  translate: calc(var(--active) * 100%) 0;
  transition: translate 250ms cubic-bezier(0.4, 0, 0.2, 1);
}

PE7 placement

All five components live in the components layer. Their dimensions (44px, 49px, 31x51px) reference tokens. The scroll-driven navbar collapse and toggle animation belong in the animations layer. The @starting-style entry for the action sheet is also animations.

Mini-exercise

The toggle in the editor uses the exact HIG dimensions: 51px wide, 31px tall, 27px knob with 2px inset. Try changing the border-radius to 0.5rem instead of 1rem — it instantly stops looking like an Apple toggle. The pill shape is fundamental to the component's identity. Now add a :focus-visible style with a 3px outline offset in the system tint color. HIG requires that all interactive elements have a visible keyboard focus state.
