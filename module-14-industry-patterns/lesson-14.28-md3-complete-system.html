Lesson 14.28 · Google Material Design 3

MD3: The Complete Design System in CSS

Individual MD3 effects (ripple, elevation, shape morph) are in Lessons 14.17-14.21. This lesson builds the architectural backbone: the color role system, all 15 type scale entries, the shape scale, all 6 motion tokens, and the 5-level elevation system. Together they form a complete, tokenized design system in CSS custom properties.

Color roles

MD3 defines semantic color roles, not raw palette values. Each role has an "on" counterpart for text/icons that must contrast against it:

:root {
  --md3-primary: oklch(50% 0.2 275);
  --md3-on-primary: oklch(100% 0 0);
  --md3-secondary: oklch(55% 0.08 275);
  --md3-on-secondary: oklch(100% 0 0);
  --md3-tertiary: oklch(55% 0.15 330);
  --md3-error: oklch(55% 0.22 25);
  --md3-surface: oklch(98% 0.005 264);
  --md3-on-surface: oklch(12% 0.01 264);
  --md3-outline: oklch(52% 0.01 264);
  --md3-primary-container: oklch(90% 0.06 275);
  --md3-on-primary-container: oklch(15% 0.08 275);
}

You never use a raw color. You use a role. If the theme changes, only the role values change — every component inherits automatically.

Type scale — 15 styles

MD3 defines 5 categories (Display, Headline, Title, Body, Label) at 3 sizes each. Each specifies font-size, line-height, letter-spacing, and font-weight:

:root {
  --md3-display-lg-size: 3.5625rem;  /* 57px */
  --md3-display-md-size: 2.8125rem;  /* 45px */
  --md3-display-sm-size: 2.25rem;    /* 36px */
  --md3-headline-lg-size: 2rem;      /* 32px */
  --md3-headline-md-size: 1.75rem;   /* 28px */
  --md3-headline-sm-size: 1.5rem;    /* 24px */
  --md3-title-lg-size: 1.375rem;     /* 22px */
  --md3-title-md-size: 1rem;         /* 16px */
  --md3-title-sm-size: 0.875rem;     /* 14px */
  --md3-body-lg-size: 1rem;          /* 16px */
  --md3-body-md-size: 0.875rem;      /* 14px */
  --md3-body-sm-size: 0.75rem;       /* 12px */
  --md3-label-lg-size: 0.875rem;     /* 14px */
  --md3-label-md-size: 0.75rem;      /* 12px */
  --md3-label-sm-size: 0.6875rem;    /* 11px */
}

Shape scale

MD3 maps semantic meaning to border-radius. Smaller components use smaller radii; pills and circles use "Full":

:root {
  --md3-shape-none: 0;
  --md3-shape-xs: 0.25rem;     /* 4px — chips, badges */
  --md3-shape-sm: 0.5rem;      /* 8px — text fields */
  --md3-shape-md: 0.75rem;     /* 12px — cards, dialogs */
  --md3-shape-lg: 1rem;        /* 16px — FABs */
  --md3-shape-xl: 1.75rem;     /* 28px — nav bars */
  --md3-shape-full: 624.9375rem; /* 9999px — pills */
}

Motion tokens

MD3 defines 6 easing curves and 3 duration tiers. "Emphasized" has longer duration and slight overshoot for hero transitions. "Standard" is for small, frequent interactions:

:root {
  --md3-dur-short: 200ms;
  --md3-dur-medium: 300ms;
  --md3-dur-long: 500ms;
  --md3-ease-standard:     cubic-bezier(0.2, 0, 0, 1);
  --md3-ease-standard-dc:  cubic-bezier(0, 0, 0, 1);
  --md3-ease-standard-ac:  cubic-bezier(0.3, 0, 1, 1);
  --md3-ease-emphasized:   cubic-bezier(0.2, 0, 0, 1);
  --md3-ease-emphasized-dc:cubic-bezier(0.05, 0.7, 0.1, 1);
  --md3-ease-emphasized-ac:cubic-bezier(0.3, 0, 0.8, 0.15);
}

Elevation — 5 levels with tonal tinting

MD3 pairs box-shadow with primary-tinted surface overlays. Higher elevation means more tint (see Lesson 14.18):

:root {
  --md3-elev-0: none;
  --md3-elev-1: 0 1px 2px oklch(0% 0 0 / 0.3), 0 1px 3px 1px oklch(0% 0 0 / 0.15);
  --md3-elev-2: 0 1px 2px oklch(0% 0 0 / 0.3), 0 2px 6px 2px oklch(0% 0 0 / 0.15);
  --md3-elev-3: 0 4px 8px 3px oklch(0% 0 0 / 0.15), 0 1px 3px oklch(0% 0 0 / 0.3);
  --md3-elev-4: 0 6px 10px 4px oklch(0% 0 0 / 0.15), 0 2px 3px oklch(0% 0 0 / 0.3);
  --md3-tint-1: oklch(50% 0.2 275 / 0.05);
  --md3-tint-2: oklch(50% 0.2 275 / 0.08);
  --md3-tint-3: oklch(50% 0.2 275 / 0.11);
  --md3-tint-4: oklch(50% 0.2 275 / 0.14);
}

Spacing

MD3 uses a 4px base unit. All spacing is a multiple of 4:

:root {
  --md3-space-xs: 0.25rem;   /* 4px */
  --md3-space-sm: 0.5rem;    /* 8px */
  --md3-space-md: 0.75rem;   /* 12px */
  --md3-space-lg: 1rem;      /* 16px */
  --md3-space-xl: 1.5rem;    /* 24px */
  --md3-space-xxl: 2rem;     /* 32px */
}

PE7 placement

Every custom property above is a token. Components that consume them (cards, FABs, nav bars) live in the components layer. Motion tokens are referenced by animations.
