Lesson 14.20 · Google Material Design 3

MD3: Dynamic Color & Tonal Palettes

Material You generates an entire UI palette from a single seed color — five tonal palettes, each with 13 lightness stops. We rebuild this system in OKLCH so one custom property drives every surface, accent, and text color in the interface.

The five palette roles

Google's dynamic color algorithm extracts a seed hue from wallpaper or brand, then generates:

  • Primary — the seed hue at full chroma
  • Secondary — the seed hue at one-third chroma (subdued complement)
  • Tertiary — the seed hue rotated 60 degrees (harmonic contrast)
  • Neutral — the seed hue at near-zero chroma (tinted gray)
  • Neutral variant — slightly more chroma than neutral (borders, dividers)

Why OKLCH is the right space

Google's internal algorithm uses HCT (Hue-Chroma-Tone), a color space developed specifically for Material You. OKLCH is the closest CSS-native equivalent: it separates lightness (L), chroma (C), and hue (H) into independent channels. This means we can hold hue constant while sweeping lightness to generate tonal stops — exactly what HCT does.

The 13 lightness stops

Each palette contains stops at lightness values: 0, 10, 20, 25, 30, 35, 40, 50, 60, 70, 80, 90, 95, 98, 99, 100. In practice, a UI uses about 6 of these. In OKLCH, these map to L values from 0% to 100%.

Chroma manipulation

The secondary palette uses c * 0.33 — one third of the primary chroma. This desaturates the hue enough to be a supporting role rather than competing with the primary. The tertiary palette keeps full chroma but rotates hue by 60 degrees, creating a triadic harmony that feels vibrant without clashing.

Light and dark mode

The same 13 stops serve both modes. In light mode, surfaces use high-lightness stops (L: 98-99) and text uses low stops (L: 10-20). Dark mode inverts this mapping. The light-dark() function handles the swap without duplicating the palette.

PE7 placement

The --seed-hue and all derived palette stops are tokens. Components reference semantic aliases like --color-primary that resolve to specific stops. The generator logic lives entirely in CSS custom properties.

Mini-exercise

Change --seed-hue to 150 (green), then 30 (warm coral), then 210 (sky blue). Watch all four palette strips and the card recolor simultaneously. Then increase --seed-chroma to 0.25 — the secondary and neutral palettes gain more personality. Material You's magic is that a single number produces a coherent, accessible color system.
