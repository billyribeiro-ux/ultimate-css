Lesson 14.8

Linear: The Glow Card

Linear's UI features cards with a subtle glow that follows the mouse cursor — a spotlight effect from the pointer position. The glow is a radial-gradient positioned at CSS custom properties. This is one of the few patterns where minimal JS is necessary — to feed the mouse coordinates into CSS.

What Linear does

On Linear's marketing pages and feature cards, hovering over a card reveals a subtle radial glow centered on the cursor position. The glow follows the mouse as it moves, creating a spotlight effect that illuminates the card surface and border from the pointer. It is understated but unmistakable — it makes the cards feel interactive and premium.

The CSS-JS boundary

This pattern requires understanding where CSS ends and JS begins. CSS handles the entire visual effect: the radial gradient, its color, opacity, and blending. JS handles one thing: setting two custom properties (--x and --y) from the mouse position. The JS is 6 lines. The CSS is everything else.

The JS event listener:

  • card.addEventListener('mousemove', e => { ... })
  • Calculate position relative to card: e.offsetX and e.offsetY converted to percentages.
  • Set style.setProperty('--x', x + '%') and style.setProperty('--y', y + '%').

The CSS glow

The glow itself is a radial-gradient on a ::before overlay or directly on the card background: radial-gradient(circle at var(--x) var(--y), oklch(75% 0.15 275 / 0.15), transparent 50%). The gradient is centered at the custom property coordinates and fades to transparent. The glow color matches the brand — Linear uses their signature purple/blue.

The border glow

The card border also responds to the cursor. A ::before pseudo-element with the same radial gradient, masked to only show the border area, creates the effect of light reflecting off the card edge near the cursor.

Static fallback for the editor

In the live editor below, the glow is positioned at a static center point (--x: 50%; --y: 50%) since the editor does not run JavaScript. In production, the 6-line mousemove handler updates these values in real time.

Try it yourself

Mini-exercise

Change the glow color from oklch(70% 0.15 275 / 0.15) to oklch(70% 0.2 150 / 0.2) — a brighter green glow. Then change transparent 50% to transparent 30% for a tighter spotlight. The balance between glow intensity and radius is what makes this effect feel subtle (Linear) vs. dramatic (gaming sites).
