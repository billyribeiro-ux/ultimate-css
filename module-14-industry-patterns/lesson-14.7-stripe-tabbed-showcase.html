Lesson 14.7

Stripe: The Tabbed Feature Showcase

Stripe's product pages use a tab interface where selecting a tab crossfades the content panel and slides the active tab indicator. The indicator is a pseudo-element that transitions via translate, and the panels use the :target pattern for CSS-only switching.

What Stripe does

Stripe's feature showcases present multiple product capabilities in a tabbed interface. Clicking a tab causes a small underline indicator to slide smoothly to the new tab, while the content panel crossfades — the old panel fades out and the new one fades in. The entire interaction is smooth, purposeful, and communicates spatial relationships.

The sliding indicator

The indicator is typically an absolutely positioned ::after pseudo-element on the tab bar. When a new tab is active, the pseudo-element's translate value changes, and a transition smoothly slides it to the new position. Each tab's position is known at build time, so the translate values can be hard-coded or calculated with calc().

CSS-only tab switching with :target

Each tab is an anchor link pointing to a panel's id. The panel uses :target to become visible. Non-targeted panels are hidden. This is the same pattern from Module 11.3 — pure CSS state management via URL fragments.

The crossfade transition

Panels use opacity and translate transitions for enter and exit. The entering panel fades in from opacity: 0 to 1 with a slight upward motion. The exiting panel is hidden via display: none — which means the exit is instant. For a true crossfade, you would use position: absolute layering so both panels occupy the same space during the transition.

Height animation

If panels have different heights, the container can animate its height using interpolate-size: allow-keywords (Module 13.5). This prevents the page from "jumping" when switching between a tall and short panel.

Try it yourself

Mini-exercise

Click the tab links in the preview to switch panels. Then try adding a translate: calc(var(--tab) * 100%) to the ::after indicator and use :has() to set --tab based on which anchor has :target. This is how you would make the sliding indicator fully CSS-driven without JavaScript.
