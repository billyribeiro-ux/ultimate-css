Lesson 14.6

Stripe: The Gradient Mesh Background

Stripe's landing pages use a colorful animated gradient mesh — multiple radial gradients layered at different positions, slowly rotating and pulsing. The colors are in OKLCH for smooth interpolation, and @property enables animating the hue values directly.

What Stripe does

Stripe's homepage features a large background with multiple colorful gradients that overlap, blend, and slowly shift. The effect resembles a gradient mesh from a design tool like Figma — smooth color transitions between multiple focal points. The motion is extremely slow, making it feel alive without being distracting.

The multi-layer technique

The mesh is built from 3-5 radial-gradient() layers stacked in the background shorthand. Each gradient is positioned at a different point (e.g., 30% 20%, 70% 80%) and uses different colors. Because radial gradients fade to transparent by default, they naturally blend where they overlap.

Animating hue with @property

CSS cannot natively animate gradient color stops. But you can register a custom property with @property --hue-shift { syntax: "<number>"; ... } and use it inside the gradient: oklch(65% 0.2 calc(275 + var(--hue-shift))). Then animate --hue-shift from 0 to 360 over 20-30 seconds. The browser smoothly interpolates the registered property, and the gradient colors cycle smoothly.

OKLCH advantage

Stripe's gradients look vibrant because OKLCH interpolation avoids the "muddy middle" problem of sRGB. When you transition between two OKLCH colors, the intermediate values maintain perceptual chroma. In sRGB, a transition from blue to green passes through a desaturated gray zone. In OKLCH, it passes through vivid cyan.

Performance

Animated gradients via @property are GPU-composited in Chromium and WebKit. The browser does not repaint the gradient on every frame — it interpolates the registered property value and recomposites. This is fundamentally different from animating background-position, which triggers a repaint per frame.

Try it yourself

Mini-exercise

Add a fifth radial-gradient layer at position 60% 40% with a warm hue like oklch(70% 0.2 calc(50 + var(--hue))). Then change the animation duration from 25s to 8s. Notice how the faster cycle makes the page feel energetic rather than ambient. Stripe keeps it slow — 20-30 seconds — because the gradient is background ambiance, not the main event.
