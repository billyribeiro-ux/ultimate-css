Lesson 14.10

Vercel: The Shimmer Loading Skeleton

Vercel and many modern apps use a shimmer/skeleton loading state — gray placeholder shapes with a diagonal light sweep animation. A single @keyframes shifts a gradient background-position to create the shimmer, and light-dark() handles both themes.

What Vercel does

When Vercel's dashboard loads, placeholder shapes appear instantly in the positions where real content will render. These placeholders match the shape and size of the final content — rectangles for text, circles for avatars, rounded rectangles for cards. A diagonal light sweep (the "shimmer") moves across these shapes continuously, signaling that content is loading.

The shimmer gradient

The shimmer is a single linear-gradient with three stops: base color, highlight color, base color. The gradient is wider than the element (background-size: 200% 100%), and the animation shifts the background-position from one end to the other. This creates the illusion of a light beam sweeping across the surface.

The keyframes are minimal:

  • from { background-position: 200% 0; }
  • to { background-position: -200% 0; }

Skeleton shape matching

The skeleton must match the real content's dimensions and border-radius. A text line skeleton is a thin rounded rectangle. An avatar skeleton is a circle. A card skeleton matches the card's padding, gap, and corner radius. This dimensional accuracy prevents layout shift when real content replaces the skeleton.

Light and dark mode

The skeleton colors must adapt to the theme. In light mode, the base is a light gray and the highlight is slightly lighter. In dark mode, the base is a dark gray and the highlight is slightly lighter. Using light-dark() with OKLCH ensures perceptual consistency across themes.

Reduced motion

Under prefers-reduced-motion: reduce, the shimmer animation stops, leaving a static placeholder. The skeleton still communicates "loading" through its shape and muted color — the shimmer is decorative, not essential.

Try it yourself

Mini-exercise

Uncomment the dark mode @media block in the CSS. Then switch your system to dark mode (or force it in DevTools) and observe the skeleton adapting. Change the shimmer speed from 1.5s to 0.8s — notice how a faster shimmer feels anxious, like the page is struggling. Vercel's 1.5s feels calm and confident.
