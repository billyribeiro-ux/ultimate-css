Lesson 14.14

Notion/Linear: The Command Palette Modal

The command-K palette slides down from the top with backdrop blur, smooth enter/exit via @starting-style, and zero JavaScript for open/close. This uses the popover attribute with animated transitions on display and overlay.

What these products do

Notion, Linear, Vercel, and many developer tools feature a command palette — triggered by pressing Cmd+K. A modal appears near the top of the viewport with a search input, a list of recent actions, and keyboard navigation. The modal slides down from above with a slight blur on the backdrop. Pressing Escape or clicking outside dismisses it with a reverse animation.

The popover foundation

The HTML popover attribute handles open/close state, light-dismiss (clicking outside to close), and Escape key behavior — all without JavaScript. A button with popovertarget toggles the popover. This replaces hundreds of lines of modal management JS.

Enter animation with @starting-style

@starting-style defines the state the element transitions from when it first appears. For the command palette:

  • @starting-style { opacity: 0; translate: 0 -1rem; } — starts invisible and offset upward.
  • The element transitions to opacity: 1; translate: 0 0; — its normal position.

Exit animation

The exit uses :not(:popover-open) or the [popover]:not(:popover-open) selector to define the leaving state. Combined with transition-behavior: allow-discrete and transition-property: display, overlay, opacity, translate, the browser smoothly transitions the element out before removing it from the top layer.

Backdrop blur

The ::backdrop pseudo-element receives backdrop-filter: blur(4px) and a semi-transparent background. This blurs the content behind the modal, focusing attention on the palette. The backdrop also transitions its opacity for a smooth appear/disappear.

Positioning

position: fixed; inset-block-start: 15vh; margin-inline: auto; places the palette near the top of the viewport, centered horizontally. The 15vh offset mirrors where users expect the command palette to appear — above center, leaving room for results below.

Try it yourself

Mini-exercise

Open the palette in the preview, then click outside to dismiss it. Watch the exit animation. Change the translate in the exit state from 0 -1rem to 0 2rem — now the palette slides down when dismissed instead of up. The direction of the exit animation communicates spatial meaning: up = "going back where it came from," down = "falling away."
