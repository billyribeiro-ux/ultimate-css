Lesson 14.13

Apple TV+: The Horizontal Scroll Showcase

Apple TV+ uses a horizontal scroll carousel of show posters with scroll-snap-type: x mandatory, indicator dots via ::scroll-marker, and internal parallax on each poster via animation-timeline: view(inline).

What Apple TV+ does

The Apple TV+ homepage features a full-width horizontal carousel of featured show posters. Each poster snaps into center alignment when scrolled. Indicator dots below show which poster is currently centered. Within each poster, the background image shifts laterally as you scroll, creating a subtle internal parallax.

Scroll-snap for precision

scroll-snap-type: x mandatory on the container forces the scroll to land exactly on a snap point. scroll-snap-align: center on each poster centers it in the viewport. The mandatory keyword means the browser will always snap — the user cannot leave the carousel in a halfway state.

Scroll markers for indicators

The ::scroll-marker pseudo-element (shipping in Chromium 135+) creates navigation dots automatically for each snap target. Each marker is a small dot that can be styled with CSS — active state, hover state, transitions. This replaces dozens of lines of JavaScript that would otherwise manage indicator state.

Internal parallax with view(inline)

animation-timeline: view(inline) binds an animation to the horizontal visibility of each poster. The background image inside each poster uses a keyframe that shifts translateX from left to right as the poster scrolls through the viewport. This creates a parallax effect within each poster, adding depth to the horizontal scroll.

Fallback

Without ::scroll-marker, the carousel still scrolls and snaps — users just lose the indicator dots. Without view(inline), the parallax is absent but the posters are static and fully visible. Each feature degrades independently.

Mini-exercise

Change scroll-snap-align: center to start and observe how the snap position changes. Then change the slide width from 85% to 65% — you now see more of the next and previous slides, which invites scrolling. Apple uses a large slide (80-90%) to keep the focused poster dominant.
