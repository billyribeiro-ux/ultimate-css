Lesson 14.12

Apple Music: The Vinyl Spin

Apple Music's album view shows a vinyl record spinning continuously. Pausing the music pauses the spin. This is animation-play-state toggled by a checkbox and :has() — zero JavaScript.

What Apple Music does

In Apple Music's Now Playing view, the album artwork sits on a spinning vinyl record. The record rotates continuously at a constant speed. When the music is paused, the record decelerates and stops. When playback resumes, it accelerates back to speed. The vinyl grooves shimmer as they rotate.

The infinite rotation

animation: spin 4s linear infinite creates a continuous rotation. The linear timing function is critical — any easing would cause the record to accelerate and decelerate on each revolution, which looks unnatural for a spinning disc. The duration controls the RPM: 4s is approximately 15 RPM, which visually reads as a gentle spin.

The keyframes are as simple as CSS gets: @keyframes spin { to { rotate: 1turn; } }. The from state defaults to rotate: 0.

Play/pause with :has()

A hidden checkbox acts as the play/pause toggle. The label is styled as a play/pause button. When the checkbox is checked (playing), the vinyl spins. When unchecked (paused), animation-play-state: paused freezes the animation at its current position.

The selector: .player:has(input:checked) .vinyl { animation-play-state: running; }. The default state is paused, and checking the box switches to running. No JavaScript needed.

The vinyl grooves

The grooves are concentric circles created with repeating-radial-gradient. Alternating transparent and semi-transparent rings at tight intervals (1-2px) create the groove texture. As the disc rotates, these rings create a subtle shimmer effect.

Try it yourself

Mini-exercise

Click the play/pause button and watch the vinyl start and stop. Change the animation duration from 4s to 1.5s for a frantic spin, then to 10s for a lazy turntable. Notice that the record pauses at whatever angle it has reached — it does not snap back to 0. That is the beauty of animation-play-state: paused.
