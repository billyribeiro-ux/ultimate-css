Lesson 14.18 · Google Material Design 3

MD3: Elevation & Surface Tinting

Material Design 3 retired drop shadows as the primary depth signal. Instead, surfaces rise through "tonal elevation" — progressively tinted with the primary color. Level 0 is the base. Level 5 glows with 18% primary. Shadows are optional, not the main event.

Why tonal elevation replaced shadows

Shadows work on light backgrounds but collapse in dark mode — a dark card on a dark background produces an invisible shadow. Google needed an elevation system that worked equally well in both schemes. Tonal elevation solves this: a Level 3 surface is visibly lighter than Level 0 regardless of scheme, because the primary tint pushes the surface color away from the base.

The six elevation levels

MD3 defines levels 0 through 5. Each maps to a percentage of primary color mixed into the surface:

  • Level 0 — 0% tint (pure surface)
  • Level 1 — 5% primary tint (cards, menus)
  • Level 2 — 8% tint (raised containers)
  • Level 3 — 11% tint (navigation bars)
  • Level 4 — 14% tint (app bars)
  • Level 5 — 18% tint (FABs, highest surfaces)

The CSS implementation

The color-mix() function is purpose-built for this pattern. We mix in OKLCH so the tint shifts both lightness and chroma predictably:

--md3-surface: oklch(98% 0.003 264);
--md3-primary: oklch(48% 0.22 275);

--elev-0: var(--md3-surface);
--elev-1: color-mix(in oklch, var(--md3-surface) 95%, var(--md3-primary));
--elev-2: color-mix(in oklch, var(--md3-surface) 92%, var(--md3-primary));
--elev-3: color-mix(in oklch, var(--md3-surface) 89%, var(--md3-primary));
--elev-4: color-mix(in oklch, var(--md3-surface) 86%, var(--md3-primary));
--elev-5: color-mix(in oklch, var(--md3-surface) 82%, var(--md3-primary));

Why OKLCH for the mix?

Mixing in sRGB would produce muddy mid-tones because sRGB interpolation is not perceptually uniform. OKLCH ensures the tint shifts feel linear to the eye — Level 3 looks halfway between Level 1 and Level 5, which would not be the case in sRGB.

Shadows as an optional layer

MD3 pairs an optional box-shadow with tonal elevation for additional depth cues, especially in dark mode. The shadow is never the sole signal — it reinforces the tint. On hover, a card might transition from Level 1 to Level 3, gaining both a stronger tint and a shadow in one smooth motion.

Dark mode and tonal elevation

In dark mode, the surface base is dark (e.g. oklch(12% 0.01 264)) and the primary tint pushes it lighter. This is the key insight: in both schemes, higher elevation means lighter surface. The brain interprets lighter surfaces as "closer to the light source," which is above the screen. Shadows alone cannot produce this effect on dark backgrounds because a dark shadow on a dark surface is invisible — tonal elevation works where shadows fail.

Hover transitions

When a card transitions between elevation levels, both background-color and box-shadow should animate together. A mismatched transition — where the shadow appears before the tint changes — breaks the illusion. Use the same duration and easing for both: transition: background-color 300ms, box-shadow 300ms. MD3 uses their standard easing cubic-bezier(0.2, 0, 0, 1) for elevation changes.

PE7 placement

The color-mix() declarations belong in the tokens layer (they are primitive color values). The card component that references --elev-N lives in components. The hover transition is animations.

Try it yourself

Mini-exercise

Change --md3-primary to oklch(55% 0.20 150) (green) and watch all six levels shift from indigo-tinted to green-tinted. Then try a warm hue like oklch(55% 0.18 30). Notice how the neutral surface acquires personality from a single variable. This is the power of tonal elevation: one token drives the entire depth system.
