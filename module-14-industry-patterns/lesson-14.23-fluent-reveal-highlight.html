Fluent: Reveal Highlight

Reveal Highlight is a border-light effect that follows the cursor across a grid of controls. Nearby borders glow as the mouse passes, creating a sense of illumination. The effect spans card boundaries, as if a flashlight is sweeping across the interface.

The illusion of light

Fluent's Reveal Highlight simulates a point light source at the cursor position. As the cursor moves, borders near it brighten while distant borders remain dark. This creates a spatial awareness effect — the UI feels like a physical surface responding to an external light source rather than a flat screen emitting pixels.

The implementation pattern

The effect uses a radial gradient centered on the cursor coordinates, applied as an overlay across the entire grid container. Each card's border appears to glow because the gradient bleeds across card boundaries.

The grid-level overlay

.grid::before {
  content: "";
  position: absolute;
  inset: 0;
  background: radial-gradient(
    circle 200px at var(--x) var(--y),
    oklch(100% 0 0 / 0.08),
    transparent
  );
  pointer-events: none;
}

Why grid-level, not per-card?

If each card had its own glow, the effect would stop at card edges — the glow would be clipped by overflow: hidden. By placing the gradient on the grid container, it naturally spans the gaps between cards. The 1px borders between cards act as "light channels" that the gradient illuminates.

The 200px radius

The radial gradient uses a 200px radius. This matches the approximate area of foveal + parafoveal vision at typical viewing distance — the user sees the glow on cards they are already looking at, plus the immediate neighbors. A larger radius would illuminate too much, destroying the directional quality. A smaller radius would feel like a laser pointer.

Production: 4 lines of JS

In the static demo, the glow is fixed at center. In production, you need a mousemove listener on the grid that sets --x and --y. This is identical to the technique from Lesson 14.8 (Linear's glow card):

grid.addEventListener('mousemove', (e) => {
  const r = grid.getBoundingClientRect();
  grid.style.setProperty('--x', e.clientX - r.left + 'px');
  grid.style.setProperty('--y', e.clientY - r.top + 'px');
});

PE7 placement

The ::before overlay is a component detail of the grid. The --x/--y properties are runtime values set by JS. The gradient radius and opacity are tokens.

Try it yourself

Mini-exercise

Change --glow-radius to 80px for a tight spotlight effect, then to 400px for a broad wash. Notice how the small radius creates urgency (laser pointer) while the large radius loses directionality. Then increase --glow-opacity to 0.25 — the borders become too prominent and distract from content. Fluent keeps the reveal subtle precisely because it is always-on during mouse movement.
