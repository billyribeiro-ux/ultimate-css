Lesson 14.9

Linear: The Spotlight Border

Linear's cards have borders that glow brighter near the cursor — a spotlight sweep effect along the card edge. This pure-CSS version uses a conic-gradient rotated via @property --angle animation, creating a continuous sweeping light around the border.

What Linear does

Linear's cards have a subtle border that is not a uniform color — it appears brighter on one side, as if a light source is sweeping around the edge. In the mouse-following version, the bright spot tracks the cursor. In the ambient version, the bright spot rotates continuously around the card perimeter.

The @property --angle technique

CSS cannot normally animate a gradient's angle because angles inside gradient functions are not interpolatable. But with @property, you register a custom property as an <angle> type, which makes it smoothly animatable. The gradient uses var(--angle) and the keyframes animate --angle from 0deg to 360deg.

The property registration:

  • @property --angle { syntax: "<angle>"; inherits: false; initial-value: 0deg; }

The conic-gradient border

A conic-gradient(from var(--angle), ...) creates a gradient that sweeps around a center point. By placing a bright color at one position and transparent/dark elsewhere, you get a spotlight effect. This gradient is applied to a ::before pseudo-element that is slightly larger than the card, with the card itself covering the center — leaving only the border visible.

The mask technique

An alternative is to use border-image with a conic gradient. However, border-image does not respect border-radius. The more robust approach is the pseudo-element overlay masked to show only the edges, or the "padding-box cutout" technique where the card's background clips to padding-box, revealing the pseudo-element border ring behind it.

Try it yourself

Mini-exercise

Change the spotlight color from oklch(65% 0.2 275 / 0.7) to oklch(75% 0.25 150 / 0.8) — a vivid green spotlight. Then change transparent 25% to transparent 10% to make the spotlight wider. A narrow spotlight feels like a laser; a wide one feels like ambient light. Linear uses a narrow one for precision.
