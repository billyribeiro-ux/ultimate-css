Lesson 14.17 · Google Material Design 3

MD3: The Ripple Effect

The ripple is Material Design's signature interaction feedback — a radial wave emanating from the touch point that confirms "yes, you pressed this." Google's implementation uses JS for the coordinate, but the visual is pure CSS. Here's how to build it.

What the user sees

A button is clicked. From the exact click point, a translucent circle expands outward, fading as it grows, then dissipates. The entire animation takes roughly 300–500ms. On touch devices, it starts at the touch coordinate; on keyboard activation, it emanates from center.

The CSS science

The ripple is a ::after pseudo-element with position: absolute, border-radius: 50%, and a background: radial-gradient(circle, oklch(0% 0 0 / 0.12) 0%, transparent 70%). The expansion uses transform: scale(0) → transform: scale(4) with opacity: 1 → opacity: 0.

The pure-CSS version (center-emanating)

Without JS, the ripple always emanates from center on :active. This is how MD3's web components work for keyboard users:

.md3-btn {
  position: relative;
  overflow: hidden;
}
.md3-btn::after {
  content: "";
  position: absolute;
  inset: 0;
  margin: auto;
  inline-size: 100%;
  aspect-ratio: 1;
  border-radius: 50%;
  background: oklch(0% 0 0 / 0.12);
  transform: scale(0);
  opacity: 1;
  transition: transform 0ms, opacity 0ms;
}
.md3-btn:active::after {
  transform: scale(4);
  opacity: 0;
  transition: transform 400ms cubic-bezier(0, 0, 0.2, 1),
              opacity 400ms cubic-bezier(0, 0, 0.2, 1);
}

Why scale(4) not scale(1)?

The pseudo-element is sized to the button's width. A circle of that diameter, scaled 4x, guarantees it covers the entire button surface regardless of aspect ratio. Google's actual implementation calculates the hypotenuse of the button and sizes the ripple to that — scale(4) is a simpler approximation that works for all but the most extreme aspect ratios.

The state layer

MD3 also uses a "state layer" — a persistent semi-transparent overlay that appears on hover (oklch(0% 0 0 / 0.08)) and focus (oklch(0% 0 0 / 0.12)). This is separate from the ripple and is simpler: a ::before with transition: opacity.

PE7 placement

The ripple animation belongs in the animations layer. The state layer overlay belongs in components (it's a visual property of the button, not motion). The duration and easing reference tokens.

Mini-exercise

Click and hold each button. Watch the ripple expand while you hold, then fade when you release. Now try tabbing to a button and pressing Enter — the ripple emanates from center. Add a fourth button variant with a red ripple (oklch(60% 0.22 25 / 0.15)) for a destructive action. The architecture: only the ::after background color changes per variant.
