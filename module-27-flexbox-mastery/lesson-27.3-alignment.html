Lesson 27.3 · Layout

Alignment: justify-content, align-items, align-self, gap

Flexbox alignment is where the magic lives. Once you internalize which axis each property targets, you can center anything, distribute space perfectly, and create component layouts that respond beautifully to variable content.

justify-content — main axis distribution

Controls how items are distributed along the main axis (horizontal by default):

justify-content: flex-start;      /* pack to start (default) */
justify-content: flex-end;        /* pack to end */
justify-content: center;          /* center the group */
justify-content: space-between;   /* first flush start, last flush end, equal gaps */
justify-content: space-around;    /* equal space around each item (half at edges) */
justify-content: space-evenly;    /* truly equal gaps including edges */

The key difference: space-between gives zero space at edges. space-around gives half-sized space at edges. space-evenly gives equal space everywhere. For most UI work, space-between or the gap property is preferred.

align-items — cross axis alignment

Controls how items align along the cross axis (vertical by default):

align-items: stretch;     /* items stretch to fill container height (default) */
align-items: flex-start;  /* items align to top */
align-items: flex-end;    /* items align to bottom */
align-items: center;      /* items vertically centered */
align-items: baseline;    /* items align on their text baseline */

The stretch default is why flex items fill the container height — a common surprise for newcomers. To get natural height, set align-items: flex-start.

align-self — per-item override

align-self overrides align-items for a single item:

.container { align-items: flex-start; }
.special-item { align-self: flex-end; }    /* this one aligns to bottom */
.centered-item { align-self: center; }     /* this one centers vertically */

align-content — multi-line cross axis

When flex-wrap: wrap creates multiple lines, align-content distributes those lines along the cross axis. Same values as justify-content. Has no effect on single-line containers.

gap — the modern spacing tool

The gap property (originally from Grid, now in Flexbox) sets spacing between items without affecting edges:

gap: 1rem;              /* equal row and column gap */
row-gap: 1rem;          /* gap between wrapped lines */
column-gap: 0.5rem;     /* gap between items on same line */
gap: 1rem 0.5rem;       /* row-gap column-gap */

gap replaced the old "margin on all items + negative margin on container" hack. It only creates space between items, never at the edges. This is almost always what you want.

place-content and place-items

Shorthands for setting both axes at once:

place-content: center;    /* align-content + justify-content */
place-items: center;      /* align-items + justify-items */

Try it yourself

Mini-exercise

Build a card footer with three buttons. Use justify-content: flex-end and gap: 0.5rem to right-align them. Then change the first button to have margin-inline-end: auto — it pushes away from the other two. This is the "split" pattern we explore deeper in Lesson 27.7.
