Lesson 27.9 · Layout

Flexbox Form Layouts

Forms are component-level layout challenges — input groups, label alignment, inline fields, and search bars all benefit from flexbox. Here are the patterns that cover 90% of real-world form layouts, from simple label+input rows to complex multi-field arrangements.

Pattern 1: Input + button group

An input that fills available space with a fixed-size button attached:

.input-group {
  display: flex;
}
.input-group input {
  flex: 1;
  min-width: 0;          /* prevent overflow */
  border-radius: 0.5rem 0 0 0.5rem;
}
.input-group button {
  flex: none;
  border-radius: 0 0.5rem 0.5rem 0;
}

The flex: 1 on the input means it grows to fill the row. The button stays at its natural width. min-width: 0 prevents the input from overflowing on very narrow containers.

Pattern 2: Label + input rows

Labels aligned to the left with inputs filling the remaining space:

.form-row {
  display: flex;
  align-items: baseline;  /* text lines up across label and input */
  gap: 1rem;
}
.form-row label {
  flex: 0 0 120px;       /* fixed label width */
}
.form-row input {
  flex: 1;
}

Using align-items: baseline instead of center ensures the label text and input text sit on the same baseline — a crucial detail for visual polish.

Pattern 3: Stacked vs inline fields

/* Stacked (mobile-first) */
.field {
  display: flex;
  flex-direction: column;
  gap: 0.25rem;
}

/* Inline (wider screens) */
@media (min-width: 600px) {
  .field {
    flex-direction: row;
    align-items: baseline;
  }
  .field label { flex: 0 0 140px; }
  .field input { flex: 1; }
}

Switch between stacked (column) and inline (row) with just a direction change. The rest of the flex properties adapt automatically.

Pattern 4: Multi-field row

.field-row {
  display: flex;
  flex-wrap: wrap;
  gap: 1rem;
}
.field-row .field {
  flex: 1 1 200px;       /* wraps when below 200px */
}
.field-row .field-small {
  flex: 0 1 100px;       /* fixed-ish, but can shrink */
}

Pattern 5: The search bar

.search {
  display: flex;
  align-items: center;
  gap: 0.5rem;
  padding: 0.5rem 1rem;
  background: oklch(97% 0.01 275);
  border: 1px solid oklch(85% 0.03 275);
  border-radius: 9999px;
}
.search .icon { flex: none; }
.search input {
  flex: 1;
  border: none;
  background: transparent;
  outline: none;
}
.search .clear-btn {
  flex: none;
  opacity: 0;
  transition: opacity 150ms;
}
.search:focus-within .clear-btn { opacity: 1; }

The search bar is a flex row with icon (rigid), input (fluid), and clear button (rigid, hidden until focused). The :focus-within pseudo-class reveals the clear button.

Key principles for form layouts

  • Always use min-width: 0 on flex inputs to prevent overflow.
  • Use align-items: baseline for label+input rows — never center.
  • Use gap instead of margins for consistent spacing.
  • Wrap multi-field rows with flex-wrap: wrap for responsiveness.
