flex-grow, flex-shrink, flex-basis: The Sizing Triad

These three properties control how flex items claim, surrender, and start with space. The flex shorthand is the way you should always set them. Understanding the difference between flex: 1, flex: auto, and flex: none is essential.

flex-basis: the starting size

flex-basis sets the initial main size of a flex item before growing or shrinking occurs. It defaults to auto, which means "use my width/height property, or my content size."

/* The item starts at 200px before growing/shrinking */
flex-basis: 200px;

/* The item starts at its content size (default) */
flex-basis: auto;

/* The item starts at zero — it gets all its size from flex-grow */
flex-basis: 0;

When flex-basis is 0, the item's content size is ignored during space distribution. All available space is distributed proportionally by flex-grow. When flex-basis is auto, only the remaining space after content is considered is distributed.

flex-grow: claiming extra space

flex-grow determines how much of the remaining space an item claims. It defaults to 0 — items do not grow by default.

/* All items grow equally */
.item { flex-grow: 1; }

/* The middle item grows twice as much as the others */
.item:nth-child(2) { flex-grow: 2; }

The algorithm: (1) lay out all items at their flex-basis size, (2) calculate remaining space, (3) distribute it proportionally by each item's flex-grow value.

flex-shrink: surrendering space

flex-shrink determines how much an item shrinks when the container is too small. It defaults to 1 — items shrink equally by default. Set it to 0 to prevent an item from shrinking.

/* This item will not shrink below its flex-basis */
.logo { flex-shrink: 0; }

/* This item shrinks 3x as aggressively as the default */
.collapsible { flex-shrink: 3; }

Shrink is proportional to both the flex-shrink factor and the item's flex-basis. A larger item with the same shrink factor surrenders more absolute space than a smaller one.

The flex shorthand

Always use flex instead of the individual properties. The shorthand sets intelligent defaults that the individual properties do not:

/* flex: grow shrink basis */
flex: 1 1 0%;     /* = flex: 1 */
flex: 1 1 auto;   /* = flex: auto */
flex: 0 0 auto;   /* = flex: none */
flex: 0 1 auto;   /* = the initial value */

flex: 1 — equal distribution

Expands to flex: 1 1 0%. Basis is 0, so all space is distributed by grow. Items end up the same size regardless of content. This is the most common pattern for equal-width columns.

flex: auto — content-aware distribution

Expands to flex: 1 1 auto. Basis is auto, so each item starts at its content size, and only the leftover space is distributed equally. Items with more content end up wider.

flex: none — rigid

Expands to flex: 0 0 auto. The item neither grows nor shrinks. It stays at its content size. Use this for icons, logos, or any element that should not flex.

Common gotcha: flex-basis vs width

When both flex-basis (not auto) and width are set, flex-basis wins. But when flex-basis: auto, the item uses width (or height in column direction) as its basis. This is why the shorthand is safer — it sets basis explicitly.

The math in action

Container is 600px. Three items with flex: 1 (basis 0): each gets 600/3 = 200px. Now give item B flex: 2: total grow = 1+2+1 = 4. Item A gets 150px, item B gets 300px, item C gets 150px. Change to flex: auto with content widths of 100px, 200px, 50px: remaining = 600 - 350 = 250px. Each grows by 250/3 ≈ 83px. Final: A = 183px, B = 283px, C = 133px.
