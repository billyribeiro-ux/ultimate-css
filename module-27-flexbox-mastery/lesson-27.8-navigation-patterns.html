Flexbox Navigation Patterns

Navigation bars are flexbox's natural habitat. From simple link rows to complex multi-section headers with centered logos and split-side actions, every pattern uses the same handful of flex properties. Here are five production-ready nav patterns.

Pattern 1: Left-aligned links

The simplest nav — all links packed to the start:

.nav {
  display: flex;
  align-items: center;
  gap: 1.5rem;
  padding: 1rem 2rem;
}
.nav a {
  text-decoration: none;
  font-weight: 500;
}

Pattern 2: Centered logo with side links

Logo centered, links split to left and right:

.header {
  display: flex;
  align-items: center;
}
.header .left-links  { flex: 1; display: flex; gap: 1rem; }
.header .logo        { flex: none; }
.header .right-links { flex: 1; display: flex; gap: 1rem; justify-content: flex-end; }

The flex: 1 on both side groups gives them equal space, keeping the logo perfectly centered regardless of link count.

Pattern 3: Right-aligned auth buttons

Brand left, auth controls pushed to the right:

.header {
  display: flex;
  align-items: center;
  gap: 1rem;
}
.header .brand { font-weight: 700; }
.header .auth {
  margin-inline-start: auto;
  display: flex;
  gap: 0.5rem;
}

Pattern 4: Responsive with wrap

Links wrap to a second line on narrow viewports:

.nav {
  display: flex;
  flex-wrap: wrap;
  align-items: center;
  gap: 0.5rem 1.5rem;
  padding: 1rem 2rem;
}
.nav .brand {
  flex: 1 0 100%;  /* brand takes full width on mobile */
}
@media (min-width: 600px) {
  .nav .brand { flex: none; }
}

Pattern 5: Mobile bottom tab bar

Equal-width tabs at the bottom of the screen:

.tab-bar {
  position: fixed;
  inset-inline: 0;
  bottom: 0;
  display: flex;
  background: white;
  border-top: 1px solid oklch(90% 0 0);
  padding-block: 0.5rem;
}
.tab-bar a {
  flex: 1;
  display: flex;
  flex-direction: column;
  align-items: center;
  gap: 0.25rem;
  font-size: 0.7rem;
  text-decoration: none;
}

Each tab uses flex: 1 for equal width and flex-direction: column to stack icon above label.

Try it yourself

Mini-exercise

Build Pattern 2 (centered logo) and make it responsive: on viewports below 600px, switch to flex-wrap: wrap with the logo on a full-width first line (flex: 1 0 100%; text-align: center) and the link groups below it. No JavaScript needed — just flex-wrap and a media query for the basis change.
