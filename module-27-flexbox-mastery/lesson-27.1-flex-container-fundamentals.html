Lesson 27.1 · Layout

Flex Container Fundamentals

Everything starts when you write display: flex. The element becomes a flex container, its children become flex items, and a brand-new layout algorithm takes over. Understanding the main axis and cross axis is the key to everything that follows.

display: flex vs display: inline-flex

display: flex creates a block-level flex container — it takes the full width of its parent, just like a div. display: inline-flex creates an inline-level flex container — it only takes as much width as its content needs. Both produce the same internal layout; only the outer behavior differs.

The axis model

Flexbox is a one-dimensional layout system. It works along a single axis at a time:

  • Main axis — the direction flex items are placed. By default, this is horizontal (inline direction).
  • Cross axis — the perpendicular direction. By default, this is vertical (block direction).

Every alignment property references one of these axes. justify-content works on the main axis. align-items works on the cross axis. Memorize this and flexbox clicks instantly.

flex-direction

The flex-direction property sets the main axis:

/* Default — items laid out left-to-right */
flex-direction: row;

/* Right-to-left (or reversed inline direction) */
flex-direction: row-reverse;

/* Top-to-bottom — main axis becomes vertical */
flex-direction: column;

/* Bottom-to-top */
flex-direction: column-reverse;

When you switch to column, the meaning of justify-content and align-items swaps because the axes swap. This is the number one source of confusion for beginners — just remember: justify = main axis, align = cross axis, always.

flex-wrap

By default, flex items try to fit on one line. flex-wrap controls whether they can break into multiple lines:

/* Default — single line, items shrink to fit */
flex-wrap: nowrap;

/* Items wrap to next line when they exceed container width */
flex-wrap: wrap;

/* Items wrap in reverse order */
flex-wrap: wrap-reverse;

flex-flow shorthand

The flex-flow shorthand combines direction and wrap:

/* row nowrap (the default) */
flex-flow: row nowrap;

/* column with wrapping */
flex-flow: column wrap;

/* reversed row with wrapping */
flex-flow: row-reverse wrap;

What happens to children

When an element becomes a flex container, its direct children become flex items. Several things change automatically:

  • Children become block-level regardless of their original display value. A span inside a flex container acts like a block.
  • Floats and clear have no effect on flex items.
  • vertical-align has no effect on flex items.
  • Margins do not collapse between flex items.
  • Absolutely positioned children are removed from the flex flow but still respect the container's padding box as their containing block.

Anonymous flex items

Text nodes directly inside a flex container become anonymous flex items. They wrap in an implicit block box:

<div style="display: flex;">
  This text is an anonymous flex item.
  <span>This span is a flex item too.</span>
</div>

Only whitespace-only text nodes are collapsed (not rendered). Any visible text creates its own flex item.

Flex formatting context

A flex container establishes a new flex formatting context for its children. This means:

  • Children participate in flex layout, not block or inline layout.
  • Percentage heights on children resolve against the flex container.
  • The container's padding does not collapse with children's margins.
  • Overflow is controlled by the flex container's overflow property.

Writing mode awareness

Flex directions are logical, not physical. In a right-to-left writing mode (dir="rtl"), flex-direction: row lays items right-to-left. In vertical writing modes, "row" becomes vertical. This is why flexbox uses "main axis" and "cross axis" rather than "horizontal" and "vertical" — the actual direction depends on writing mode.

PE7 layer placement

Flex container declarations belong in the layout layer of PE7. The container's display: flex and directional properties define structure, not visual styling. Individual item flex properties (flex: 1) may live in the components layer if they're component-specific.

Try it yourself

Mini-exercise

Create a flex container with five boxes. Set flex-direction: row and flex-wrap: wrap. Give each box a min-width: 200px. Resize the browser and watch boxes wrap to the next line. Now change to flex-direction: column with a fixed height: 300px and flex-wrap: wrap — observe the column-wrap behavior.
