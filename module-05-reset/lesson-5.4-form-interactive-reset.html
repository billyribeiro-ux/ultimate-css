Lesson 5.4

Form & Interactive Element Reset

Form elements are the only HTML elements the browser refuses to style like the rest of the page. They ignore font inheritance, render OS-specific chrome, and have a focus outline that fights every design system. The reset layer fixes all three problems at once.

The inheritance gap

Every element on a page inherits font-family, font-size, color, and line-height from its parent — except button, input, select, and textarea. Those four break the chain on purpose so they can match the operating system's widgets. That was reasonable in 1998 and is a liability today.

:where(button, input, select, textarea) {
  font: inherit;
  color: inherit;
}

The shorthand font: inherit pulls family, size, weight, style, variant, and line-height in a single declaration. After this rule, form elements are finally ordinary text.

Removing button chrome

A bare <button> ships with a background gradient, a border, padding, and a cursor that changes between operating systems. A reset strips every visual opinion and leaves only the semantic behaviour.

:where(button) {
  background: none;
  border: none;
  padding: 0;
  cursor: pointer;
}

The button still focuses, still submits, still fires click events. It just looks like nothing until the components layer decides what it should look like.

Textareas are special

Textareas default to resize: both, which lets users drag them sideways out of the layout. Horizontal resize is almost never wanted; vertical usually is. Lock it to vertical.

:where(textarea) { resize: vertical; }

Fieldsets

The UA gives <fieldset> a border, margin, and padding designed for Netscape-era forms. Strip them and use the element purely for semantic grouping.

:where(fieldset) { border: none; padding: 0; margin: 0; }

Outline handling — do not remove, defer

Never write :where(button) { outline: none; } in the reset. Removing the keyboard focus ring is the single most common accessibility mistake on the web. The reset keeps the outline alive; the base layer replaces it with an intentional :focus-visible style that meets WCAG contrast requirements. See Lesson 6.6.

Mini-exercise

Delete font: inherit from the reset and run. The input and button revert to the operating system's default widget font. Now add it back. Notice that you did not need to touch font-family on either element directly — one shorthand in the reset fixed every form control in the entire application.
