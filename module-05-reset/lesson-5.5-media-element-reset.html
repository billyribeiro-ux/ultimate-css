Lesson 5.5

Media Element Reset

Images, videos, and SVGs are inline elements by default — a decision made when images were used as text decorations. On a modern page every image is a block, and every image must be allowed to shrink to its container. The reset fixes both with two rules.

The descender gap

An <img> is inline by default, which means it sits on a text baseline. There is empty space below the baseline — the descender gap — reserved for letters like "g" and "y". In an image-only container you see that space as a mysterious four-pixel white stripe under every image. Setting display: block removes the baseline entirely.

:where(img, picture, video, canvas, svg) {
  display: block;
  max-inline-size: 100%;
}

Why max-inline-size, not max-width

In a vertical writing mode, "width" is the block axis, not the inline axis. max-inline-size adapts automatically. This is a preview of the logical-properties rule from Lesson 6.5: in PE7 we never write physical properties when logical ones exist. The reset is the first layer to enforce that rule.

Aspect ratio preservation

Setting max-inline-size: 100% alone causes distortion when you also constrain block-size. The fix is to let the block axis flex with content:

:where(img, video) { block-size: auto; }

Combined with the browser's native aspect-ratio inference from the width and height HTML attributes, this gives correct layout-stable image sizing without cumulative layout shift.

What we do not reset

We do not force object-fit: cover or cover-like behaviour on media — that is a component decision. We do not set a default background or placeholder color — that is a component decision. The reset is subtraction, and everything else belongs to higher layers.

SVG specifically

Inline SVGs inherit color via currentColor, which is exactly what you want for icon systems. The reset should not touch SVG color or fill — doing so would break icons that rely on the currentColor pattern.

Mini-exercise

Delete max-inline-size: 100% from the reset. The SVG overflows its parent figure and pushes the border out. Now delete display: block only. You will see a one-to-four pixel gap appear above the caption — the classic descender-gap bug. Two lines of reset CSS eliminate a whole category of image-related layout complaints.
