Module 5 · Project

Ship a Production Reset

Take the rules from every lesson in this module and assemble them into one reset.css. Prove the result by rendering the same HTML twice — once without the reset, once with — and explain every visible difference.

The brief

  1. Write a single reset.css that contains every rule from lessons 5.2–5.6. Every selector wrapped in :where(). Every rule inside @layer reset.
  2. Apply it to the HTML below and screenshot the before/after.
  3. Write down, for each visible difference, which reset rule caused it.

The complete reset file

/* reset.css — PE7 production reset */
@layer reset {
  :where(*, *::before, *::after) { box-sizing: border-box; }

  :where(h1, h2, h3, h4, h5, h6, p, figure, blockquote, dl, dd) { margin: 0; }
  :where(h1, h2, h3, h4, h5, h6) {
    font-size: inherit; font-weight: inherit; line-height: inherit;
  }
  :where(ul[role="list"], ol[role="list"]) {
    list-style: none; padding: 0; margin: 0;
  }

  :where(img, picture, video, canvas, svg) {
    display: block; max-inline-size: 100%;
  }
  :where(img, video) { block-size: auto; }

  :where(button, input, select, textarea) { font: inherit; color: inherit; }
  :where(button) {
    cursor: pointer; background: none; border: none; padding: 0;
  }
  :where(textarea) { resize: vertical; }
  :where(fieldset) { border: none; padding: 0; margin: 0; }

  :where(body) {
    min-block-size: 100svh;
    text-rendering: optimizeLegibility;
  }

  @media (prefers-reduced-motion: reduce) {
    :where(*, *::before, *::after) {
      animation-duration: 0.01ms !important;
      animation-iteration-count: 1 !important;
      transition-duration: 0.01ms !important;
      scroll-behavior: auto !important;
    }
  }
}

Your deliverable

Ten numbered observations. For each one, state which rule in reset.css caused the change and which lesson introduced it.

  1. Heading sizes: h1 and h2 collapse to body size. Which rule? Which lesson?
  2. Heading and paragraph margins: gone. Which rule?
  3. Button font: inherits Georgia on the right, still uses system font on the left. Why?
  4. Button chrome: removed on the right. Which rule?
  5. Input font: inherits Georgia. Which rule?
  6. SVG inside figure: now block-level on the right, no descender gap. Which rule?
  7. SVG width: constrained to parent. Which rule?
  8. Box-sizing: verify by inspecting computed styles. Which rule?
  9. Motion: enable OS reduce-motion and re-check any animation. Which rule?
  10. Third-party CSS: sketch how you would import a vendor stylesheet into this reset. Which lesson?
