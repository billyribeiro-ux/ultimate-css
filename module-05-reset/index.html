@layer reset: The Production Reset

Reset is subtraction. Its only job is to neutralise the user-agent stylesheet and any imported third-party CSS so that every layer above it can assume a known, boring baseline. In PE7 the reset layer is the lowest-priority layer in the cascade — by design.

Module goal

Build a complete, production-grade reset inside @layer reset that is safe to drop into any project without surprising the layers above it. Every rule in this module is wrapped in :where() so it has zero specificity — your base, components, and utilities will override it without effort.

Why reset is its own layer

Because reset is subtraction, not decoration, it must live at the bottom of the cascade. Any rule in reset that accidentally wins over a component is a bug. By placing it in the lowest @layer, the language itself guarantees that cannot happen — no specificity gymnastics, no !important, no source-order tricks.
