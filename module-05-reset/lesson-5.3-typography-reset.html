Lesson 5.3

Typography Reset

The user agent stylesheet ships six differently sized headings, default paragraph margins, and a collection of inherited quirks. Reset strips every opinion so the base layer can rebuild typography from tokens.

Headings inherit, not default

The UA sizes h1 through h6 using magic numbers that predate the web. Worse, those sizes cascade independently of your design tokens — a base font size change does not flow through to headings. The fix is to make headings inherit font properties from their parent, then let the base layer apply token-driven sizes explicitly.

:where(h1, h2, h3, h4, h5, h6) {
  font-size: inherit;
  font-weight: inherit;
  line-height: inherit;
}

After this rule, an h1 looks identical to a span — which is exactly what you want in a reset. It is now the base layer's exclusive job to describe what headings look like.

Margin: zero, globally

The UA puts margin-block on paragraphs, headings, figures, blockquotes, and definition list elements. Those margins collapse, cascade, and interfere with gap-based layouts. Remove them all, then let the stack primitive in the layout layer reintroduce spacing via gap.

:where(h1, h2, h3, h4, h5, h6, p, figure, blockquote, dl, dd) {
  margin: 0;
}

Lists: opt-in stripping

Never strip bullets from every list. Screen readers announce "list" based on both the element and its style — when you remove list-style, some assistive technologies stop announcing the list. The right pattern is to strip only lists explicitly marked as UI structures with role="list".

:where(ul[role="list"], ol[role="list"]) {
  list-style: none;
  padding: 0;
  margin: 0;
}

Body-level baselines

Two rules on body are worth pre-paying: guaranteeing a full-viewport-height minimum so sticky footers work, and enabling better font rendering. Neither is subtraction in the strict sense, but both are universally wanted before any visual decision is made.

:where(body) {
  min-block-size: 100svh;
  text-rendering: optimizeLegibility;
}

Small, sub, sup

The <small> element has a UA rule of font-size: 80%. That is a baked-in opinion. Leave it — the base layer may reassign it, but it does not need to be reset first because it is already proportional.

Mini-exercise

Delete font-size: inherit from the heading rule and run. Headings jump back to UA sizes. Now try adding a conflicting rule in a higher layer — notice that you do not need any specificity tricks to override the reset. That is the :where() guarantee working.
