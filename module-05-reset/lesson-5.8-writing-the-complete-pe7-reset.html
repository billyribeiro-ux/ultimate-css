Lesson 5.8

Writing the Complete PE7 Reset

Every rule we introduced in lessons 5.2 through 5.7, assembled into a single file. Each block carries an inline comment explaining why it exists — a reset without justification rots into cargo culting.

The assembled file

This is the reset that ships with the PE7 course shell. Every line is cross-referenced to the lesson that justifies it, and every selector is wrapped in :where(). There are no surprises — if a rule is not in this list, it does not belong in the reset layer.

/* =============================================================
   @layer reset — PE7 production reset
   Every rule wraps selectors in :where() for zero specificity.
   Justifications reference Module 5 lessons.
   ============================================================= */

@layer reset {
  /* 5.2 — Box model reset */
  :where(*, *::before, *::after) {
    box-sizing: border-box;
  }

  /* 5.3 — Typography: neutralise heading and prose margins */
  :where(h1, h2, h3, h4, h5, h6, p, figure, blockquote, dl, dd) {
    margin: 0;
  }
  :where(h1, h2, h3, h4, h5, h6) {
    font-size: inherit;
    font-weight: inherit;
    line-height: inherit;
  }

  /* 5.3 — Opt-in list stripping */
  :where(ul[role="list"], ol[role="list"]) {
    list-style: none;
    padding: 0;
    margin: 0;
  }

  /* 5.5 — Media elements as blocks, constrained to parent */
  :where(img, picture, video, canvas, svg) {
    display: block;
    max-inline-size: 100%;
  }
  :where(img, video) {
    block-size: auto;
  }

  /* 5.4 — Form / interactive inheritance */
  :where(button, input, select, textarea) {
    font: inherit;
    color: inherit;
  }
  :where(button) {
    cursor: pointer;
    background: none;
    border: none;
    padding: 0;
  }
  :where(textarea) {
    resize: vertical;
  }
  :where(fieldset) {
    border: none;
    padding: 0;
    margin: 0;
  }

  /* 5.3 — Body baseline */
  :where(body) {
    min-block-size: 100svh;
    text-rendering: optimizeLegibility;
  }

  /* 5.6 — Motion reset (accessibility) */
  @media (prefers-reduced-motion: reduce) {
    :where(*, *::before, *::after) {
      animation-duration: 0.01ms !important;
      animation-iteration-count: 1 !important;
      transition-duration: 0.01ms !important;
      scroll-behavior: auto !important;
    }
  }
}

What is not in this file

  • No font-family. That is the base layer's job (Lesson 6.2).
  • No color or background-color. That is the base layer's job, driven by tokens.
  • No :focus or :focus-visible rules. Those belong in base (Lesson 6.6).
  • No ul { list-style: none } without the role="list" opt-in. That would be an accessibility regression.
  • No outline: 0 anywhere. Removing focus outlines in reset is a WCAG failure.

Line count

The complete reset is under 60 lines including comments. If your reset is longer than that, it is probably doing work that belongs in base. If it is shorter, something was omitted — check the list above.

Ordering inside the layer

Because every rule has zero specificity and the layer ordering is unambiguous, the source order within the reset layer is irrelevant for the cascade. We still group rules by concern — box model, typography, media, forms, motion — because humans read source files and grouping is for humans.

Mini-exercise

Copy the complete reset from this lesson into a new reset.css file in your own project. Remove your existing reset. Run your app. Anything that breaks is telling you that a rule you thought was in reset was actually doing base-layer work. Move it to base.
