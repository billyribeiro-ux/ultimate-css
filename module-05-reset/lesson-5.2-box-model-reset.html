Lesson 5.2

Box Model Reset

The default box-sizing: content-box is an accident of history that nobody actually wants. Exactly one line of reset CSS fixes it for every element, every pseudo-element, and every third-party widget on the page.

The problem, stated precisely

In content-box the width you set is the width of the content alone. Padding and border are added outside that number. A column declared width: 33.333% with padding: 1rem is no longer 33.333% wide — it is 33.333% plus two rems. Three of them in a row overflow their parent.

In border-box the width you set includes padding and border. The column you asked for is the column you get. This is what every layout system, every grid framework, and every competent developer has silently wished for since 2001.

The rule

@layer reset {
  :where(*, *::before, *::after) {
    box-sizing: border-box;
  }
}

Three targets: every element, every ::before, and every ::after. The pseudo-elements are not optional — framework components use them for icons, arrows, and dividers, and they inherit nothing by default. Miss them and you get mysterious half-pixel drift in tab indicators and tooltip arrows.

Why :where() and not the universal selector alone

The universal selector * already has zero specificity, so the wrapper is redundant for this rule. We use :where() anyway for consistency with the rest of the reset layer. Every reset rule looks the same. No exceptions, no special cases, no "well, this one doesn't need it" conversations in code review.

Why not inherit?

Some older resets write html { box-sizing: border-box; } *, *::before, *::after { box-sizing: inherit; }. The inherit pattern was a workaround for third-party widgets that set their own box-sizing on internal elements. Modern third-party CSS either behaves correctly or is already broken in ways a reset cannot fix. The direct form is simpler and wins.

Mini-exercise

Delete the @layer reset block from the editor above and run. Predict the overflow pixel count before you check. (Hint: two borders and two paddings per column, times three columns, minus the parent's own width.) This is exactly the arithmetic your colleagues are doing in their head every time they write calc(33.333% - 2rem). A reset makes that arithmetic unnecessary.
