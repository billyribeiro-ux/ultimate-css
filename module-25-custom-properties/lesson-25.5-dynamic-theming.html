Lesson 25.5 · Custom Properties

Runtime Theme Generation

One --hue property generates an entire color system. Primary, secondary, surface, and accent colors all derive from a single input — enabling real-time theme customization with zero JavaScript color math.

The single-hue architecture

OKLCH separates lightness, chroma, and hue. By fixing lightness and chroma while varying hue, you get a perceptually uniform palette from a single variable:

:root {
  --hue: 275;
  --primary: oklch(55% 0.22 var(--hue));
  --secondary: oklch(55% 0.15 calc(var(--hue) + 60));
  --tertiary: oklch(55% 0.12 calc(var(--hue) + 180));
  --surface: oklch(97% 0.01 var(--hue));
  --on-surface: oklch(20% 0.02 var(--hue));
}

Derived palette tokens

Once you have the base colors, derive everything else with lightness adjustments:

--primary-light: oklch(75% 0.15 var(--hue));
--primary-dark: oklch(35% 0.18 var(--hue));
--primary-container: oklch(90% 0.06 var(--hue));
--on-primary-container: oklch(25% 0.12 var(--hue));

Combining with light-dark()

Use the light-dark() function for automatic mode switching:

:root { color-scheme: light dark; }
body {
  background: light-dark(
    oklch(97% 0.01 var(--hue)),
    oklch(15% 0.02 var(--hue))
  );
  color: light-dark(
    oklch(20% 0.02 var(--hue)),
    oklch(92% 0.01 var(--hue))
  );
}

The range input technique

A single <input type="range"> sets --hue on :root via minimal JS:

<input type="range" min="0" max="360" value="275"
  oninput="document.documentElement.style.setProperty('--hue', this.value)">

Everything recolors instantly because all colors reference var(--hue).

Beyond hue: multi-axis theming

Add more axes for richer theme control:

:root {
  --hue: 275;        /* brand color axis */
  --chroma: 0.22;    /* saturation axis */
  --contrast: 1;     /* accessibility axis */
}
--primary: oklch(
  calc(55% * var(--contrast))
  var(--chroma)
  var(--hue)
);

A "high contrast" mode increases --contrast to 1.2, making colors more vivid and lightness differences more pronounced. A "desaturated" mode drops --chroma to 0.05. All from CSS alone.

Persisting user preferences

Store the hue value in localStorage. On page load, read it back and set the property. This gives users persistent personalization with one line of JS and zero backend:

// On input change
localStorage.setItem('theme-hue', value);
// On page load
const hue = localStorage.getItem('theme-hue') || '275';
document.documentElement.style.setProperty('--hue', hue);
