Lesson 25.3 · Custom Properties

The Space Toggle: Boolean Logic in CSS

Before if() existed in CSS, developers discovered a hack: a custom property set to a single space behaves differently than one set to initial. This trick enables binary state toggling in pure CSS — no JavaScript, no classes.

How it works

A custom property set to a space (--flag: ; — technically an empty value) is considered "defined." One set to initial is considered "guaranteed invalid." The var() function reacts differently:

/* ON state: --flag is a space (empty value) */
--flag: ;
background: var(--flag, red) green;
/* Result: " green" → valid → background is green */

/* OFF state: --flag is initial (guaranteed invalid) */
--flag: initial;
background: var(--flag, red) green;
/* Result: fallback "red" is used → "red green" is invalid
   for background shorthand → IACVT → inherits/initial */

The key insight: when --flag is a space, var(--flag, fallback) returns the space (nothing visible), so the rest of the value is what applies. When --flag is initial, the fallback is returned instead.

The clean pattern

/* Define two channels: ON and OFF */
--ON: ;
--OFF: initial;

/* Toggle */
--is-dark: var(--OFF);

.dark-mode {
  --is-dark: var(--ON);
}

/* Usage — pick value based on toggle */
--bg: var(--is-dark, oklch(15% 0 0)) var(--is-light, oklch(98% 0 0));
/* When --is-dark is ON (space), first part wins.
   When --is-dark is OFF, second part with fallback wins. */

Numeric toggles with calc()

For numeric interpolation, use 0/1 values instead:

--is-dark: 0; /* light mode */
--is-dark: 1; /* dark mode */

--lightness: calc(95% - var(--is-dark) * 80%);
/* light: 95%, dark: 15% */

background: oklch(var(--lightness) 0.02 275);

Building if/else

Combine two toggled properties for a full if/else:

--if-dark: var(--is-dark);
--if-light: var(--is-light);

color: var(--if-dark, oklch(90% 0 0)) var(--if-light, oklch(20% 0 0));

This was the only pure-CSS conditional before the if() function. It remains useful for supporting older browsers.

Limitations and gotchas

The space toggle has real limitations to understand:

  • Not human-readable — the intent of --flag: ; is not obvious without comments.
  • Only binary — unlike the numeric approach, the space toggle cannot represent intermediate states.
  • DevTools confusion — some browser DevTools show the space value as empty, making debugging harder.
  • Superseded by if() — when if() has full browser support, prefer it for new code.

When to use which approach

Use the numeric toggle (0/1) when you need intermediate values, interpolation, or calc() math. Use the space toggle when you need to swap entire non-numeric values (like a font-family, a gradient, or a keyword). Use neither when you can simply override the property in a selector — the simplest solution is often the right one.

Quick reference: toggle patterns

  • Numeric (0/1): --is-dark: 1 — works with calc(), can interpolate.
  • Fractional: --is-dark: 0.5 — enables "halfway" states.
  • Space toggle: --flag: ; (on) / --flag: initial (off) — swaps entire values.
  • Future: if(style(--dark: 1), dark-val, light-val) — clean syntax when available.
