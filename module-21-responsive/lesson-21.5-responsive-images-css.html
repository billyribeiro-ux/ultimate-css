Lesson 21.5 · Fluid Systems

Responsive Images via CSS

Control how images adapt with aspect-ratio for placeholder sizing, object-fit for cropping strategy, object-position for focal point control, and art-direction patterns using container queries.

aspect-ratio for placeholder sizing

Before an image loads, aspect-ratio reserves the correct space, preventing layout shift (CLS):

.hero-img {
  aspect-ratio: 16 / 9;
  inline-size: 100%;
  block-size: auto;
  /* Space is reserved even before image loads */
}

.avatar {
  aspect-ratio: 1; /* Perfect square */
  inline-size: 3rem;
}

object-fit: cropping strategy

When an image's intrinsic dimensions don't match its box, object-fit controls how it fills:

/* Cover: fill the box, crop overflow */
.card-img { object-fit: cover; }

/* Contain: fit within the box, letterbox if needed */
.product-img { object-fit: contain; }

/* Scale-down: like contain, but never upscales */
.icon-img { object-fit: scale-down; }

object-position: focal point control

When cropping with object-fit: cover, control which part of the image is visible:

/* Focus on the top of the image (faces in portraits) */
.portrait { object-position: center top; }

/* Focus on the left third */
.left-focus { object-position: 25% center; }

/* Precise focal point */
.custom-focus { object-position: 30% 20%; }

Art direction with container queries

Different crops at different container sizes — the modern replacement for the HTML <picture> element's art-direction use case:

.hero-container {
  container-type: inline-size;
}

.hero-img {
  aspect-ratio: 9 / 16; /* Portrait by default (mobile) */
  object-position: center 30%; /* Face focus */
}

@container (min-width: 600px) {
  .hero-img {
    aspect-ratio: 16 / 9; /* Landscape (desktop) */
    object-position: center center;
  }
}

background-image with image-set()

Resolution-dependent backgrounds without media queries:

.hero {
  background-image: image-set(
    url("hero-1x.webp") 1x,
    url("hero-2x.webp") 2x,
    url("hero-3x.webp") 3x
  );
  background-size: cover;
  background-position: center;
}

Mini-exercise

Create a hero section with a simulated image (use a gradient background). On narrow containers (under 500px), the image should be portrait (9:16) with object-position: center 30% focusing on an upper focal point. On wider containers, switch to landscape (16:9) with centered positioning. No media queries — container queries only.
