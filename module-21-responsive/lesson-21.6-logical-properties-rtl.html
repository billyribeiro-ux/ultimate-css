Lesson 21.6 · Fluid Systems

Logical Properties & RTL/Vertical Writing

Complete physical-to-logical property mapping. The PE7 rule: logical properties everywhere in base styles. One CSS file that works in LTR, RTL, and vertical writing modes without a single override.

Physical to logical mapping

Logical properties replace physical directions (left/right/top/bottom) with flow-relative directions (inline-start/inline-end/block-start/block-end):

/* PHYSICAL → LOGICAL */

/* Dimensions */
width        → inline-size
height       → block-size
min-width    → min-inline-size
max-height   → max-block-size

/* Margin */
margin-left   → margin-inline-start
margin-right  → margin-inline-end
margin-top    → margin-block-start
margin-bottom → margin-block-end

/* Padding */
padding-left  → padding-inline-start
padding-right → padding-inline-end

/* Shorthand */
margin: 1rem 2rem → margin-block: 1rem; margin-inline: 2rem;
padding: 1rem 2rem 1rem 2rem → padding-block: 1rem; padding-inline: 2rem;

/* Border */
border-left  → border-inline-start
border-right → border-inline-end
border-top   → border-block-start

/* Position */
top    → inset-block-start
bottom → inset-block-end
left   → inset-inline-start
right  → inset-inline-end
inset: 0 → inset: 0 (already logical)

/* Border-radius */
border-top-left-radius     → border-start-start-radius
border-top-right-radius    → border-start-end-radius
border-bottom-left-radius  → border-end-start-radius
border-bottom-right-radius → border-end-end-radius

Logical values

Properties that take directional values also have logical equivalents:

/* text-align */
text-align: left  → text-align: start
text-align: right → text-align: end

/* float and clear */
float: left  → float: inline-start
float: right → float: inline-end

/* resize */
resize: horizontal → resize: inline
resize: vertical   → resize: block

The PE7 rule

In PE7 architecture, all base styles use logical properties exclusively. Physical properties are only allowed in the rare case where something must be physically positioned regardless of writing direction (e.g., a fixed visual decoration).

/* PE7 base — always logical */
.card {
  padding-inline: 1.5rem;
  padding-block: 1rem;
  margin-block-end: 1rem;
  border-inline-start: 3px solid var(--accent);
  border-start-start-radius: 0.5rem;
  border-end-start-radius: 0.5rem;
}

Testing with dir and writing-mode

A properly logical layout needs zero CSS changes for RTL or vertical writing:

/* Just change the HTML attribute */
<html dir="rtl" lang="ar">

/* Or change writing mode */
html { writing-mode: vertical-rl; }

/* If you used logical properties throughout,
   everything flips/rotates correctly */
