Lesson 21.8 · Fluid Systems

Responsive Navigation Patterns

Five navigation patterns that adapt to available space: top bar to hamburger, tab bar morphing, collapsible sidebar, bottom sheet, and the command palette alternative. Container queries drive the responsive switching.

Pattern 1: Top bar to hamburger

The classic pattern. Full nav links visible on desktop, collapsed into a menu toggle on narrow containers:

.nav-container { container-type: inline-size; }
.nav-links { display: flex; gap: 1rem; }
.nav-toggle { display: none; }

@container (max-width: 600px) {
  .nav-links {
    display: none;
    position: absolute;
    inset-block-start: 100%;
    inset-inline: 0;
    flex-direction: column;
    background: var(--surface);
  }
  .nav-links[data-open] { display: flex; }
  .nav-toggle { display: block; }
}

Pattern 2: Tab bar on mobile, full nav on desktop

Mobile-first: a bottom tab bar with icons. Desktop: a horizontal nav with text labels:

.nav {
  position: fixed;
  inset-block-end: 0;
  inset-inline: 0;
  display: flex;
  justify-content: space-around;
}
.nav-label { display: none; }

@container (min-width: 768px) {
  .nav {
    position: static;
    justify-content: flex-start;
    gap: 2rem;
  }
  .nav-label { display: inline; }
  .nav-icon { display: none; }
}

Pattern 3: Sidebar collapse to icons

Full sidebar with labels collapses to icon-only rail on narrow containers:

.sidebar {
  container-type: inline-size;
  inline-size: clamp(4rem, 20vw, 16rem);
}
.sidebar-label { display: inline; }

@container (max-width: 8rem) {
  .sidebar-label { display: none; }
  .sidebar-link { justify-content: center; }
}

Pattern 4: Bottom sheet (mobile-first)

Nav hidden in a bottom sheet that slides up on tap. On larger containers, it becomes a visible sidebar or top nav:

.nav-sheet {
  position: fixed;
  inset-block-end: 0;
  transform: translateY(100%);
  transition: transform 300ms;
}
.nav-sheet[data-open] { transform: translateY(0); }

@container (min-width: 768px) {
  .nav-sheet {
    position: static;
    transform: none;
  }
}

Pattern 5: Command palette as nav

Instead of visible navigation, provide a keyboard-triggered command palette (Cmd+K). Scales to any number of items without layout constraints. Best for power-user apps.

Mini-exercise

Build a sidebar navigation that has 3 states controlled by container queries: (1) full sidebar with icons + labels when wide enough, (2) icon-only rail when medium, (3) completely hidden (replaced by a bottom tab bar) when narrow. Use container-type: inline-size on the sidebar's parent, and drive all state changes with @container rules.
