Lesson 21.3 · Fluid Systems

Intrinsic Sizing: min(), max(), clamp(), fit-content

Five layout problems solved without media queries. Let elements size themselves intelligently using CSS math functions and intrinsic keywords.

min() — "be this OR smaller"

The min() function picks the smallest of its arguments. The classic use: a container that maxes out at a fixed width but shrinks to fit small viewports:

/* Container: 40rem max, or 100% of available space */
.container {
  inline-size: min(40rem, 100%);
  margin-inline: auto;
}
/* No media query needed — it just works */

max() — "be this OR bigger"

The inverse: pick the largest value. Useful for minimum sizing constraints:

/* Sidebar: at least 300px, or 30% of parent */
.sidebar {
  inline-size: max(300px, 30%);
}

/* Image: never smaller than 200px */
.thumbnail {
  inline-size: max(200px, 25%);
}

fit-content — content-driven sizing with a cap

fit-content(max) makes an element shrink to its content but never exceed the specified maximum. Unlike max-width, it also affects how the element participates in grid/flex layouts:

/* Tag: shrinks to text but caps at 200px */
.tag {
  inline-size: fit-content(200px);
}

/* Grid column that fits content up to 300px */
grid-template-columns: fit-content(300px) 1fr;

min-content and max-content

These keywords size elements to their content's intrinsic dimensions:

/* Shrink to the longest word */
.narrow { inline-size: min-content; }

/* Expand to fit all content on one line */
.wide { inline-size: max-content; }

/* Practical: a heading that wraps tightly */
h1 {
  inline-size: min-content;
  /* Wraps at each word boundary */
}

The auto-fit + minmax() pattern

The most powerful intrinsic grid pattern — columns that automatically wrap and fill available space:

.grid {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(min(300px, 100%), 1fr));
  gap: 1rem;
}
/* Why min(300px, 100%)?
   Prevents overflow when container is less than 300px */
