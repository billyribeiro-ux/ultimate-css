Lesson 21.4 · Fluid Systems

Container Queries at Scale

Moving beyond simple size queries into nested containers, container query units, named containers, and style queries. Build a dashboard where every widget adapts to its grid cell independently.

Nested container contexts

When a card lives inside a sidebar inside a page, each ancestor can be a container. The card queries its nearest containment context — the sidebar — not the page:

/* Each level establishes its own context */
.page    { container-type: inline-size; container-name: page; }
.sidebar { container-type: inline-size; container-name: sidebar; }
.card    { /* queries .sidebar by default */ }

/* Target a specific ancestor */
@container sidebar (min-width: 300px) {
  .card { flex-direction: row; }
}
@container page (min-width: 1200px) {
  .card { font-size: 1.1rem; }
}

Container query units

Size relative to the container, not the viewport:

/* cqi = 1% of container inline size
   cqw = 1% of container width
   cqh = 1% of container height
   cqmin = smaller of cqi/cqb
   cqmax = larger of cqi/cqb */

.widget-title {
  font-size: clamp(0.9rem, 3cqi, 1.5rem);
  /* Scales with container width, clamped for safety */
}

.widget-padding {
  padding: 4cqi;
  /* 4% of container inline size */
}

Container names for specificity

Without names, a container query targets the nearest ancestor with containment. Names let you skip levels:

.dashboard {
  container-type: inline-size;
  container-name: dashboard;
}
.widget-cell {
  container-type: inline-size;
  container-name: cell;
}

/* Target the cell (nearest) */
@container cell (min-width: 400px) {
  .widget { grid-template-columns: 1fr 1fr; }
}

/* Target the dashboard (skip cell) */
@container dashboard (min-width: 1000px) {
  .widget { border-radius: 1rem; }
}

Style queries

Query computed custom property values on the container:

.widget-cell {
  container-type: inline-size;
  --density: normal;
}
.compact-mode .widget-cell {
  --density: compact;
}

@container style(--density: compact) {
  .widget { padding: 0.5rem; gap: 0.25rem; }
  .widget-title { font-size: 0.85rem; }
}
