Lesson 21.10 · Fluid Systems

Complete Layouts with Zero Breakpoints

The capstone of responsive thinking: a full page layout that adapts from 320px to 2560px without a single media query. Design for a continuum, not discrete sizes.

The philosophy

Breakpoint-based design treats responsive as "desktop layout + mobile layout + maybe tablet." Zero-breakpoint design treats every pixel width as equally valid. The layout flows continuously like water, never snapping between states.

The toolkit

Every zero-breakpoint layout combines these techniques:

/* 1. Fluid type and spacing */
--text-h1: clamp(1.5rem, 1rem + 2.5vw, 3.5rem);
--space-section: clamp(2rem, 1rem + 4vw, 6rem);

/* 2. Intrinsic container sizing */
.page { inline-size: min(75rem, 100% - 2rem); margin-inline: auto; }

/* 3. Auto-fit grids for card areas */
.cards { grid-template-columns: repeat(auto-fit, minmax(min(300px, 100%), 1fr)); }

/* 4. Flex-wrap for nav/tags/buttons */
.nav { display: flex; flex-wrap: wrap; gap: 1rem; }

/* 5. Container queries for component-level adaptation */
.card-container { container-type: inline-size; }

/* 6. Logical properties for writing-mode agnosticism */
.card { padding-inline: var(--space-m); padding-block: var(--space-s); }

The sidebar pattern without breakpoints

A sidebar that collapses to full-width when space is insufficient, using only flex-wrap:

.with-sidebar {
  display: flex;
  flex-wrap: wrap;
  gap: var(--space-l);
}
.sidebar {
  flex-basis: 20rem;
  flex-grow: 1;
}
.content {
  flex-basis: 0;
  flex-grow: 999;
  min-inline-size: 60%;
}
/* When there isn't room for both, content's min-inline-size
   forces the sidebar to wrap below. No breakpoint needed. */

The header pattern

Logo + nav that wraps naturally:

.header {
  display: flex;
  flex-wrap: wrap;
  align-items: center;
  gap: 1rem;
}
.logo { margin-inline-end: auto; }
/* Nav items wrap when they run out of space. Done. */

Building Layouts Without Breakpoints

May 2026 — 5 min read

This entire layout uses zero media queries. The header wraps naturally with flex-wrap. The sidebar collapses when the main content needs its 60% minimum width. The card grid uses auto-fit to reflow at any width.

Every font size uses clamp() with rem+vw. Every spacing token derives from one fluid unit. The container maxes out with min(70rem, 100%). Resize from 320px to 2560px and nothing breaks.
