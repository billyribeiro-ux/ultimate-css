Lesson 21.2 · Fluid Systems

Fluid Spacing Systems

Spacing that scales with the viewport using clamp(). Define one fluid unit, derive all others with calc(), and watch padding, gap, and margin scale proportionally from mobile to ultrawide.

The ratio approach

If your base spacing is 1rem at 320px and 1.5rem at 1440px, every other spacing token should scale at the same rate. This creates visual harmony — the relationships between spaces remain constant even as absolute values change.

:root {
  /* Base fluid unit: 1rem at 320px, 1.5rem at 1440px */
  --space-unit: clamp(1rem, 0.7rem + 1.3vw, 1.5rem);

  /* Derived scale — all proportional */
  --space-3xs: calc(var(--space-unit) * 0.25);
  --space-2xs: calc(var(--space-unit) * 0.5);
  --space-xs:  calc(var(--space-unit) * 0.75);
  --space-s:   var(--space-unit);
  --space-m:   calc(var(--space-unit) * 1.5);
  --space-l:   calc(var(--space-unit) * 2);
  --space-xl:  calc(var(--space-unit) * 3);
  --space-2xl: calc(var(--space-unit) * 4);
  --space-3xl: calc(var(--space-unit) * 6);
}

Independent clamp() per token

For more control, define each spacing token with its own clamp(). This lets smaller spaces scale less aggressively than larger ones:

:root {
  --space-xs:  clamp(0.25rem, 0.2rem + 0.25vw, 0.5rem);
  --space-s:   clamp(0.5rem, 0.4rem + 0.5vw, 0.75rem);
  --space-m:   clamp(1rem, 0.7rem + 1.3vw, 1.5rem);
  --space-l:   clamp(1.5rem, 1rem + 2vw, 2.5rem);
  --space-xl:  clamp(2rem, 1rem + 3.5vw, 4rem);
  --space-2xl: clamp(3rem, 1.5rem + 5vw, 6rem);
}

Using fluid spacing in layouts

Apply the tokens to gaps, padding, and margins. The entire layout breathes as one:

.card-grid {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(min(300px, 100%), 1fr));
  gap: var(--space-m);
  padding: var(--space-l);
}

.card {
  padding: var(--space-m);
  border-radius: var(--space-xs);
}

.card h3 { margin-block-end: var(--space-xs); }
.card p  { margin-block-end: var(--space-s); }

Section spacing with fluid tokens

Vertical rhythm between page sections benefits most from fluid spacing. Sections need generous breathing room on large screens but cannot waste space on mobile:

.section + .section {
  margin-block-start: var(--space-2xl);
}

.section-header {
  margin-block-end: var(--space-l);
}

Fluid spacing and borders/radius

Border-radius and border-width also benefit from fluid scaling. A card that has generous rounded corners on desktop but tighter corners on mobile looks more intentional:

.card {
  border-radius: calc(var(--space-unit) * 0.75);
  /* At 320px: ~12px radius
     At 1440px: ~18px radius */

  border: calc(var(--space-unit) * 0.05) solid var(--border);
  /* Subtle scaling — almost invisible but prevents
     borders from feeling too thick on small screens */
}

The cascade: one source of truth

The single --space-unit pattern means changing responsive behavior is a one-line edit. Want tighter mobile spacing? Reduce the minimum. Want more generous desktop spacing? Increase the maximum. Every component automatically updates:

/* Before: tight spacing */
--space-unit: clamp(0.5rem, 0.4rem + 0.5vw, 0.75rem);

/* After: generous spacing */
--space-unit: clamp(1rem, 0.7rem + 1.3vw, 1.5rem);

/* Every component using derived tokens
   (--space-xs through --space-3xl) updates automatically.
   Zero find-and-replace needed. */
