Lesson 6.3

Heading Hierarchy from Tokens

The reset flattened every heading to body size. The base layer rebuilds the hierarchy — not with magic numbers, but with token references that respond to a single scale change. Plus one modern property that replaces manual line breaks: text-wrap: balance.

Shared heading rule

All six headings share behaviour: a font-family, a weight, a tight line-height, a specific color, and balanced wrapping. Write that once:

:where(h1, h2, h3, h4, h5, h6) {
  font-family: var(--font-sans);
  font-weight: var(--weight-bold);
  line-height: var(--leading-tight);
  color: var(--color-text-heading);
  text-wrap: balance;
}

The :where() wrapper keeps specificity at 0,0,0 even though the selector list is long — so downstream components can override any of these properties with a plain element selector.

Per-level sizes

Sizes are the only thing that varies between heading levels. Bind each to its scale token, not to a pixel value:

h1 { font-size: var(--size-4xl); letter-spacing: -0.02em; }
h2 { font-size: var(--size-3xl); letter-spacing: -0.015em; }
h3 { font-size: var(--size-2xl); letter-spacing: -0.01em; }
h4 { font-size: var(--size-xl); }
h5 { font-size: var(--size-lg); }
h6 { font-size: var(--size-md); }

Negative letter-spacing is an opinion: larger type at default tracking looks loose, and pulling it in a fraction of an em makes display-size headlines feel intentional. The effect is invisible at smaller sizes, which is why only h1-h3 carry it.

text-wrap: balance

Before text-wrap: balance, designers asked developers to insert <br> tags in headlines so a two-line title would break evenly rather than leaving one word on the second line. balance makes the browser do it automatically, re-flowing on resize. It works best on short headings (under ten words) — longer than that, performance degrades and the browser falls back to normal wrapping.

Why the shared rule is first

Cascade order matters inside a layer. The shared :where(h1..h6) rule lists all six headings; the per-level rules are plain element selectors. When both match an h1, the per-level rule (specificity 0,0,1) wins over the shared rule (specificity 0,0,0) regardless of source order. Source order only matters between rules of equal specificity.

What we do not set

  • No margin — the layout layer's stack primitive handles spacing via gap.
  • No text-transform — that is a component opinion.
  • No text-decoration — headings are not links.

Mini-exercise

Change --size-3xl from 2rem to 3rem and re-run. Every h1 on the page scales in proportion, and nothing else moves. Now try the same change in a codebase that uses raw pixel values — you will find the pixel values in eight different files. That difference is why tokens exist.
