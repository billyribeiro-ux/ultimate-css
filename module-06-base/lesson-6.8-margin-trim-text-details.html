Lesson 6.8

margin-trim and Text Refinements

The last pass on base is a handful of modern properties that only turn on where they are supported: margin-trim, hyphens, overflow-wrap, orphans, and widows. Each one is small. Together they are the difference between prose that looks handmade and prose that looks auto-generated.

The problem margin-trim solves

A common pattern: a card with 1rem of padding contains a heading and two paragraphs. Each paragraph has a margin-block for vertical rhythm. The first paragraph's top margin collides with the card's padding, adding unwanted space; the last paragraph's bottom margin does the same. Developers have worked around this for twenty years with :first-child and :last-child rules — messy and specific to each container.

/* The old way */
.card > :first-child { margin-block-start: 0; }
.card > :last-child  { margin-block-end: 0; }

margin-trim fixes this at the container level. Set it on the card and the browser automatically removes the outermost margins of the first and last children:

.card { margin-trim: block; }

@supports gating

margin-trim has partial browser support as of 2025 — stable in Safari and WebKit, shipping in Chromium behind a flag, experimental in Firefox. Wrap it in @supports so browsers without it fall back to the old :first-child/:last-child pattern:

@supports (margin-trim: block) {
  :where(section, article, aside, blockquote) {
    margin-trim: block;
  }
}

hyphens and overflow-wrap

Long words in narrow columns overflow. Two properties handle this:

:where(p, li, dd) {
  hyphens: auto;
  overflow-wrap: break-word;
}

hyphens: auto enables soft hyphenation at syllable boundaries — the browser knows where to break a word like "compartmentalisation" without making you type &shy;. overflow-wrap: break-word is the last-resort rule: if a word cannot be hyphenated (a URL, a long hash, a token), break it anywhere rather than overflowing the container.

orphans and widows

In print typography, an orphan is a single word left on the last line of a paragraph; a widow is a single line of a paragraph left at the top of a page. The CSS properties orphans and widows let you request minimum counts — on multi-column and paginated layouts, the browser respects them. They are ignored on regular block layout, but setting them costs nothing and they apply in print stylesheets automatically.

p { orphans: 3; widows: 3; }

The full base text-refinement block

@supports (margin-trim: block) {
  :where(section, article, aside, blockquote, .card) {
    margin-trim: block;
  }
}

:where(p, li, dd) {
  hyphens: auto;
  overflow-wrap: break-word;
  orphans: 3;
  widows: 3;
}

Mini-exercise

Remove hyphens: auto and overflow-wrap: break-word from the rules. The long made-up word in the first paragraph blows out of the container. Add them back. Every prose page you ever ship benefits from these two lines — they cost nothing and prevent a whole category of "text overflow" bug reports.
