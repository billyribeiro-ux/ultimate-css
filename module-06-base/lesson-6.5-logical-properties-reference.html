Lesson 6.5

Logical Properties Reference

Physical properties hard-code the assumption that text runs left-to-right and top-to-bottom. Logical properties adapt to the writing mode at runtime. In PE7 we never write physical properties in base — and the payoff is that flipping dir="rtl" on a page mirrors every layout automatically.

Shorthands matter

The shorthands margin-block and margin-inline accept one or two values:

margin-block: 1rem;          /* both block edges */
margin-block: 1rem 2rem;     /* start, end */
padding-inline: var(--gutter);/* both inline edges */
border-inline-start: 3px solid var(--color-primary);

Prefer the shorthands when you are setting both edges, and the full name when you are setting one edge. Never mix physical and logical on the same element — debugging mixed rules is painful.

The PE7 rule

In the base and layout layers, write logical properties exclusively. In components, the same rule applies unless the component has a documented reason to use a physical property (a decorative ornament pinned visually to the left edge regardless of writing mode, for example). Utilities may use physical properties for terse class names, but they are still logical-first.

Try it yourself

Mini-exercise

Grep your current project for margin-left, padding-right, text-align: left, and width: on layout elements. Every match is a bug waiting for an Arabic or Hebrew translation. Replace them with logical equivalents and your entire site becomes RTL-capable without touching a single component.
