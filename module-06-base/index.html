Module 6 · Layer

@layer base: Typography, Logic, Dark Mode

The base layer is where raw HTML becomes a usable document. It sits between tokens and components and has one job: turn every element in the user-agent vocabulary into something readable using only the design tokens from Module 4. No classes. No hard-coded values. No exceptions.

Module goal

Write a complete base layer that a documentation site could ship with tomorrow — responsive typography driven by tokens, logical properties throughout, focus styles that meet WCAG, automatic dark mode via OKLCH, and prose refinements gated by @supports.

The single-author rule

Every selector in base matches a raw HTML element. No .class, no #id, no [data-*]. If a rule needs a class, it belongs in components. This constraint is what keeps base from growing into a second component layer — and it is the reason base can be written once and reused across projects that share a token system.
