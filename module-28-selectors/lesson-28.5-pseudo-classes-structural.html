Pseudo-Classes: Structural

Structural pseudo-classes select elements based on their position in the DOM tree — first child, last child, every Nth item, empty elements, and more. Combined with the functional selectors :is(), :where(), :not(), and :has(), they form a complete targeting language.

Position-based selectors

:first-child     /* first element among siblings */
:last-child      /* last element among siblings */
:only-child      /* element with no siblings */
:first-of-type   /* first of its tag type among siblings */
:last-of-type    /* last of its tag type among siblings */
:only-of-type    /* only one of its tag type among siblings */

The :nth-child() family

:nth-child(3)          /* exactly the 3rd child */
:nth-child(odd)        /* 1st, 3rd, 5th... */
:nth-child(even)       /* 2nd, 4th, 6th... */
:nth-child(3n)         /* every 3rd: 3, 6, 9... */
:nth-child(3n+1)       /* 1, 4, 7, 10... */
:nth-last-child(2)     /* 2nd from the end */
:nth-of-type(2n)       /* every even element of that type */
:nth-last-of-type(1)   /* last of that type */

The An+B formula

:nth-child(An+B) where A is the step (cycle size) and B is the offset:

  • 2n = every 2nd (even). 2n+1 = every odd.
  • 3n = every 3rd: 3, 6, 9. 3n+1 = 1, 4, 7, 10.
  • -n+5 = first 5 items only (5, 4, 3, 2, 1).
  • n+3 = everything from 3rd onward.

:empty

/* Hide elements with no children or text */
:empty { display: none; }

/* Style empty state containers */
.list:empty::before { content: "No items yet."; }

Note: whitespace-only elements are NOT considered empty. An element must have truly zero child nodes.

Functional pseudo-classes

:not() — negation

/* All inputs that are NOT disabled */
input:not(:disabled) { border-color: oklch(70% 0.1 275); }

/* All children except the last */
.item:not(:last-child) { border-bottom: 1px solid oklch(90% 0 0); }

:is() — matches-any (forgiving)

/* Instead of: h1 a, h2 a, h3 a, h4 a */
:is(h1, h2, h3, h4) a { color: inherit; }

/* Specificity = highest selector in the list */
:is(.card, #hero) .title { font-weight: 700; }  /* specificity of #hero! */

:where() — zero specificity :is()

/* Same matching as :is() but adds ZERO specificity */
:where(h1, h2, h3) { margin-block: 0.5em; }

/* Perfect for defaults that should be easily overridden */
:where(.btn) { cursor: pointer; }

:has() — parent/relational selector

/* Card that contains an image */
.card:has(img) { padding: 0; }

/* Form that contains an invalid input */
form:has(:invalid) { border-color: oklch(55% 0.22 25); }

/* Section followed by another section */
section:has(+ section) { border-bottom: 1px solid oklch(90% 0 0); }

:has() is covered in depth in Lesson 28.7.

Demo — structural selectors

  • :first-child (purple bg)
  • 2nd item (even = light bg)
  • :nth-child(3) (left border)
  • 4th item (even = light bg)
  • 5th item
  • :last-child (blue bg)

Multiple structural selectors applied simultaneously. Specificity conflicts resolved by source order.

Try it yourself

Mini-exercise

Use :is() to write a single rule that applies to the first child of .card, .panel, and .section elements. Then use :where() for a default that's easily overridden. Finally, use :not(:last-child) to add bottom borders to all list items except the last.
