Attribute Selectors

Attribute selectors let you target elements based on their HTML attributes and attribute values — without needing extra classes. From simple presence checks to substring matching, they enable powerful data-attribute-driven styling patterns.

The seven attribute selector forms

[attr] — presence

/* Any element with a "title" attribute */
[title] { cursor: help; border-bottom: 1px dotted; }

/* Any input with a "required" attribute */
[required] { border-color: oklch(55% 0.2 25); }

[attr=val] — exact match

/* Only type="email" inputs */
[type="email"] { background: oklch(97% 0.02 200); }

/* Only links to exactly "/" */
[href="/"] { font-weight: 700; }

[attr~=val] — space-separated word

/* Element whose class list contains "active" as a whole word */
[class~="active"] { opacity: 1; }
/* Equivalent to .active but less common */

[attr|=val] — exact or prefix with hyphen

/* Matches lang="en", lang="en-US", lang="en-GB" */
[lang|="en"] { quotes: "\201C" "\201D"; }

Originally designed for language codes. Matches the value exactly OR the value followed by a hyphen.

[attr^=val] — starts with

/* External links (start with http) */
[href^="http"] { padding-inline-end: 1rem; }

/* Links starting with /docs/ */
[href^="/docs/"] { color: oklch(50% 0.2 150); }

[attr$=val] — ends with

/* PDF file links */
[href$=".pdf"] { color: oklch(55% 0.2 25); }

/* Image sources ending in .webp */
[src$=".webp"] { border-radius: 0.5rem; }

[attr*=val] — contains substring

/* Links containing "github" anywhere in href */
[href*="github"] { font-weight: 600; }

/* Any data attribute containing "error" */
[class*="error"] { color: oklch(55% 0.22 25); }

Case-insensitive flag (i)

/* Match .PDF, .pdf, .Pdf — case insensitive */
[href$=".pdf" i] { color: oklch(55% 0.2 25); }

/* Case-insensitive type matching */
[type="Email" i] { /* matches type="email" too */ }

Data-attribute-driven styling

Custom data-* attributes let you drive styling from HTML without inventing new classes:

/* Theme variants via data attributes */
[data-theme="dark"] { background: oklch(15% 0.02 275); color: oklch(90% 0 0); }
[data-theme="light"] { background: oklch(98% 0.01 275); color: oklch(15% 0 0); }

/* Size variants */
[data-size="sm"] { font-size: 0.8rem; padding: 0.25rem 0.5rem; }
[data-size="lg"] { font-size: 1.1rem; padding: 0.75rem 1.5rem; }

/* Status indicators */
[data-status="success"] { border-color: oklch(60% 0.2 150); }
[data-status="error"]   { border-color: oklch(55% 0.22 25); }
[data-status="warning"] { border-color: oklch(70% 0.18 80); }

Specificity

Attribute selectors have the same specificity as a class: (0, 1, 0). They can be combined freely with other selectors.
