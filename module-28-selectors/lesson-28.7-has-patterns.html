:has() Patterns Encyclopedia

The :has() pseudo-class is CSS's most powerful addition in a decade. It selects an element based on what it contains or what follows it. Here are 20 real-world patterns that replace JavaScript with pure CSS.

1. Parent styling based on children

/* Card with image gets no padding on top */
.card:has(> img:first-child) { padding-top: 0; }

/* Card without image gets extra top padding */
.card:not(:has(img)) { padding-top: 2rem; }

2. Form validation on the parent

/* Form turns red-bordered when it has invalid inputs */
form:has(:invalid) { border: 2px solid oklch(55% 0.22 25); }

/* Submit button disabled-looking when form is invalid */
form:has(:invalid) button[type="submit"] { opacity: 0.5; pointer-events: none; }

3. Sibling detection (previous sibling styling)

/* Style a label when its adjacent input is focused */
label:has(+ input:focus) { color: oklch(50% 0.2 275); }

/* Style the heading before an expanded details */
h2:has(+ details[open]) { color: oklch(50% 0.2 275); }

4. Empty state

/* Show empty state when list has no items */
.list:not(:has(.item)) .empty-state { display: block; }
.list:has(.item) .empty-state { display: none; }

5. Content-aware layouts

/* Switch to 2-column layout when card has both image and text */
.card:has(img):has(.text) { display: grid; grid-template-columns: 1fr 1fr; }

/* Full-width when only text */
.card:not(:has(img)) { max-width: 60ch; }

6. Image detection

/* Figure with image gets aspect-ratio container */
figure:has(img) { aspect-ratio: 16/9; overflow: hidden; }

/* Article with hero image gets different layout */
article:has(> .hero-img) { padding-top: 0; }

7. Checkbox-driven UI (no JavaScript)

/* Dark mode toggle */
body:has(#dark-toggle:checked) { background: oklch(15% 0.02 275); color: oklch(90% 0 0); }

/* Show/hide sidebar */
.layout:has(#sidebar-toggle:checked) .sidebar { display: block; }

8. Quantity queries

/* List with more than 3 items gets compact style */
.list:has(:nth-child(4)) { font-size: 0.85rem; gap: 0.25rem; }

/* Grid changes columns based on item count */
.grid:has(:nth-child(7)) { grid-template-columns: repeat(4, 1fr); }

9. Focus-within alternative

/* Container reacts to focused input inside */
.search-box:has(input:focus) { box-shadow: 0 0 0 3px oklch(55% 0.2 275 / 0.2); }

10. Conditional decorations

/* Add separator only between sections that both exist */
section:has(+ section)::after { content: ""; display: block; border-bottom: 1px solid oklch(90% 0 0); }

11-20: More patterns

/* 11. Style nav differently when page has a banner */
body:has(.banner) .nav { position: absolute; }

/* 12. Highlight table row with checked checkbox */
tr:has(input:checked) { background: oklch(92% 0.06 275); }

/* 13. Adjust grid when aside is present */
main:has(+ aside) { grid-column: span 2; }

/* 14. Show tooltip only when content overflows (with resize observer) */
.cell:has(.truncated) .tooltip { display: block; }

/* 15. Different heading style when followed by subtitle */
h1:has(+ .subtitle) { margin-bottom: 0.25rem; }

/* 16. Card footer only when actions exist */
.card:has(.card-actions) { padding-bottom: 0; }

/* 17. Style based on media inside */
.post:has(video) { border-color: oklch(55% 0.2 275); }
.post:has(audio) { border-color: oklch(55% 0.2 150); }

/* 18. Required field group styling */
fieldset:has(:required) legend::after { content: " (required)"; }

/* 19. Pagination hides when single page */
.pagination:not(:has(:nth-child(2))) { display: none; }

/* 20. Auto-apply grid to containers with many children */
.auto-layout:has(:nth-child(3)) { display: grid; grid-template-columns: repeat(auto-fit, minmax(200px, 1fr)); }
