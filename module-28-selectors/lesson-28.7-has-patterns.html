:has() Patterns Encyclopedia

The :has() pseudo-class is the "parent selector" CSS always needed. It selects an element based on what it contains or what follows it. Specificity: takes the specificity of its most specific argument. Here are 20 real-world patterns.

1. Parent with image

/* Card layout changes when it contains an image */
.card:has(img) {
  padding: 0;
  overflow: hidden;
}
.card:has(img) .card-body { padding: 1.5rem; }

2. Form with invalid field

/* Highlight the entire form when any field is invalid */
.form:has(:invalid) {
  border-color: oklch(55% 0.22 25);
  box-shadow: 0 0 0 3px oklch(55% 0.22 25 / 0.1);
}

3. Empty state detection

/* Show empty-state message when container has no children */
.container:not(:has(*))::after {
  content: "Nothing here yet.";
  color: oklch(60% 0.05 275);
  font-style: italic;
}

4. Sibling detection (adjacent)

/* Heading that is followed by a paragraph — reduce margin */
h2:has(+ p) { margin-block-end: 0.5rem; }

/* Heading NOT followed by paragraph — keep full margin */
h2:not(:has(+ p)) { margin-block-end: 1.5rem; }

5. Quantity query

/* Grid switches to 2 columns when 4+ items exist */
.grid:has(:nth-child(4)) {
  grid-template-columns: repeat(2, 1fr);
}
/* 6+ items: 3 columns */
.grid:has(:nth-child(6)) {
  grid-template-columns: repeat(3, 1fr);
}

6. Checkbox-driven UI

/* Toggle panel visibility via checkbox — no JS */
.toggle:has(input:checked) .panel {
  display: block;
  opacity: 1;
}
.toggle:not(:has(input:checked)) .panel {
  display: none;
}

7. Content-aware card

/* Card with badge gets extra top padding */
.card:has(.badge) { padding-block-start: 2.5rem; }
.card:has(.badge) .badge {
  position: absolute;
  top: 0.75rem;
  right: 0.75rem;
}

8. Nested open state

/* Nav highlights when any details inside is open */
.nav:has([open]) {
  background: oklch(95% 0.03 275);
  border-radius: 0.5rem;
}

9. Required field indicator

/* Label gets a visual marker when its input is required */
.field:has(:required) label::after {
  content: " *";
  color: oklch(55% 0.22 25);
  font-weight: 700;
}

10. Image aspect detection

/* Portrait image inside card changes layout */
.card:has(img[data-orient="portrait"]) {
  flex-direction: row;
}
.card:has(img[data-orient="landscape"]) {
  flex-direction: column;
}

11. Dark mode from data attribute

/* Scope dark mode without media query */
html:has([data-theme="dark"]) {
  color-scheme: dark;
  --surface: oklch(15% 0.02 275);
  --text: oklch(90% 0.02 275);
}

12. Focus-within alternative

/* More specific than :focus-within — only when input focused */
.search-box:has(input:focus) {
  box-shadow: 0 4px 12px oklch(55% 0.2 275 / 0.2);
  border-color: oklch(55% 0.2 275);
}

13. Conditional grid gap

/* Only add gap when multiple children exist */
.stack:has(> :nth-child(2)) { gap: 1.5rem; }

14. Table row with status

/* Highlight row containing an error badge */
tr:has(.status-error) {
  background: oklch(95% 0.05 25);
}
tr:has(.status-success) {
  background: oklch(95% 0.05 150);
}

15. Sticky header shadow on scroll

/* Sentinel element scrolled out of view triggers shadow */
html:has(.sentinel:not(.visible)) .site-header {
  box-shadow: 0 2px 8px oklch(0% 0 0 / 0.1);
  backdrop-filter: blur(8px);
}

16. Multi-select detection

/* Show toolbar when 2+ checkboxes are checked */
.bulk-actions:has(input:checked ~ input:checked) .toolbar {
  display: flex;
}

17. Last visible child styling

/* Style the last non-hidden item differently */
.list > :not([hidden]):has(~ [hidden]):not(:has(~ :not([hidden]))) {
  border-bottom: none;
}

18. Responsive component without container query

/* Wide card when it has both image and long text */
.card:has(img):has(.text-long) {
  grid-template-columns: 1fr 2fr;
}

19. Accordion — dim closed items

/* When any panel is open, dim the closed ones */
.accordion:has(details[open]) details:not([open]) {
  opacity: 0.7;
}

20. Page-level style based on content

/* Hero section present — remove top margin from main */
body:has(.hero) main { margin-block-start: 0; }

/* Sidebar present — switch to grid layout */
body:has(.sidebar) .layout {
  display: grid;
  grid-template-columns: 250px 1fr;
}

Specificity of :has()

:has() takes the specificity of its most specific argument:

SelectorSpecificity
.card:has(img)(0, 1, 1)
.card:has(.badge)(0, 2, 0)
.card:has(#hero)(1, 1, 0)
div:has(:nth-child(3))(0, 1, 1)
