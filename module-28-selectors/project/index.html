Functional Pseudo-Classes

SelectorPurposeSpecificity note
:not(S)Negation — excludes SSpecificity of S
:is(S1, S2)Matches any of the listHighest in list
:where(S1, S2)Same as :is() but...Always (0,0,0)

:is() and :where() are forgiving — invalid selectors in the list don't break the whole rule.

PatternEffect
