Pseudo-Elements

Pseudo-elements create virtual sub-parts of elements that you can style independently. From the classic ::before and ::after to modern additions like ::marker, ::backdrop, and ::view-transition-*, they extend what CSS can target without extra HTML.

::before and ::after

Insert generated content before or after an element's real content:

.required-label::after {
  content: " *";
  color: oklch(55% 0.22 25);
}

.card::before {
  content: "";
  position: absolute;
  inset: 0;
  background: linear-gradient(to bottom, transparent, oklch(0% 0 0 / 0.6));
}

Key rule: content is required (even if empty string). Without it, the pseudo-element doesn't render.

::first-line and ::first-letter

::first-line {
  font-weight: 600;
  color: oklch(35% 0.15 275);
}

::first-letter {
  font-size: 3em;
  float: inline-start;
  line-height: 0.8;
  margin-inline-end: 0.1em;
  color: oklch(50% 0.2 275);
}

Only a limited subset of CSS properties work on these (mainly font, color, background, and margin for ::first-letter).

::marker

Styles the bullet or number of list items:

li::marker {
  color: oklch(55% 0.2 275);
  font-weight: 700;
  font-size: 1.2em;
}

/* Custom counter markers */
ol li::marker {
  content: counters(list-item, ".") ". ";
}

::placeholder

input::placeholder {
  color: oklch(65% 0.05 275);
  font-style: italic;
}

::selection

::selection {
  background: oklch(55% 0.2 275 / 0.3);
  color: oklch(20% 0.1 275);
}

::backdrop

The layer behind a <dialog> or fullscreen element:

dialog::backdrop {
  background: oklch(0% 0 0 / 0.6);
  backdrop-filter: blur(4px);
}

::file-selector-button

input[type="file"]::file-selector-button {
  padding: 0.5rem 1rem;
  background: oklch(55% 0.2 275);
  color: white;
  border: none;
  border-radius: 0.375rem;
  cursor: pointer;
}

::details-content

Styles the content area of a <details> element (the part that expands):

details::details-content {
  padding: 1rem;
  background: oklch(97% 0.02 275);
  border-radius: 0 0 0.5rem 0.5rem;
}

::view-transition-* pseudo-elements

::view-transition-old(root) { animation: fade-out 200ms; }
::view-transition-new(root) { animation: fade-in 200ms; }
::view-transition-group(card) { animation-duration: 300ms; }
::view-transition-image-pair(card) { isolation: auto; }

Specificity

Pseudo-elements add (0, 0, 1) to specificity — same weight as a type selector.
