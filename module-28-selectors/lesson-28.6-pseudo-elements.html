Pseudo-Elements

Pseudo-elements create virtual sub-elements that don't exist in the DOM. They let you style specific parts of an element or inject decorative content without extra markup. Double-colon syntax (::) distinguishes them from pseudo-classes.

::before and ::after

Generate content before or after an element's actual content. Requires the content property (even if empty). Specificity: (0, 0, 1) for the pseudo-element itself.

/* Decorative arrow after links */
.link::after {
  content: " \2192";  /* right arrow */
  color: oklch(55% 0.2 275);
}

/* Decorative accent bar before headings */
.section-title::before {
  content: "";
  display: block;
  width: 3rem;
  height: 3px;
  background: oklch(55% 0.2 275);
  margin-block-end: 0.5rem;
}

When to use: Decorative elements that don't convey meaning — icons, separators, accents, quotation marks. Never use for essential content that should be accessible.

::first-line

Targets only the first rendered line of a block element. Responsive — adapts as the viewport changes. Limited properties: font, color, background, text-decoration, letter-spacing, word-spacing.

article p::first-line {
  font-weight: 700;
  color: oklch(35% 0.1 275);
}

::first-letter

Targets the first letter (or first punctuation + first letter) of a block element. Classic use: drop caps.

.article-body > p:first-of-type::first-letter {
  float: inline-start;
  font-size: 3.5em;
  line-height: 0.8;
  padding-inline-end: 0.1em;
  color: oklch(45% 0.2 275);
  font-weight: 700;
}

::marker

Styles list item markers (bullets, numbers). Limited but growing property support: color, content, font properties, animation.

li::marker {
  color: oklch(55% 0.2 275);
  font-weight: 700;
}

/* Custom counter marker */
ol li::marker {
  content: counters(list-item, ".") ". ";
  color: oklch(50% 0.15 200);
}

::placeholder

Styles placeholder text in form inputs. Only a subset of properties apply (color, font, text-transform, etc.).

input::placeholder {
  color: oklch(65% 0.05 275);
  font-style: italic;
}

::selection

Styles text highlighted by the user. Only color, background-color, text-decoration, and text-shadow apply.

::selection {
  background: oklch(80% 0.12 275);
  color: oklch(20% 0.05 275);
}

::backdrop

Styles the backdrop behind fullscreen elements or <dialog> modals. Sits in its own stacking layer.

dialog::backdrop {
  background: oklch(10% 0.02 275 / 0.7);
  backdrop-filter: blur(4px);
}

::file-selector-button

Styles the button inside <input type="file">.

input[type="file"]::file-selector-button {
  padding: 0.5rem 1rem;
  background: oklch(55% 0.2 275);
  color: white;
  border: none;
  border-radius: 0.375rem;
  cursor: pointer;
}

::details-content

Targets the expandable content area of a <details> element. Enables animation of open/close.

details::details-content {
  transition: height 300ms ease, opacity 300ms ease;
  overflow: hidden;
}

::scroll-marker and ::scroll-button

Part of the CSS Scroll Snap specification extensions. ::scroll-marker creates navigation dots for scroll containers; ::scroll-button() creates prev/next buttons.

.carousel::scroll-button(inline-start) {
  content: "\2190";
}
.carousel::scroll-button(inline-end) {
  content: "\2192";
}
.carousel > *::scroll-marker {
  content: "";
  width: 0.75rem;
  height: 0.75rem;
  border-radius: 50%;
  background: oklch(70% 0.1 275);
}

::view-transition pseudo-elements

Used with the View Transitions API. Target the old, new, and group snapshot elements during a transition.

::view-transition-old(root) {
  animation: fade-out 200ms ease;
}
::view-transition-new(root) {
  animation: fade-in 200ms ease;
}
::view-transition-group(hero) {
  animation-duration: 400ms;
}

Specificity of pseudo-elements

All pseudo-elements add (0, 0, 1) to the selector's specificity — the same weight as a type selector.

SelectorSpecificity
p::first-line(0, 0, 2)
.card::before(0, 1, 1)
#hero::after(1, 0, 1)
