Pseudo-Classes: State

State pseudo-classes target elements based on their current interaction or form state. From hover effects to validation styling, these selectors are the bridge between user action and visual feedback — no JavaScript required.

Interaction states

/* Mouse/pointer is over the element */
:hover { background: oklch(95% 0.03 275); }

/* Element is being clicked/pressed */
:active { transform: scale(0.98); }

/* Element has keyboard focus */
:focus { outline: 2px solid oklch(55% 0.2 275); outline-offset: 2px; }

/* Keyboard focus only (not click) — the modern way */
:focus-visible { outline: 2px solid oklch(55% 0.2 275); }

/* Any child inside this element has focus */
:focus-within { border-color: oklch(55% 0.2 275); }

:focus vs :focus-visible

:focus matches on any focus (click or keyboard). :focus-visible only matches when the browser determines focus should be visible — typically keyboard navigation. Use :focus-visible for outline styles so mouse users don't see focus rings.

Form states: enabled/disabled

:enabled  { cursor: pointer; }
:disabled { opacity: 0.5; cursor: not-allowed; }
:read-only  { background: oklch(95% 0.01 275); }
:read-write { background: white; }

Form states: checked/indeterminate

:checked { accent-color: oklch(55% 0.2 275); }
:indeterminate { opacity: 0.7; }
/* :indeterminate matches checkboxes in neither true nor false state */

Form validation states

:valid   { border-color: oklch(60% 0.2 150); }
:invalid { border-color: oklch(55% 0.22 25); }

:required { border-inline-start: 3px solid oklch(55% 0.2 275); }
:optional { border-inline-start: 3px solid oklch(80% 0.05 275); }

/* Input has placeholder text showing (field is empty) */
:placeholder-shown { color: oklch(60% 0 0); }

/* The default submit button or default option */
:default { font-weight: 700; }

Smart validation: avoid styling empty required fields as invalid

/* Only show invalid styles after user has interacted */
input:not(:placeholder-shown):invalid {
  border-color: oklch(55% 0.22 25);
  background: oklch(97% 0.02 25);
}

/* Or use :user-invalid (newer, better) */
input:user-invalid {
  border-color: oklch(55% 0.22 25);
}

Link states

:link    { color: oklch(50% 0.2 275); }   /* unvisited links */
:visited { color: oklch(45% 0.15 310); }  /* visited links */
:any-link { text-decoration: underline; } /* both visited and unvisited */

Note: :visited is heavily restricted for privacy — you can only change color-related properties.

Other state pseudo-classes

:target { scroll-margin-top: 2rem; }   /* matches URL fragment target */
:autofill { background: oklch(95% 0.05 80) !important; } /* browser-autofilled inputs */

Mini-exercise

Build a form with :focus-within on the parent container that changes its border color and adds a subtle box-shadow when any input inside is focused. Combine with :placeholder-shown to create a floating label effect: when the input is empty (placeholder shown), position the label over the input. When filled, move it above.
