:nth-child() Advanced Formulas

The An+B formula inside :nth-child() is a small programming language. Master it to target any pattern of elements: every 3rd, first 5, last 3, ranges, and the new "of S" filtered selector syntax.

The An+B formula explained

:nth-child(An+B) matches elements where the child index (1-based) satisfies the equation index = An + B for some non-negative integer n (n = 0, 1, 2, 3...).

FormulaMatchesUse case
2n (even)2, 4, 6, 8...Zebra striping
2n+1 (odd)1, 3, 5, 7...Alternate rows
3n3, 6, 9, 12...Every 3rd item
3n+11, 4, 7, 10...1st of each group of 3
4n+33, 7, 11, 15...3rd in each group of 4
-n+55, 4, 3, 2, 1First 5 items only
n+33, 4, 5, 6...Everything from 3rd onward
-n+33, 2, 1First 3 items only

Selecting first N items

/* First 5 items */
li:nth-child(-n+5) {
  font-weight: 700;
  color: oklch(45% 0.15 275);
}

/* First 3 — negative formula counts down from 3 */
.item:nth-child(-n+3) { background: oklch(92% 0.06 275); }

Selecting last N items

/* Last 3 items */
li:nth-last-child(-n+3) {
  opacity: 0.6;
  font-style: italic;
}

/* The very last one */
li:nth-last-child(1) { border-bottom: none; }

Selecting a range

/* Items 3 through 7 — combine two formulas */
li:nth-child(n+3):nth-child(-n+7) {
  background: oklch(90% 0.08 200);
  border-inline-start: 3px solid oklch(55% 0.2 200);
}

Skip the first N

/* Everything except the first item */
li:nth-child(n+2) { border-top: 1px solid oklch(90% 0 0); }

/* Skip first 3 */
.card:nth-child(n+4) { opacity: 0.8; }

Every Nth with offset

/* Every 4th starting from the 2nd: 2, 6, 10, 14... */
li:nth-child(4n+2) { background: oklch(92% 0.06 150); }

/* Every 3rd from end */
li:nth-last-child(3n) { font-weight: 700; }

The "of S" syntax (filtered nth-child)

The of S syntax filters which elements are counted. Only elements matching the selector S participate in the numbering.

/* 2nd highlighted item (only counting .highlight elements) */
li:nth-child(2 of .highlight) {
  background: oklch(85% 0.12 275);
}

/* Every odd visible item (not counting hidden ones) */
li:nth-child(odd of :not([hidden])) {
  background: oklch(97% 0.02 275);
}

/* First item of class .active */
.item:nth-child(1 of .active) {
  border-inline-start: 4px solid oklch(55% 0.2 275);
}

Zebra striping patterns

/* Standard zebra */
tr:nth-child(even) { background: oklch(97% 0.01 275); }

/* Grouped rows: stripe every other pair */
tr:nth-child(4n+1), tr:nth-child(4n+2) {
  background: oklch(95% 0.03 275);
}

/* Column striping in grids */
.grid > :nth-child(3n+2) { background: oklch(96% 0.02 200); }

Grid column targeting

/* In a 3-column grid: target the first column */
.grid > :nth-child(3n+1) { text-align: start; }

/* Middle column */
.grid > :nth-child(3n+2) { text-align: center; }

/* Last column */
.grid > :nth-child(3n+3) { text-align: end; }

Specificity

:nth-child() has specificity (0, 1, 0) — same as any pseudo-class. The "of S" syntax adds the specificity of S to that base.

SelectorSpecificity
li:nth-child(2n)(0, 1, 1)
:nth-child(3 of .active)(0, 2, 0)
.list > :nth-child(odd)(0, 2, 0)

Try it yourself

Mini-exercise

Create a 12-item grid that mimics a calendar row. Use :nth-child(7n) and :nth-child(7n+1) to highlight weekends. Use :nth-child(-n+7) to bold the first week. Use the "of S" syntax to select the 2nd item with class .event and give it a colored background.
