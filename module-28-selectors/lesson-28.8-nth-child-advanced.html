:nth-child() Advanced Formulas

The :nth-child(An+B) formula is more powerful than most developers realize. From selecting ranges to the new "of S" syntax for filtered matching, these patterns cover zebra striping, featured items, pagination, and quantity-aware layouts.

The An+B formula explained

A = the cycle size (repeat every A items). B = the offset (start position). For each n = 0, 1, 2, 3..., the formula produces matching positions:

:nth-child(3n)      /* n=0→0, n=1→3, n=2→6: every 3rd (3,6,9...) */
:nth-child(3n+1)    /* 1, 4, 7, 10 — first of every group of 3 */
:nth-child(2n)      /* = even: 2, 4, 6, 8 */
:nth-child(2n+1)    /* = odd: 1, 3, 5, 7 */

Pattern: First N items

/* First 5 items only */
:nth-child(-n+5) { font-weight: 700; }
/* n=0→5, n=1→4, n=2→3, n=3→2, n=4→1, n=5→0 (stops) */

The negative step (-n) counts down. Combined with a positive offset, it selects items from 1 up to that offset.

Pattern: Last N items

/* Last 3 items */
:nth-last-child(-n+3) { opacity: 0.6; }
/* Same logic but counting from the end */

Pattern: Everything from Nth onward

/* From the 4th item onward */
:nth-child(n+4) { font-size: 0.85rem; }
/* n=0→4, n=1→5, n=2→6: matches 4, 5, 6... */

Pattern: Range selection (items 3 through 7)

/* Items 3–7: combine "from 3rd" AND "first 7" */
:nth-child(n+3):nth-child(-n+7) {
  background: oklch(92% 0.06 275);
}
/* Must satisfy BOTH conditions: position >= 3 AND position <= 7 */

Pattern: Every 3rd starting from the 2nd

:nth-child(3n+2) { /* items 2, 5, 8, 11... */ }

Pattern: Skip first, style rest

/* All except the first item */
:nth-child(n+2) { border-top: 1px solid oklch(90% 0 0); }

The "of S" syntax (modern)

Select the Nth matching item of a filtered set:

/* The 2nd element that has class .active among siblings */
:nth-child(2 of .active) { font-weight: 700; }

/* First 3 visible items (not hidden) */
:nth-child(-n+3 of :not(.hidden)) { animation: fade-in 300ms; }

/* Every odd .card (ignoring non-card siblings) */
:nth-child(odd of .card) { background: oklch(97% 0.02 275); }

Without "of S", :nth-child counts ALL siblings regardless of class. With "of S", it filters first, then counts. This solves the classic problem of zebra-striping only visible rows in a filtered list.

Quantity queries with :nth-child

/* Style all items IF there are at least 4 */
.item:nth-last-child(n+4),
.item:nth-last-child(n+4) ~ .item {
  font-size: 0.85rem;
}

/* Style all items IF there are exactly 3 */
.item:nth-last-child(3):first-child,
.item:nth-last-child(3):first-child ~ .item {
  flex: 1 1 33%;
}

Combined with :nth-of-type

/* Every 2nd paragraph (ignoring other elements) */
p:nth-of-type(2n) { color: oklch(50% 0.1 275); }

/* First heading of each type */
:is(h1, h2, h3):first-of-type { margin-top: 0; }

Mini-exercise

Build a pagination component with 10 page buttons. Style the current page (5th item) using :nth-child(5). Then style items 3-7 with a range selector as "nearby pages" with a different background. Use :nth-child(-n+1) and :nth-last-child(-n+1) to style first/last as special navigation buttons.
