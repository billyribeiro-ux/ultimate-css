Lesson 17.2 · Micro-Interactions

Seven Loading Spinners, One System

Seven distinct spinner designs that all speak the same visual language. They share motion tokens for size and color, respect prefers-reduced-motion, and each demonstrates a different CSS animation technique — from simple rotation to SVG stroke manipulation to border-radius morphing.

The motion token system

Every spinner references two custom properties: --spinner-size (default 2rem) and --spinner-color (default oklch(55% 0.2 260)). This means any spinner can be dropped into any context and will adopt the local design tokens. Change the parent's custom property, all spinners in that scope update.

The seven patterns

1. Rotating ring

A border with only one side colored, spinning 360 degrees infinitely. The simplest spinner and the most universally recognized. Uses border-top-color for the visible arc and transparent for the rest.

2. Pulsing dots

Three circles that scale up and down in sequence with staggered animation-delay. The delay creates a wave effect. Each dot uses the same keyframe but offset by one-third of the duration.

3. Bar equalizer

Five vertical bars with staggered scaleY animations. Reminiscent of an audio equalizer. Each bar's delay is offset by calc(var(--i) * -120ms) where --i is the bar's index.

4. Orbit

Two dots rotating around a shared center point at 180-degree offset. Uses a single rotation keyframe on the container, with dots positioned at opposite ends.

5. Skeleton shimmer

The Vercel-style diagonal gradient sweep across a placeholder rectangle. A linear gradient at 105 degrees, animated via background-position from left to right. The background-size is 200% so the gradient can slide through.

6. Progress ring (SVG)

An SVG circle with stroke-dasharray set to the circumference and stroke-dashoffset animated. The circle also rotates, creating the effect of a partially-drawn arc chasing itself around the ring.

7. Morphing shape

A single element whose border-radius cycles between circle (50%), rounded square (25%), and diamond (50% with rotation). Combined with a slow hue rotation on the background color for visual interest.

Reduced motion

Every spinner wraps its animation in a @media (prefers-reduced-motion: no-preference) check. When motion is reduced, the spinners show a static pulsing opacity (0.4 to 1, 2s duration) instead — still indicating "loading" without disorienting movement.

Mini-exercise

Create an eighth spinner: a "typing indicator" with three dots that bounce vertically in sequence (like iMessage). Use translateY and stagger each dot by 150ms. Then override --spinner-color on the parent to oklch(65% 0.18 145) and verify all spinners update to green simultaneously.
