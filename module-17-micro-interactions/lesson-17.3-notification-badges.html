Badges, Dots & Count Bubbles

The red notification dot. The count badge that bounces in. The "new" indicator that pulses. These tiny markers carry outsized importance — they guide attention, signal urgency, and must animate with precision so they feel informative rather than annoying.

The notification dot

The simplest badge: a small colored circle positioned at the top-right of an icon or avatar using ::after. The parent needs position: relative, and the dot is absolutely positioned with negative offsets to overlap the edge. Size is typically 8-12px. Color is the danger token: oklch(60% 0.25 25).

The count badge

When you need to show a number ("3 unread"), the badge becomes a pill-shaped element with min-width equal to its height (so a single digit is a circle) and horizontal padding for wider numbers. Above 99, display "99+" to prevent layout overflow. The font-size is typically 10-11px with font-weight 600.

Entry animation with @starting-style

The badge should bounce in when it first appears. Using @starting-style, we define the initial state as scale(0) and transition to scale(1) with a bounce easing (cubic-bezier(0.34, 1.56, 0.64, 1)). This fires automatically when the badge element is added to the DOM or when its display changes from none.

The "new" badge

A text badge ("NEW") with a pulsing box-shadow. The pulse uses a keyframe that animates box-shadow spread from 0 to 4px and back, with the same hue as the badge background but lower opacity. This creates a subtle "breathing" glow that draws the eye without being distracting.

Positioning strategies

The ideal approach uses CSS anchor positioning when supported. The badge anchors to the top-right corner of its target element. For browsers without support, absolute positioning with top: -4px; right: -4px is the fallback. The @supports(anchor-name: --badge) query handles the progressive enhancement.

Badge contexts

Badges appear on icons (nav items, toolbar buttons), on avatars (online status), and on cards (notification counts). Each context requires slightly different positioning offsets due to the varying shapes of the parent element.

Mini-exercise

Make the count badge animate when its number changes. Use a CSS class swap (e.g., .badge--updated) that triggers a quick scale bounce. Also add a "badge-remove" animation: when a badge disappears, it should scale down to 0 and fade out over 200ms rather than vanishing instantly. Use transition-behavior: allow-discrete with a transition on display.
