Lesson 17.11 · Micro-Interactions

Scroll-Triggered Animation Cookbook

Eight production scroll patterns — fade-up, slide-in, scale-up, counter tick-up, progress fill, parallax shift, header shrink, and text highlight sweep — all powered by animation-timeline: view() with progressive enhancement via @supports.

How scroll-driven animations work

The animation-timeline property replaces time with scroll progress. Instead of an animation running over 2 seconds, it runs from 0% to 100% of the element's visibility in the viewport. animation-timeline: view() binds to the element's own intersection with the scrollport. No JavaScript, no Intersection Observer.

The eight patterns

1. Fade up

Element starts at opacity: 0; translateY(2rem) and ends at opacity: 1; translateY(0). The animation range is entry 0% entry 50% so it completes by the time the element is half-visible.

2. Slide in left/right

Same as fade-up but using translateX(-3rem) or translateX(3rem). Alternating left/right on adjacent items creates a staggered reveal.

3. Scale up

Starts at scale(0.8); opacity: 0 and scales to full size. Great for cards and images that "pop" into view.

4. Counter tick-up

Uses @property to animate a registered custom property as an integer. The counter ticks from 0 to the target number as the element scrolls into view, displayed via counter() in a pseudo-element.

5. Progress fill

A horizontal bar that fills from 0% to its target width based on scroll position. Uses animation-timeline: scroll() bound to the nearest scroll container for a "reading progress" effect.

6. Parallax shift

Background or element moves at a different rate than scroll. Using animation-range: cover with a translateY from -20% to 20% creates depth.

7. Header shrink

The page header reduces padding and font-size as the user scrolls down. Uses animation-timeline: scroll(root) with a short range so it completes quickly.

8. Text highlight sweep

A gradient background sweeps across text using background-size animation from 0% to 100%, with background-clip: text.

Mini-exercise

Create a "reading progress" bar fixed at the top of the scroll container using animation-timeline: scroll() (document scroll, not view). The bar should fill from 0% to 100% width as the user scrolls the entire page. Then add a "staggered grid" where 6 cards animate in sequence using animation-delay combined with animation-timeline: view().
