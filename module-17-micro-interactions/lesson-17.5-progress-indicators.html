Progress Bars, Rings & Steps

Three progress patterns driven by a single --progress custom property: a linear bar with striped and indeterminate variants, a circular ring using conic-gradient, and a multi-step indicator with connecting lines. Change one value, everything updates.

The custom property approach

Every progress component reads --progress as a value from 0 to 100. The linear bar sets its width as calc(var(--progress) * 1%). The ring uses conic-gradient(oklch(55% 0.2 260) calc(var(--progress) * 1%), transparent 0). The step indicator checks thresholds. One property, three visualizations.

Linear bar

The bar track is a rounded container with a nested fill element. The fill transitions its width with a 300ms ease. A striped variant overlays a repeating-linear-gradient at 45 degrees with alternating semi-transparent stripes. The indeterminate variant uses an infinite sliding animation since progress is unknown.

Circular ring

The ring is a single element with a conic-gradient background, masked by a radial-gradient to punch out the center (creating the "ring" shape). A ::after pseudo-element displays the percentage text. The gradient rotates from the top using from 0deg at 50% 50%.

Step indicator

Steps are a flex row of numbered circles connected by lines. The line and circle colors change based on whether the step is completed (progress past its threshold). Each step is 25% of the total, so step 2 activates at --progress: 50. The connecting line fills progressively using a scaleX transform anchored from the left.

Accessibility

All progress indicators use role="progressbar" with aria-valuenow, aria-valuemin="0", and aria-valuemax="100". The indeterminate variant omits aria-valuenow entirely, signaling "progress unknown" to assistive technology.

Mini-exercise

Add a color threshold system: when --progress is below 33, the fill is red (oklch(55% 0.2 25)); between 33-66, yellow (oklch(75% 0.15 85)); above 66, green (oklch(55% 0.18 145)). Use style queries or gradient stops to achieve this. Also add a label inside the bar that shows the percentage text, positioned absolutely over the fill.
