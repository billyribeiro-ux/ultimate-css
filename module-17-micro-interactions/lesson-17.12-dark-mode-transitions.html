Lesson 17.12 · Micro-Interactions

Seamless Dark Mode Switching

A dark mode toggle built with light-dark(), :has(), smooth color transitions, a circular clip-path reveal animation, and image adaptation. The toggle is a checkbox that sets color-scheme on the root — no JavaScript needed for the core behavior.

The :has() technique

A checkbox with id="dark-toggle" lives in the page. The root selector :root:has(#dark-toggle:checked) sets color-scheme: dark. Since light-dark() responds to the computed color-scheme, every color in the page flips instantly. One checkbox controls everything.

Transitioning colors

To avoid a jarring snap, we add transition: background-color 300ms ease, color 300ms ease to the body and major containers. The key insight: transition only background and color, not "all" — transitioning all properties causes layout thrashing and janky behavior.

Circular clip-path reveal

For a dramatic mode switch, we can use view transitions with a clip-path: circle() animation. The new theme "reveals" from the toggle button's position as a growing circle. This uses ::view-transition-new(root) with a clip-path animation from circle(0%) to circle(150%).

Image adaptation

In dark mode, bright images can be harsh. We apply filter: brightness(0.85) saturate(1.1) to images when dark mode is active. This subtly dims images without making them look washed out. The saturate boost compensates for the perceived desaturation from brightness reduction.

The toggle animation

The toggle itself animates between a sun and moon icon. Using clip-path transitions, the sun circle morphs into a crescent moon shape. A "rays" element rotates and fades. The whole transition takes 400ms with a spring-like easing.
