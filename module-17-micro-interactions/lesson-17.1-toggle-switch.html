Lesson 17.1 · Micro-Interactions

The Perfect Toggle Switch

A custom checkbox styled as an iOS/Android-style toggle. The knob slides with cubic-bezier overshoot, the track color transitions smoothly, and the whole thing is built on a real checkbox so screen readers and keyboards work without a single line of JavaScript.

Why toggles matter

The toggle switch is the most common micro-interaction in product UI. Every settings page, every preference panel, every feature flag uses one. The difference between a checkbox with a label and a polished toggle is the difference between "functional" and "feels native." The motion is what sells it: the knob needs to slide, not teleport. The track color needs to transition, not snap.

The architecture

The toggle is built on a native <input type="checkbox">. The checkbox is visually hidden (not display: none — that removes it from the accessibility tree) but remains focusable. A sibling <span> element provides the visual track and knob. The :checked pseudo-class drives every visual change.

Sizing with custom properties

A single --toggle-size custom property controls everything. The track width is calc(var(--toggle-size) * 1.75), the track height is var(--toggle-size), and the knob diameter is calc(var(--toggle-size) - 4px). Change one value, the entire toggle scales proportionally.

The overshoot easing

The knob slides with cubic-bezier(0.34, 1.56, 0.64, 1) — this creates a slight bounce past the endpoint before settling. It takes 250ms. The track color transitions with a standard ease over 200ms. These two different timings create a layered, organic feel.

Theme-aware colors

The track uses light-dark() for its off-state color: light-dark(oklch(85% 0 0), oklch(30% 0 0)). The on-state uses the primary color token. This means the toggle looks correct in both light and dark modes without any media queries on the component itself.

The icon variant

The "with icon" variant places a checkmark and X inside the knob using clip-path. The checkmark is a polygon path, the X is built from two rotated rectangles. These swap on toggle with an opacity transition so the icon morphs smoothly.

Mini-exercise

Add a "danger" variant that uses a red track color (oklch(55% 0.2 25)) when checked. Then create an extra-small size variant at --size: 0.75rem and verify the knob still has enough padding. Finally, add a :disabled style that reduces the toggle's opacity to 0.5 and sets cursor: not-allowed on the label.
