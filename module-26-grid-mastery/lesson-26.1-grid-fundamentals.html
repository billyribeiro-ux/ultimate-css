Grid Fundamentals: Tracks, Cells, and Areas

Every grid layout begins with display: grid and track definitions. Understanding the difference between explicit tracks (you define them) and implicit tracks (the browser auto-creates them) is the key to predictable layouts.

The mental model

A grid container creates a coordinate system of rows and columns. The intersections form cells. A rectangular collection of cells is an area. The columns and rows themselves are tracks.

Defining columns and rows

.grid {
  display: grid;
  grid-template-columns: 200px 1fr 1fr;
  grid-template-rows: auto 1fr;
  gap: 1rem;
}

This creates 3 column tracks (one fixed, two flexible) and 2 row tracks. The fr unit distributes remaining space proportionally — 1fr 1fr means equal shares.

The fr unit

fr stands for "fraction of available space." It only divides what remains after fixed tracks, min-content, and gaps are accounted for. 1fr 2fr gives the second column twice the remaining space of the first.

gap

gap (shorthand for row-gap and column-gap) adds gutters between tracks without affecting the outer edges. Unlike margins, gaps never collapse and never affect the first/last item.

Explicit vs implicit tracks

Explicit tracks are the ones you define with grid-template-columns and grid-template-rows. Implicit tracks are created by the browser when items are placed beyond your explicit grid.

.grid {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  /* No rows defined — they're all implicit */
  grid-auto-rows: minmax(8rem, auto);
}

grid-auto-rows sizes implicit rows. Without it, implicit rows are auto-sized (shrink to content). Set it to control minimum heights for unknown quantities of items.

repeat() notation

repeat(3, 1fr) is shorthand for 1fr 1fr 1fr. You can repeat patterns: repeat(3, 1fr 2fr) creates 6 columns alternating 1fr and 2fr.

minmax() for flexible tracks

minmax(min, max) defines a track that is at least min and at most max. The most common pattern:

grid-template-rows: minmax(8rem, auto);
/* Row is at least 8rem, grows with content */

grid-template-columns: minmax(200px, 1fr);
/* Column is at least 200px, takes available space */

Track sizing keywords

  • auto — sizes to content (as min: largest min-content, as max: largest max-content)
  • min-content — the smallest the track can be without overflow
  • max-content — the ideal size if space were unlimited
  • fit-content(value) — clamps max-content at the given value

Grid terminology summary

  • Grid container — the element with display: grid
  • Grid item — direct children of the container
  • Track — a row or column
  • Line — the boundary between tracks (numbered starting at 1)
  • Cell — the intersection of one row track and one column track
  • Area — a rectangular set of cells

Common mistakes

Setting display: grid on an element does NOT make its grandchildren grid items. Only direct children participate in the grid layout. Nested elements need their own grid or flex context.

Using percentage-based gaps can cause overflow. Prefer rem or em for gap values. The fr unit accounts for gaps automatically — percentages don't.

The grid inspector

Every modern browser has a grid inspector in DevTools. It overlays line numbers, track sizes, and area names directly on the page. Always use it when debugging grid layouts — it makes invisible track boundaries visible.

Try it yourself

Mini-exercise

Change the grid to 4 columns using repeat(4, 1fr). Add 8 items and observe how implicit rows form. Then set grid-auto-rows: 10rem to control their height. Finally, try gap: 0.5rem 2rem for different row and column gaps.

Next, define explicit rows with grid-template-rows: 4rem 8rem. Add 9 items — the first 8 fill the explicit 2 rows of 4 columns, and the 9th creates an implicit third row. Compare the implicit row height with and without grid-auto-rows set.

Try mixing units: grid-template-columns: 200px 2fr 1fr. The first column is fixed, the second gets twice the remaining space of the third. Resize the container and observe that only the fr columns resize.

Key takeaways

  • display: grid turns an element into a grid container
  • grid-template-columns and grid-template-rows define explicit tracks
  • The fr unit distributes remaining space proportionally
  • gap adds gutters between (not around) tracks
  • grid-auto-rows controls the size of implicitly created rows
  • repeat() reduces repetition in track definitions
  • minmax() creates tracks with minimum and maximum size constraints
