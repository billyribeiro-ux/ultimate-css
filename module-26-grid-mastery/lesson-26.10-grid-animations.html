Lesson 26.10 · Layout

Animating Grid Layouts

CSS can now transition grid-template-columns and grid-template-rows. This enables smooth sidebar collapses, expanding panels, and layout morphs — all with pure CSS transitions.

What's animatable

  • grid-template-columns — track sizes interpolate between values
  • grid-template-rows — same as columns
  • gap — interpolates as a length

Track values must be compatible for interpolation: 20rem 1fr can transition to 0fr 1fr because both have 2 tracks. You cannot animate between different numbers of tracks.

The sidebar collapse pattern

.layout {
  display: grid;
  grid-template-columns: 20rem 1fr;
  transition: grid-template-columns 300ms ease;
}
.layout.collapsed {
  grid-template-columns: 0fr 1fr;
}

The sidebar smoothly collapses from 20rem to 0. Content in the sidebar should have overflow: hidden to avoid visual artifacts during the transition.

Using 0fr vs 0px

0fr transitions smoothly because both values use the same unit type (fr). Using 0px against 20rem also works because they're both absolute lengths. But 0px to 1fr won't interpolate — use 0fr instead.

Animating gap

.grid {
  gap: 1rem;
  transition: gap 200ms ease;
}
.grid:hover {
  gap: 2rem;
}

Combined with @starting-style

.grid-item {
  transition: opacity 300ms, transform 300ms;
  @starting-style {
    opacity: 0;
    transform: translateY(1rem);
  }
}

Items entering the grid animate in from their starting style.

Multi-panel layouts

.panels {
  display: grid;
  grid-template-columns: 1fr 1fr 1fr;
  transition: grid-template-columns 400ms ease;
}
.panels.left-expanded {
  grid-template-columns: 2fr 1fr 1fr;
}
.panels.center-expanded {
  grid-template-columns: 1fr 2fr 1fr;
}

Clicking a panel expands it smoothly. The fr units interpolate naturally, so adjacent panels compress proportionally.

Accordion with grid rows

.accordion {
  display: grid;
  grid-template-rows: auto 0fr auto 0fr auto 0fr;
  transition: grid-template-rows 300ms ease;
}
.accordion.open-first {
  grid-template-rows: auto 1fr auto 0fr auto 0fr;
}

Alternating header (auto) and content (0fr/1fr) rows. The content rows transition from 0fr (collapsed) to 1fr (open). Content must have overflow: hidden and min-height: 0 for clean collapse.

Limitations

  • Cannot animate between different numbers of tracks
  • auto tracks don't interpolate with fr tracks — use 0fr instead of 0
  • grid-template-areas cannot be animated — only the track sizes change
  • Performance is good for small grids; avoid animating grids with 50+ items

The interpolate-size property

For animating between auto and a fixed size, use interpolate-size: allow-keywords on the container. This enables transitions like grid-template-rows: auto to grid-template-rows: 0 that would otherwise snap:

.grid {
  interpolate-size: allow-keywords;
  transition: grid-template-rows 300ms;
}

Combining with view transitions

Grid animations pair well with the View Transitions API for page-level layout morphs. The grid handles the structural change; view transitions handle the cross-fade and element continuity.
