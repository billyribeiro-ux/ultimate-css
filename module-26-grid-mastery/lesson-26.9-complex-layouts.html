Lesson 26.9 · Layout

Complex Layouts Only Grid Can Build

Some layouts are impossible (or absurdly complex) without CSS Grid. The full-bleed pattern, overlapping elements without absolute positioning, and the pancake stack are patterns that showcase Grid's unique power.

The full-bleed pattern

Content constrained to a max-width, but some elements (images, banners) break out to fill the full viewport width:

.content {
  display: grid;
  grid-template-columns: 1fr min(65ch, 100%) 1fr;
}
.content > * {
  grid-column: 2;
}
.content > .full-bleed {
  grid-column: 1 / -1;
}

The outer 1fr columns act as gutters. Normal content sits in the middle. Full-bleed items span all three.

The pancake stack

.page {
  display: grid;
  grid-template-rows: auto 1fr auto;
  min-height: 100vh;
}

Header and footer size to content (auto). Main stretches to fill remaining space (1fr). Footer always at the bottom — no sticky footer hacks needed.

Overlapping elements (no position:absolute)

.stack {
  display: grid;
}
.stack > * {
  grid-area: 1 / 1;  /* all items occupy the same cell */
}
.stack .overlay {
  align-self: end;
  padding: 1rem;
  background: oklch(0% 0 0 / 0.6);
  color: white;
}

Items placed in the same grid area overlap naturally. Source order determines stacking (later = on top). No position: absolute, no z-index battles, no collapsed containers.

The sidebar that matches content height

.layout {
  display: grid;
  grid-template-columns: 16rem 1fr;
}
/* Sidebar and content automatically have equal height */

Grid items stretch to fill their row by default. The sidebar always matches the content height — no height: 100%, no flexbox column hacks.

The responsive full-bleed with popout

An extended version of the full-bleed pattern with multiple width levels:

.content {
  display: grid;
  grid-template-columns:
    [full-start] 1fr
    [popout-start] 1fr
    [content-start] min(60ch, 100%)
    [content-end] 1fr
    [popout-end] 1fr
    [full-end];
}
.content > *        { grid-column: content; }
.content > .popout  { grid-column: popout; }
.content > .full    { grid-column: full; }

Three width levels: normal content, popout (wider), and full bleed. Common in blog layouts where images should be wider than text.

Overlapping for hero sections

.hero {
  display: grid;
  grid-template-rows: 1fr auto 1fr;
}
.hero > * { grid-column: 1; }
.hero .image { grid-row: 1 / -1; }
.hero .text  { grid-row: 2; z-index: 1; }

The image fills all rows, the text sits vertically centered (row 2 of 3) on top. Clean, no absolute positioning, no transform centering tricks.

Why "only grid"?

These layouts require simultaneous control of both axes, overlapping without removing elements from flow, or spanning items across tracks. Flexbox cannot overlap items in flow, cannot do full-bleed without negative margins, and cannot align items across both axes simultaneously.

The sticky sidebar in grid

.layout {
  display: grid;
  grid-template-columns: 16rem 1fr;
  align-items: start;
}
.sidebar {
  position: sticky;
  top: 1rem;
}

Grid makes the sidebar match content height (stretch is default). Override with align-items: start on the container, then use position: sticky on the sidebar. It sticks while the main content scrolls — a common dashboard pattern.

Full viewport layouts

.app {
  display: grid;
  grid-template-columns: auto 1fr;
  grid-template-rows: auto 1fr auto;
  height: 100vh;
  overflow: hidden;
}
.app .content { overflow-y: auto; }

The app fills the viewport exactly. The content area scrolls independently. No need for position: fixed on the header or sidebar. Grid handles all sizing constraints in one declaration.

Try it yourself

Mini-exercise

Extend the full-bleed grid to include a "popout" level: grid-template-columns: 1fr 1fr min(50ch, 100%) 1fr 1fr. Add a .popout class with grid-column: 2 / -2 — it breaks out partially but not to full width. This "wide" content pattern is common in articles with wider images.

Then create a pancake stack layout: grid-template-rows: auto 1fr auto with min-height: 100vh. Add a header, main, and footer. Notice the footer stays at the bottom regardless of content length. Try removing the min-height and observe the difference.

Key takeaways

  • Full-bleed: 1fr min(65ch, 100%) 1fr with children in column 2, bleed items at 1 / -1
  • Pancake stack: grid-template-rows: auto 1fr auto pins header/footer
  • Overlap: same grid-area stacks items without absolute positioning
  • Equal-height sidebar: grid items stretch to fill rows by default
  • These patterns are impossible or extremely complex without grid
