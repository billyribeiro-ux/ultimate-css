Auto-Placement Algorithm: Dense Packing

When you don't explicitly place every item, CSS Grid's auto-placement algorithm decides where things go. The dense keyword fills gaps left by larger items — perfect for photo grids and dashboards.

grid-auto-flow

.grid {
  display: grid;
  grid-template-columns: repeat(4, 1fr);
  grid-auto-flow: row;      /* default: fill row by row */
  grid-auto-flow: column;   /* fill column by column instead */
  grid-auto-flow: dense;    /* fill gaps (same as "row dense") */
}

The problem dense solves

Imagine a 4-column grid with one item spanning 2 columns. If that item is the 3rd in source order and starts at column 3, there's only 1 column left — it wraps to the next row, leaving a gap. Without dense, that gap stays empty. With dense, the algorithm backtracks and fills it with smaller items.

The trade-off

dense reorders visual presentation away from source order. For decorative grids (photo galleries), this is fine. For content with a meaningful reading order (articles, navigation), avoid it.

Implicit track sizing

.grid {
  grid-auto-rows: minmax(8rem, auto);    /* implicit rows */
  grid-auto-columns: 1fr;               /* implicit columns */
}

Control the size of tracks the browser creates automatically when items overflow your explicit grid.

The magazine layout pattern

.grid { grid-auto-flow: dense; }
.featured {
  grid-column: span 2;
  grid-row: span 2;
}

One item takes a 2x2 area. The rest fill in around it automatically with dense packing.

Row vs column flow

Default grid-auto-flow: row places items left-to-right, then wraps to the next row. With grid-auto-flow: column, items fill top-to-bottom, then move to the next column. This is useful for newspaper-style layouts where content flows down columns.

.newspaper {
  display: grid;
  grid-template-rows: repeat(5, auto);
  grid-auto-flow: column;
  grid-auto-columns: 1fr;
}

Controlling placement with order

The order property affects auto-placement order. Items with lower order values are placed first. Combined with dense, this gives you control over which items fill gaps:

.priority-item { order: -1; }  /* placed before order:0 items */

When NOT to use dense

  • Navigation menus — visual order must match DOM order for accessibility
  • Form fields — users expect top-to-bottom/left-to-right order
  • Article content — paragraphs must stay in reading order
  • Any interactive content where tab order matters

Dense is perfect for decorative grids: photo galleries, dashboards with independent widgets, product thumbnails, or any layout where items have no sequential relationship.

Try it yourself

Mini-exercise

Remove the word dense from grid-auto-flow and observe the gaps that appear. Then add it back. Try changing to grid-auto-flow: column dense — items now fill column-first. Make item 7 span 2 columns and watch dense packing rearrange the grid to fill the hole.

Add order: -1 to items 6 and 7. With dense packing, they fill earlier gaps. Without dense, they just appear first in flow but gaps remain. This demonstrates how order affects the auto-placement algorithm.

Key takeaways

  • grid-auto-flow: row (default) fills left-to-right, top-to-bottom
  • grid-auto-flow: column fills top-to-bottom, left-to-right
  • dense backtracks to fill gaps left by larger items
  • grid-auto-rows and grid-auto-columns size implicit tracks
  • Use dense only for decorative/independent content (not sequential reading order)
  • The order property affects which items are placed first
