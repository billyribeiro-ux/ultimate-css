Subgrid: Nested Alignment Patterns

Subgrid lets child elements participate in a parent's grid tracks. This solves the "content alignment across siblings" problem — card headings that line up, form labels that align, pricing tiers that match — without JavaScript or fixed heights.

The problem

You have 4 cards in a grid. Each card has a heading, description, and button. The headings are different lengths, so the descriptions start at different vertical positions. Without subgrid, you'd need fixed heights or JS to align them.

The solution

.card-grid {
  display: grid;
  grid-template-columns: repeat(4, 1fr);
  grid-template-rows: subgrid; /* not here — on the children */
  gap: 1rem;
}

/* Each card spans 3 rows and uses parent's row tracks */
.card {
  grid-row: span 3;
  display: grid;
  grid-template-rows: subgrid;
  gap: 0.75rem;
}

The card becomes a grid that inherits its row tracks from the parent. All cards share the same row lines, so headings align across cards, descriptions align, and CTAs align.

How subgrid works

  • Set grid-template-rows: subgrid (or columns) on a grid item that is also display: grid
  • The item adopts the parent's tracks for that axis instead of defining its own
  • The item must span multiple tracks in the parent for subgrid to be useful
  • You can subgrid one axis and define the other normally

Form alignment pattern

.form-grid {
  display: grid;
  grid-template-columns: auto 1fr;
  gap: 0.5rem 1rem;
}
.form-row {
  display: grid;
  grid-column: 1 / -1;
  grid-template-columns: subgrid;
}

Labels and inputs align across all rows because they share the parent's column tracks.

Try it yourself

Mini-exercise

Remove grid-template-rows: subgrid from .card and watch the buttons misalign. Add it back. Then add a 4th row to the parent (grid-template-rows: auto auto 1fr auto), add an image placeholder <div> to each card, update grid-row: span 4, and see how all 4 rows now align across cards.

Try subgrid on the column axis instead: create a form where each row has a label and input, and use grid-template-columns: subgrid on each row to align labels and inputs across all rows.

Subgrid vs nested grid

A nested grid (regular display: grid) creates its own independent track system. A subgrid inherits the parent's tracks. Use subgrid when siblings need to share alignment; use a regular nested grid when the child's internal layout is independent.

Browser support

Subgrid is supported in all modern browsers since 2023. For older browsers, the fallback is a regular grid with fixed row heights — less elegant but functional.

Key takeaways

  • grid-template-rows: subgrid inherits parent row tracks
  • The subgrid item must span multiple parent tracks to be useful
  • You can subgrid one axis and define the other independently
  • Subgrid solves cross-sibling alignment (cards, forms, pricing tables)
  • Subgrid items still participate in the parent's gap
  • Subgrid can be nested: a subgrid's child can also be a subgrid, propagating tracks down multiple levels

Named lines in subgrid

You can add local named lines to a subgrid for convenience:

.card {
  grid-template-rows: subgrid [card-top] [card-mid] [card-bottom];
}
/* These names only exist within the card's context */
