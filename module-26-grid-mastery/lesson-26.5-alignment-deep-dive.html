Grid Alignment: justify, align, place

Grid has 6 alignment properties that control how items sit within their cells and how the grid itself sits within its container. Mastering these eliminates the need for margin hacks forever.

The 6 properties

PropertyApplies toAxis
justify-itemsAll items in cellsInline (horizontal)
align-itemsAll items in cellsBlock (vertical)
justify-contentThe grid in containerInline (horizontal)
align-contentThe grid in containerBlock (vertical)
justify-selfSingle item in cellInline (horizontal)
align-selfSingle item in cellBlock (vertical)

-items vs -content

-items aligns children within their grid cells. -content aligns the entire grid within its container (only visible when the grid is smaller than its container).

place- shorthands

place-items: center;           /* align-items + justify-items */
place-content: center;         /* align-content + justify-content */
place-self: end center;        /* align-self: end; justify-self: center */

Values

  • stretch — fill the entire cell (default for items)
  • start — pack to the start edge
  • end — pack to the end edge
  • center — center in the cell/container
  • space-between, space-around, space-evenly — distribute (content only)

The perfect centering

.container {
  display: grid;
  place-items: center;
  min-height: 100vh;
}

Two lines to center anything both horizontally and vertically.

When -content matters

justify-content and align-content only have a visible effect when the grid is smaller than its container. This happens when:

  • You use fixed track sizes (e.g., repeat(3, 8rem)) in a wider container
  • You use max-content or fit-content() tracks
  • The container has an explicit height larger than the grid's row tracks

With fr tracks, the grid always fills its container — so -content properties have no effect.

Alignment and writing modes

In left-to-right languages, justify-* is horizontal and align-* is vertical. In vertical writing modes, they swap. The properties follow the logical axes: inline (justify) and block (align). This makes grid layouts automatically work in any writing direction.

The normal value

normal behaves like stretch for grid items (they fill their cell). It's the initial value for justify-items and align-items. For -content, normal behaves like start.

Practical patterns

/* Center everything in the grid */
.grid { place-items: center; }

/* Stretch horizontally, center vertically */
.grid { justify-items: stretch; align-items: center; }

/* Distribute tracks evenly, items fill cells */
.grid { place-content: space-evenly; place-items: stretch; }

/* One item overrides */
.special { place-self: end center; }

Alignment vs margins

In grid layouts, prefer alignment properties over margins for positioning. Margins on grid items push them away from cell edges but don't participate in the grid's alignment system. margin: auto on a grid item absorbs available space (similar to flexbox), which can be useful for one-off positioning — but alignment properties are more predictable and maintainable.

/* Instead of margin: auto, prefer: */
.item { justify-self: end; align-self: center; }

/* margin: auto still works for absorbing space: */
.item { margin-inline-start: auto; } /* push to end */

Baseline alignment

Grid also supports align-items: baseline and align-self: baseline. Items align so their first text baseline lines up — useful for cells with different font sizes or padding that still need text alignment.

.grid {
  align-items: baseline;
}
/* All items' first text lines align horizontally */

You can also use last baseline to align on the last line of text in each cell.

Key takeaways

  • -items properties align children within their cells
  • -content properties align the entire grid within its container
  • -self properties override alignment on individual items
  • place-* shorthands combine align and justify (block first, inline second)
  • stretch is the default for items — they fill their cells
  • place-items: center is the simplest centering technique in CSS

Try it yourself

Mini-exercise

Set justify-content: space-between and align-content: space-evenly. Notice how the grid tracks spread out within the container. Now change justify-items to stretch — items fill their cells horizontally. Give item E place-self: end start and observe it move to the bottom-left of its cell.
