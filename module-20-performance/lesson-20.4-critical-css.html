Lesson 20.4 · Loading

Critical CSS & Above-the-Fold Optimization

Critical CSS is the minimum CSS needed to render what the user sees first. Inline it in the HTML, load the rest asynchronously, and your First Contentful Paint drops by seconds. Here is the technique, the tooling, and the @layer advantage.

What is critical CSS?

When a browser encounters a <link rel="stylesheet">, it blocks rendering until that file is downloaded and parsed. If your stylesheet is 150KB, the user sees nothing until all 150KB arrive. Critical CSS solves this by inlining only the CSS needed for the initial viewport directly in a <style> tag in <head>.

Identifying critical CSS

Open DevTools, go to the Coverage panel (Ctrl+Shift+P, type "coverage"), reload the page. The panel shows which CSS rules were used during initial render. Rules marked red were not used above the fold — they can be deferred.

The implementation pattern

<head>
  <!-- Critical CSS inlined -->
  <style>
    /* tokens, reset, base, header, hero — above fold only */
    :root { --brand: oklch(55% 0.22 265); }
    *, *::before, *::after { box-sizing: border-box; margin: 0; }
    body { font-family: system-ui; line-height: 1.6; }
    .header { /* ... */ }
    .hero { /* ... */ }
  </style>

  <!-- Rest loaded asynchronously -->
  <link rel="preload" href="full.css" as="style"
        onload="this.onload=null;this.rel='stylesheet'">
  <noscript><link rel="stylesheet" href="full.css"></noscript>
</head>

The preload + onload trick loads the full stylesheet without blocking render. Once loaded, it switches to a regular stylesheet link.

The @layer advantage

With PE7's layered architecture, critical CSS maps cleanly to layers:

  • Inline: @layer tokens, reset, base (these are small and needed everywhere)
  • Async: @layer layout, components, animations, overrides (these are larger and only needed as the user scrolls)

Because layers enforce cascade order regardless of load order, the async CSS won't cause FOUC (Flash of Unstyled Content) when it arrives — it slots into its designated layer.

The 14KB budget

The first TCP round-trip delivers approximately 14KB of compressed data. If your critical CSS fits within this budget (after Brotli compression), the browser can render the first frame without waiting for additional network round-trips. This is the performance sweet spot.

Tokens + reset + base = ~6.5KB (fits in 14KB budget)

<style> @layer tokens { :root { ... } } @layer reset { *, *::b... } @layer base { body { ... } } </style>

Try it yourself

Mini-exercise

Open DevTools Coverage panel on any website you work on. Reload and check how much CSS is actually used above the fold. Typical result: 10-25% of the CSS is critical. Extract that critical portion, inline it in a <style> tag, and defer the rest with the preload pattern. Measure the FCP improvement with Lighthouse.
