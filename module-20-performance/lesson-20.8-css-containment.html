Lesson 20.8 · Containment

CSS Containment: contain & container-type

The contain property is a performance contract between you and the browser. It says "changes inside this element won't affect the outside" — allowing the browser to skip expensive recalculations. Here is how each containment type works and when container queries add implicit containment.

contain: layout

Layout containment means the element's internal layout is independent from the rest of the page. If something inside changes size, the browser only recalculates layout within this element — not the entire page. This is the most impactful containment for performance.

.card {
  contain: layout;
}

contain: paint

Paint containment tells the browser that nothing inside this element will be painted outside its bounds. The element acts as a containing block for absolutely positioned descendants and establishes a stacking context. The browser can skip repainting this element if it's off-screen.

contain: style

Style containment isolates CSS counter effects and quotes auto-incrementing. It prevents a counter inside one component from affecting counters in sibling components. Lower impact than layout/paint, but useful for component isolation.

contain: size

Size containment means the element's size does not depend on its children. You must give it an explicit size. This is the most restrictive form — the element renders as if it has no children for sizing purposes. Rarely used alone, but combined with content-visibility, it enables the placeholder sizing behavior.

container-type: inline-size

When you use container-type: inline-size for container queries, the browser implicitly adds contain: layout style inline-size. This means every container query element already has performance-beneficial containment built in. You get containment for free with container queries.

When containment breaks things

  • Scrollable containers: contain: size can collapse a scrollable element to zero height if you forget to set explicit dimensions.
  • Overflow: contain: paint clips overflow, which may hide tooltips, dropdowns, or popovers that extend beyond the element.
  • Position: contain: layout establishes a new containing block, which changes how position: absolute descendants are positioned.

Try it yourself

Mini-exercise

Create a grid of 12 cards with contain: layout style paint. Add a hover effect that changes the card's internal content height (e.g., reveal a description). Without containment, hovering one card would trigger layout recalculation for all siblings. With containment, only the hovered card relayouts. Verify with DevTools Performance panel — look for the scope of "Layout" events.
