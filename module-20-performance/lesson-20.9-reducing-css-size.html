Lesson 20.9 · File Size

Reducing CSS File Size

Every kilobyte of CSS blocks rendering. From dead code elimination to custom property deduplication to compression algorithms — here are the techniques that take a 45KB stylesheet down to 12KB without losing a single feature.

Audit with DevTools Coverage

Open DevTools, press Ctrl+Shift+P, type "coverage", start recording, reload the page. The Coverage panel shows exactly which CSS rules are used on the current page. Red = unused. On most sites, 60-80% of CSS is unused on any given page.

@layer helps removal

With PE7's layered architecture, you can remove entire layers without cascade fear. If a page doesn't use animations, remove the animations layer. If it doesn't have components of a certain type, remove that component file. Layers make CSS modular and safely removable.

Dead CSS detection patterns

  • Search for class names in CSS that don't appear in any HTML/JS file
  • Look for vendor-prefixed properties that are no longer needed (-webkit-transform when you only support modern browsers)
  • Find duplicate selectors with identical rules
  • Remove commented-out CSS (it still adds bytes)

Custom property deduplication

Before: 20 places using oklch(55% 0.22 265) directly. After: one token --color-brand: oklch(55% 0.22 265) referenced 20 times. This saves bytes AND improves maintainability.

/* Before: 45 bytes per usage x 20 = 900 bytes */
.hero { background: oklch(55% 0.22 265); }
.btn  { background: oklch(55% 0.22 265); }

/* After: 45 bytes once + 20 bytes per usage x 20 = 445 bytes */
:root { --brand: oklch(55% 0.22 265); }
.hero { background: var(--brand); }
.btn  { background: var(--brand); }

Shorthand vs longhand

/* Longhand: 82 bytes */
margin-top: 1rem;
margin-right: 2rem;
margin-bottom: 1rem;
margin-left: 2rem;

/* Shorthand: 22 bytes */
margin: 1rem 2rem;

Use shorthands when all sides are set. Use longhands when you need to override only one side (avoids resetting the others).

Compression: Brotli vs Gzip

CSS compresses exceptionally well due to repetitive patterns. Typical results:

  • Gzip: 60-70% reduction (45KB becomes ~15KB over the wire)
  • Brotli: 70-80% reduction (45KB becomes ~10KB over the wire)

Brotli is supported by all modern browsers. Configure your server to serve .css files with Content-Encoding: br.

The 14KB target

Critical CSS should fit in 14KB compressed (the first TCP congestion window). Total CSS for a page should target under 50KB compressed. If you're over these numbers, audit and reduce.

Try it yourself

Mini-exercise

Take a real stylesheet from a project you're working on. Run DevTools Coverage panel and note the percentage of unused CSS. Then: (1) Extract repeated color values into custom properties, (2) convert longhands to shorthands where possible, (3) remove any CSS rules not used on any page. Measure the file size before and after. Target: at least 30% reduction.
