Lesson 20.7 · Images

Image Performance via CSS

Images are the largest contributors to layout shift and page weight. CSS provides powerful tools to prevent shift (aspect-ratio), control rendering (object-fit), defer work (content-visibility), and optimize display (image-rendering). Here is the full toolkit.

aspect-ratio: preventing layout shift

Without aspect-ratio, an image container has zero height until the image loads, then it snaps to the image's natural dimensions — causing layout shift. The fix:

img {
  aspect-ratio: 16 / 9;
  width: 100%;
  height: auto;
  object-fit: cover;
}

The browser reserves the correct space before the image loads. Zero CLS from images.

object-fit: responsive images without distortion

  • object-fit: cover — fills the container, crops excess (most common for cards/heroes)
  • object-fit: contain — fits entirely within the container, may leave gaps
  • object-fit: fill — stretches to fill (distorts the image)
  • object-fit: none — displays at natural size, clips if larger

content-visibility for image containers

Combine content-visibility: auto on image grid items to skip rendering of off-screen images entirely. The browser won't even decode the image data until the container approaches the viewport.

image-rendering

  • image-rendering: auto — browser chooses (default, good for photos)
  • image-rendering: crisp-edges — no smoothing (for pixel art, QR codes)
  • image-rendering: pixelated — nearest-neighbor scaling (retro game sprites)

The contain: inline-size pattern

In flex/grid layouts, images can blow out their container width. The pattern:

.image-container {
  container-type: inline-size;
  contain: inline-size;
}
.image-container img {
  width: 100%;
  height: auto;
}

background-image vs img element

<img> is better for performance: it supports loading="lazy", srcset, sizes, and is prioritized by the browser's preload scanner. background-image is only discovered when CSS is parsed — later in the pipeline. Use background-image only for decorative images that don't need lazy loading or responsive sources.

Try it yourself

Mini-exercise

Create an image gallery with 6 items. Apply aspect-ratio: 4/3 to each image container and object-fit: cover to the images. Run Lighthouse and check the CLS score. Then remove aspect-ratio and re-run — watch CLS increase. Add content-visibility: auto with contain-intrinsic-size: auto 200px to items below the fold for extra performance.
