Lesson 15.12 · Spectacular Effects

Hamburger-to-X Morph

A hamburger menu icon that morphs smoothly into an X on toggle. Three <span> elements transform: top and bottom rotate to form the X, middle shrinks away. Uses :has(input:checked) for pure CSS state — no JavaScript needed.

The morph mechanics

Three horizontal lines become an X through coordinated transforms. The top line translates down to the middle position and rotates 45 degrees. The bottom line translates up to the middle position and rotates -45 degrees. The middle line scales to scaleX(0) and fades out — it vanishes so the X cross is clean.

CSS-only state with :has()

A hidden <input type="checkbox"> inside the button provides the toggle state. The button uses :has(input:checked) to apply the morphed transforms. No JavaScript, no ARIA-toggling complexity — pure CSS state management. The <input> is visually hidden but remains accessible to screen readers.

The transition recipe

.hamburger span {
  display: block;
  width: 24px; height: 2px;
  background: currentColor;
  border-radius: 1px;
  transition: transform 300ms cubic-bezier(0.4, 0, 0.2, 1),
              opacity 300ms ease;
}
/* Top line → rotate to X */
.hamburger:has(input:checked) .top {
  transform: translateY(8px) rotate(45deg);
}
/* Middle line → vanish */
.hamburger:has(input:checked) .mid {
  transform: scaleX(0);
  opacity: 0;
}
/* Bottom line → rotate to X */
.hamburger:has(input:checked) .bot {
  transform: translateY(-8px) rotate(-45deg);
}

Try it yourself

Mini-exercise

Try changing the translateY value. The 8px matches the gap: 6px plus the line height (2px). If you change the gap, recalculate so the lines meet at center. Then try an arrow morph: instead of rotating to an X, rotate the top line to rotate(30deg) and bottom to rotate(-30deg) without translation — this creates a downward chevron, like a "close" hint.
