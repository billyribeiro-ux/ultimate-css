Lesson 15.9 · Spectacular Effects

Scroll-Driven 3D Tilt Gallery

A photo gallery where images tilt in 3D as they scroll through the viewport. Uses animation-timeline: view() with perspective for a cinematic depth-of-field effect that feels like a 3D carousel — all driven by scroll position, no JavaScript.

Scroll-driven animations meet 3D

The animation-timeline: view() property ties an animation's progress to an element's position within the viewport. Combined with perspective and rotateY, each card rotates as it enters, centers, and exits — creating a flowing 3D carousel effect that responds naturally to scroll speed.

The tilt arc

Each image animates from rotateY(-15deg) scale(0.9) (entering from right, smaller) through rotateY(0) scale(1) (centered, full size) to rotateY(15deg) scale(0.9) (exiting left, smaller). This creates a natural "arc" through 3D space — like cards on a rotating drum.

Progressive enhancement

Scroll-driven animations are not yet universally supported. The entire effect is wrapped in @supports (animation-timeline: view()). Without support, the gallery is a standard grid — functional, just not spectacular. This is the PE7 approach: the enhancement layer never breaks the foundation layer.

@supports (animation-timeline: view()) {
  .gallery-item {
    animation: tilt-through linear both;
    animation-timeline: view();
  }
}
@keyframes tilt-through {
  0%   { transform: rotateY(-15deg) scale(0.9); opacity: 0.5; }
  50%  { transform: rotateY(0) scale(1); opacity: 1; }
  100% { transform: rotateY(15deg) scale(0.9); opacity: 0.5; }
}

Try it yourself

Mini-exercise

Try changing rotateY to rotateX for a vertical tilt instead of horizontal. Then increase the rotation to 30deg for more dramatic perspective. Add translateZ(-50px) at the 0% and 100% keyframes to push cards "into" the screen as they enter and exit. Experiment with animation-range: entry exit to control when the animation starts and ends relative to the viewport.
