Infinite Scroll Marquee

A smooth, infinite horizontal scrolling strip — the "trusted by" logo ticker used on every SaaS landing page. The trick: duplicate the content, animate exactly 50%, and the loop is seamless. Pause on hover for accessibility.

The seamless loop math

The container holds two identical copies of the content side by side in a flex row. The total width is exactly 2x the content width. The animation translates by -50% (one full content width). When the second copy reaches where the first copy started, the animation loops — and since the copies are identical, the jump is invisible.

The pattern

.marquee { overflow: hidden; }
.marquee__track {
  display: flex;
  width: max-content;
  animation: marquee 20s linear infinite;
}
.marquee:hover .marquee__track {
  animation-play-state: paused;
}
@keyframes marquee {
  to { translate: -50% 0; }
}

Vertical variant

The same principle works vertically: stack the duplicated content in a column and animate translate: 0 -50%. Perfect for testimonial tickers or notification feeds.

Accessibility

Pause on :hover lets mouse users stop the motion. For keyboard and reduced-motion users, prefers-reduced-motion: reduce stops the animation entirely, showing all items in a static row.

Mini-exercise

Add animation-direction: reverse to scroll the other way. Then add a second marquee row below going in the opposite direction — this "opposing lanes" pattern is extremely common on marketing sites. Try speeding up to 10s and slowing down to 40s to find the sweet spot for readability versus energy.
