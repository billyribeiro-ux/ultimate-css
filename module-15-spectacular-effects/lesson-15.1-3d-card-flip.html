Lesson 15.1 · Spectacular Effects

3D Card Flip with Perspective

A card that flips 180 degrees on hover revealing a back face. The key ingredients: perspective on the parent, transform-style: preserve-3d on the card, backface-visibility: hidden on both faces, and a weighty cubic-bezier easing that makes the flip feel physical.

The 3D transform stack

CSS 3D transforms require three layers working together. The perspective container establishes the viewer's distance from the scene — lower values create more dramatic foreshortening. The card element uses transform-style: preserve-3d to tell the browser its children exist in the same 3D space. The faces use backface-visibility: hidden so only the front-facing side is visible at any angle.

Why 600ms, not 200ms?

Physical objects have mass. A 200ms flip feels digital — like toggling a boolean. A 600ms flip with cubic-bezier(0.4, 0.0, 0.2, 1) feels like an actual card rotating through space. The easing starts fast (the "push") and decelerates (air resistance). This is the Material Design standard easing, and it's perfect for 3D transforms.

Perspective-origin for drama

By default, the vanishing point is dead center. Shifting perspective-origin to, say, 75% 50% makes the card appear to rotate from an off-center viewpoint — like watching from the side of a stage. This subtle shift adds cinematic depth that most implementations miss.

The architecture

.scene       { perspective: 800px; }
.card        { transform-style: preserve-3d; transition: transform 600ms cubic-bezier(0.4,0,0.2,1); }
.card:hover  { transform: rotateY(180deg); }
.card__face  { backface-visibility: hidden; position: absolute; inset: 0; }
.card__back  { transform: rotateY(180deg); }

Mini-exercise

Try changing the perspective value from 800px to 300px — notice how much more dramatic the foreshortening becomes. Then try 2000px for an almost-flat rotation. Next, add perspective-origin: 100% 50% to the .scene and watch how the rotation axis seems to shift. Finally, change rotateY to rotateX for a top-to-bottom flip.
