Lesson 15.6 · Spectacular Effects

Neon Glow Text

Realistic neon sign text with animated flicker. Multiple text-shadow layers at increasing blur radii create the glow, while irregularly-timed keyframes simulate the characteristic flicker of gas-discharge tubes.

Building the neon glow

Real neon tubes have a bright core (the gas discharge itself) surrounded by a soft, wide glow (scattered light). We simulate this with multiple text-shadow layers at increasing blur radii — typically 5 layers from tight (7px) to wide (82px) in the same hue.

The text-shadow stack

text-shadow:
  0 0 7px   oklch(80% 0.18 190),
  0 0 10px  oklch(80% 0.18 190),
  0 0 21px  oklch(75% 0.20 190),
  0 0 42px  oklch(70% 0.22 190),
  0 0 82px  oklch(65% 0.25 190);

Irregular flicker

Real neon flickers irregularly — not evenly. The keyframes use unevenly spaced percentages (0%, 2%, 4%, 8%, 70%, 72%, 100%) with brief dips in opacity and shadow intensity. This asymmetry is what makes the flicker look genuine rather than like a simple pulse.

The power-on entrance

Using @starting-style, the neon sign "powers on" when first rendered — starting dim and building to full intensity. This entrance effect sells the illusion that these are real electrical tubes warming up.

Try it yourself

Mini-exercise

Add a third neon sign in amber/gold (oklch(80% 0.18 85)) with its own unique flicker timing. Then try adding @starting-style { .neon { opacity: 0; text-shadow: none; } } with a transition: opacity 1.5s, text-shadow 1.5s on .neon for a power-on entrance effect. The sign should warm up from dark to full glow when the page loads.
