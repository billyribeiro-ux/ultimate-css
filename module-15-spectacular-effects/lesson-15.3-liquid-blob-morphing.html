Lesson 15.3 · Spectacular Effects

Liquid Blob Morphing

The classic "liquid" effect: blobs that merge and separate like a lava lamp. Uses the filter: blur() contrast() CSS trick — a parent with high contrast clips blurred children into hard-edged organic shapes that fuse on overlap.

The blur-contrast trick

This is one of CSS's most satisfying visual hacks. The parent container gets filter: contrast(20) and a solid background (white or black). Children get filter: blur(20px) and solid-colored backgrounds. Here is why it works:

The science

A Gaussian blur spreads each pixel's color into its neighbors, creating soft, semi-transparent edges. When contrast(20) is applied to the parent, it crushes those soft edges into hard edges — pixels above 50% opacity become fully opaque, below become transparent. When two blurred shapes overlap, their combined opacity in the overlap zone crosses the threshold, and the contrast filter fuses them into one continuous organic shape.

The lava lamp pattern

Animate 4 blobs along different orbital paths using @keyframes. Each blob follows a different timing and path so they constantly merge and separate. The motion should be slow — 10-15 second cycles — to feel organic rather than frantic.

.lava-container {
  filter: contrast(20);
  background: oklch(0% 0 0);  /* must match desired bg */
}
.blob {
  filter: blur(20px);
  background: oklch(65% 0.25 160);
  border-radius: 50%;
  animation: orbit-1 12s ease-in-out infinite;
}

Try it yourself

Mini-exercise

Change the container background to oklch(100% 0 0) (white) and the blob colors to darker values. The same merging effect works in reverse. Then try reducing contrast() from 20 to 5 — the edges become softer and more organic. Try adding a fifth blob with oklch(70% 0.22 60) (warm gold) for a richer palette.
