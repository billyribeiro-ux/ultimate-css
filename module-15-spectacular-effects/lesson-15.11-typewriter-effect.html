Lesson 15.11 · Spectacular Effects

Typewriter Effect with Blinking Cursor

Text that types itself out character by character with a blinking cursor. Uses width animation with steps() timing, overflow: hidden, and white-space: nowrap. Multiple lines sequenced with animation-delay create a terminal-style output.

How the typewriter works

The text exists in full in the HTML — we are not generating characters. Instead, the element starts at width: 0 with overflow: hidden and white-space: nowrap, then animates to width: Nch where N is the character count. The ch unit equals the width of the "0" character — perfect for monospace fonts.

The steps() timing function

The key is steps(N) where N matches the character count. Instead of a smooth width transition, the animation jumps in exactly N discrete steps — revealing one character at a time. Without steps(), the text would smoothly slide in, destroying the typewriter illusion.

The blinking cursor

A border-inline-end: 3px solid on the text element creates the cursor line. A separate @keyframes blink toggles border-color to transparent at 50% for the classic terminal blink. The cursor blink runs independently of the typing animation.

Sequencing multiple lines

The second line's animation-delay equals the first line's total animation duration. The cursor on line 1 only blinks during its typing phase, then the cursor "moves" to line 2 by hiding line 1's border and showing line 2's.

Mini-exercise

Add a fourth line with your own custom message. Count the characters carefully — the steps() value and the ch width must match exactly. Then try changing the cursor blink speed from 0.7s to 1s — which feels more realistic? Add a slight animation-delay gap between lines (2 seconds instead of immediate) to simulate "thinking time."
