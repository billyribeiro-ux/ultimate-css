Lesson 15.2 · Spectacular Effects

The Holographic Card

An iridescent, rainbow-shifting card surface that looks like a holographic trading card. A conic-gradient of OKLCH rainbow hues layered with mix-blend-mode, animated with @property for a constant subtle shimmer — genuinely magical in pure CSS.

The holographic illusion

Holographic surfaces shift color based on viewing angle. We simulate this with a conic-gradient of rainbow hues layered over the card using mix-blend-mode: color-dodge at low opacity. The gradient's center position shifts on hover (via custom properties), creating the angle-reactive shimmer.

The @property animation trick

We register --holo-angle as an <angle> type with @property. This lets us animate it smoothly in a keyframe — something impossible with unregistered custom properties. The result: the rainbow pattern slowly rotates even at rest, creating that restless iridescence real holograms have.

Layer stack

/* Base card gradient */
background: linear-gradient(135deg, oklch(25% 0.08 280), oklch(15% 0.05 260));

/* Holographic overlay via ::after */
.card::after {
  background: conic-gradient(from var(--holo-angle) at var(--x, 50%) var(--y, 50%),
    oklch(70% 0.3 0), oklch(70% 0.3 60), oklch(70% 0.3 120),
    oklch(70% 0.3 180), oklch(70% 0.3 240), oklch(70% 0.3 300), oklch(70% 0.3 360));
  mix-blend-mode: color-dodge;
  opacity: 0.3;
}

Try it yourself

Mini-exercise

Try changing mix-blend-mode from color-dodge to overlay, hard-light, or screen — each creates a different holographic feel. Then increase the opacity to 0.5 for a more aggressive rainbow. For the ultimate effect, add a second ::after pseudo-element with a radial-gradient spotlight that follows hover position.
