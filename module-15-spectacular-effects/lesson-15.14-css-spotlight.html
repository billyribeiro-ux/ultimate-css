Lesson 15.14 · Spectacular Effects

CSS-Only Spotlight / Searchlight

A spotlight cone sweeping across a dark page, revealing content underneath. Uses an animated radial-gradient mask with @property for smooth position interpolation. The effect is dramatic and theatrical — content appears only where the light falls.

The mask-image technique

The content sits normally in the document, but a mask-image with a radial-gradient controls what is visible. The gradient goes from white (fully visible) at its center to transparent (hidden) at its edges, creating a circular "window" — the spotlight.

Animating the spotlight position

Register --spot-x and --spot-y as <percentage> types with @property. This lets the keyframes smoothly interpolate between positions. The spotlight sweeps from 10% 30% to 90% 70% and back, tracing an arc across the page.

@property --spot-x {
  syntax: "<percentage>";
  inherits: false;
  initial-value: 10%;
}
.spotlight-layer {
  mask-image: radial-gradient(
    circle 180px at var(--spot-x) var(--spot-y),
    white, transparent);
  animation: sweep 6s ease-in-out infinite alternate;
}
@keyframes sweep {
  0%   { --spot-x: 10%; --spot-y: 30%; }
  100% { --spot-x: 90%; --spot-y: 70%; }
}

Mini-exercise

Change the spotlight radius from 150px to 80px for a tighter beam, or 300px for a flood light. Try replacing the circular gradient with an ellipse: ellipse 200px 100px for an oval searchlight. Add a second spotlight by layering two gradients in the mask-image — use mask-composite: add to combine them.
