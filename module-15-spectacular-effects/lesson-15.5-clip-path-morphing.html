Lesson 15.5 · Spectacular Effects

Clip-Path Shape Morphing

Animate between complex shapes using clip-path: polygon() transitions. The critical insight: transitions only work smoothly when both states have the same number of points. Define every shape with 12 points and watch circles become stars become hexagons.

The same-point-count rule

CSS can interpolate clip-path: polygon() values — but only when both the start and end polygon have identical point counts. If the counts differ, the browser snaps instantly between states with no transition. The trick: define every shape (circle, star, hexagon, blob) using exactly 12 points, just positioned differently.

Building shapes from 12 points

A circle approximation uses 12 points evenly spaced around the perimeter. A star alternates between outer and inner radii. A hexagon places 6 points on vertices and 6 midway along edges. A blob uses irregular offsets for organic randomness. Same 12 points, radically different shapes.

Progressive enhancement with clip-path: path()

For truly organic shapes, clip-path: path() accepts SVG path data. Browser support is newer, so wrap it in @supports (clip-path: path("M0 0")). Path-based clip-paths can use curves (C, Q commands) for shapes impossible with polygon points alone.

Try it yourself

Mini-exercise

Try changing one of the polygon keyframes to use 11 points instead of 12. The transition to that shape will snap instantly — no interpolation. Then restore it and try creating a 5th keyframe at 87.5% with a diamond shape (all 12 points rearranged). Experiment with animation-timing-function: steps(1) for instant shape-switching instead of smooth morphing.
