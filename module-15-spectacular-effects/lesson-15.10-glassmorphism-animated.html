Lesson 15.10 · Spectacular Effects

Glassmorphism with Animated Gradient

A layered glass card floating over an animated gradient background. The combination of moving color, frosted glass, and hover elevation creates a premium, modern aesthetic. Dark mode flips the overlay. The effect should feel like a luxury product page.

The three-layer composition

The glassmorphism effect requires three visual layers working together. The background provides the color and motion — an animated gradient that rotates via @property --bg-angle. The glass card sits on top with backdrop-filter: blur(20px) saturate(180%), picking up blurred fragments of the background color. The border uses a semi-transparent white to catch the light.

The glass recipe

.glass {
  backdrop-filter: blur(20px) saturate(180%);
  background: oklch(100% 0 0 / 0.15);
  border: 1px solid oklch(100% 0 0 / 0.2);
  border-radius: 1rem;
  box-shadow: 0 8px 32px oklch(0% 0 0 / 0.1);
}

The animated background

Register --bg-angle as <angle> to enable smooth rotation. The gradient uses three OKLCH colors and rotates slowly — 20 seconds per revolution — creating that living, breathing background that makes the glass card pop.

Dark mode adaptation

In dark mode, the glass overlay switches from oklch(100% 0 0 / 0.15) (white tint) to oklch(0% 0 0 / 0.2) (dark tint). The border becomes oklch(100% 0 0 / 0.08) — subtler but still catching light. This two-line change is all that is needed.

Mini-exercise

Change the glass background to oklch(0% 0 0 / 0.25) for a dark-glass variant.
