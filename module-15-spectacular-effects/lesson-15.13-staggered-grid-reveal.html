Lesson 15.13 · Spectacular Effects

Staggered Grid Reveal

A grid of cards that reveal one by one in a wave pattern. Each card's delay is offset by its index, creating a cascading "rainbow wave" effect. Combined with scroll-driven animation for a reveal that triggers on scroll, not on page load.

The stagger pattern

Staggered animation means each element starts its animation slightly after the previous one. The delay is calculated per-element. The emerging CSS approach uses sibling-index() — but since browser support is still limited, we use inline style attributes with --i custom properties as the reliable fallback.

The delay calculation

/* Future: automatic stagger */
animation-delay: calc((sibling-index() - 1) * 60ms);

/* Current: manual index via custom property */
.card { animation-delay: calc(var(--i, 0) * 60ms); }
<div class="card" style="--i: 0">
<div class="card" style="--i: 1">
...

The reveal animation

Each card fades up from opacity: 0; transform: translateY(2rem) scale(0.95) to its natural position. The combination of vertical translation, slight scale, and opacity creates a "rising into existence" effect that feels organic.

Rainbow hue cycling

Each card's background hue is derived from its index: background: oklch(70% 0.15 calc(30 * var(--i))). With 12 cards at 30-degree hue increments, the grid cycles through the entire color wheel — creating a rainbow wave when the stagger plays.

Try it yourself

Mini-exercise

Try changing the stagger delay from 80ms to 150ms — it becomes more dramatic but slower. Then try 30ms — the wave becomes almost imperceptible. Find the sweet spot for your taste. Change the hue multiplier from 30 to 15 for a subtler color range, or 60 for a more compressed rainbow. For extra credit, wrap the animation in @supports (animation-timeline: view()) and add animation-timeline: view() to trigger on scroll.
