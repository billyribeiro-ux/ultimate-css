Lesson 15.8 · Spectacular Effects

Magnetic Hover Button

A button that "attracts" toward the cursor with a springy, elastic return. The CSS architecture uses custom properties for the transform, with an overshooting cubic-bezier that creates a physical, magnetic feel. Production uses 6 lines of JS for the coordinate; the CSS is where the magic lives.

The CSS-first approach

The magnetic effect is built on CSS custom properties and elastic easing. The transform reads from --tx and --ty which default to 0. In production, a mousemove listener calculates the offset between cursor and button center, scales it down (e.g., * 0.3), and sets those properties. The CSS handles all the animation physics.

The elastic easing

The key to the magnetic feel is cubic-bezier(0.33, 1, 0.68, 1) — this easing overshoots slightly past the target, then settles back. When the cursor leaves and the properties reset to 0, the button "bounces" back to center like a spring releasing. This single line of CSS is what makes it feel physical rather than robotic.

The production JS (6 lines)

btn.addEventListener('mousemove', e => {
  const rect = btn.getBoundingClientRect();
  const x = e.clientX - rect.left - rect.width / 2;
  const y = e.clientY - rect.top - rect.height / 2;
  btn.style.setProperty('--tx', `${x * 0.3}px`);
  btn.style.setProperty('--ty', `${y * 0.3}px`);
});
btn.addEventListener('mouseleave', () => {
  btn.style.setProperty('--tx', '0px');
  btn.style.setProperty('--ty', '0px');
});

CSS-only simplified version

Without JS, we use :hover for a simpler effect: transform: scale(1.05) translateY(-2px) with the elastic easing. It does not follow the cursor, but the elastic return still feels magnetic. This is the progressive enhancement baseline.

Mini-exercise

Try changing the cubic-bezier from (0.33, 1, 0.68, 1) to (0.34, 1.56, 0.64, 1) — this is the bounce easing from the tokens file. The overshoot is more dramatic. Then try a longer 600ms duration — the button feels heavier, like it has more mass. Which combination feels most magnetic to you?
